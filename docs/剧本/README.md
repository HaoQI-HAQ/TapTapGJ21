## 旁白系统核心设定

- **旁白 = 编织者**（世界观 §15）——上一轮循环留下的记忆，只引导不控制。
- **三档状态机**：引导（偏离值 0–3）/ 困惑（4–7）/ 坦白（8+），偏离值只升不降、跨关累计。
- **沉默 / 共鸣**（非《艾希》式对抗）——旁白不崩溃，它先沉默，再坦白。
- **密度规范**：主线短（≤3 句）/ 反应可长 / 记忆低语一句（≤15 字，画面边缘）。
