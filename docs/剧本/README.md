## 资源规则（2026-10-13 定案）

**泡泡值靠破坏可破坏的泡泡恢复**——破坏=赚，爆炸=花。**没有回收机制**（已全面移除）。
泡泡值不足时，去破坏粉色泡泡补充，不是捡回散落液滴。

## 旁白设定（一句话）

旁白 = **编织者**（世界观 §15）。三档状态由偏离值决定：引导 0–3 / 困惑 4–7 / 坦白 8+，跨关累计。

**三档调性**（2026-10-12 定案）：
- **引导**（默认）— 正经讲剧情、正经引导。
- **困惑**（偏离 4+）— 正经开始绷不住，说漏嘴、自我怀疑。
- **坦白**（偏离 8+）— **先破罐破摔，再摆烂**。旁白摊牌、自嘲、躺平。

> 与《艾希》的差异：《艾希》是旁白**崩溃**后玩家突破牢笼（对抗）；《泡涌》是旁白**破防**后摆烂，与玩家变成"一起摆烂的难兄难弟"。
