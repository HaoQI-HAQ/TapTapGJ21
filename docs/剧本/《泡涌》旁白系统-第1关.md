# 《泡涌》旁白系统设计 · 第 1 关

> **版本 v1.0** ｜ 2026-10-12 ｜ 状态：待评审
>
> 本文件是**旁白系统的可实现规格**，取代旧版《泡涌》剧本文案（第一版）中第 1 关的一次性台词表。
>
> 三条已确认的方向（来自评审）：
> 1. **旁白 = 编织者**（世界观 §15）
> 2. **保留沉默 / 共鸣，去掉"崩溃 / 对抗"**（差异化于《艾希》）
> 3. **密度规范**：主线短、反应可长、记忆一句
>
> 名词一律遵循《04-完整策划案》§0.1 术语规范（泡泡液 / 粉色泡泡墙 / 弹力泡泡 / 诞生泡泡体 / 愈合）。

---

## 0. 设计目标（一句话）

把旁白从**"一条条写死的台词"**升级为**"一个记得你、会随你改变状态的编织者"**。

参照《艾希》的三层结构，但落点不同：

| | 《艾希》 | 《泡涌》 |
|---|---|---|
| 旁白身份 | 系统程序（后期揭示） | **编织者**（前期即暗示，后期坦白） |
| 玩家反抗的结果 | 旁白崩溃、玩家突破牢笼 | 旁白**沉默 → 坦白 → 共鸣** |
| 情感底色 | 对抗、反叛 | 温柔、被看见 |
| 主题句 | "不再服从指令" | "两个不同的泡泡才会共鸣"（世界观 §18） |

## 1. 系统设计

### 1.1 旁白身份：编织者

旁白是一个**编织者**——世界观第十五章的定义：

> "编织者不是工匠。它们不'制作'泡泡，它们'生长'泡泡。"
> "我不是在吐泡泡。我是在和泡泡跳舞。我引导它们，它们也引导我。"
> "编织者的艺术，是这个世界最接近'游戏'的东西。"

**这一个设定同时解释了旁白的四个行为特征：**

| 旁白的行为 | 编织者身份的解释 |
|-----------|----------------|
| 它"知道接下来会发生什么" | 它编织过很多次这段旅程 |
| 它偶尔"记混"（第零次、我似乎说过同样的话） | 它是**上一轮循环**留下的记忆，但只剩模糊印象 |
| 它只引导、从不直接控制玩家 | 编织者的定义就是"引导而非控制" |
| 它对玩家的态度会变化 | 它逐渐意识到玩家不是"它吐出的泡泡"，而是**另一个编织者 / 海本身** |

**玩家身份的升级曲线**（对齐策划案 §8.9）：

```
第 1 关   旁白以为玩家是"故事里的一个泡泡"
第 2-3 关 旁白发现玩家会"自己找解法"——玩家开始像编织者
第 4-5 关 旁白承认玩家也是编织者——或者，玩家就是"海本身"
```

> ⚠️ 第 1 关**不揭穿**，只埋伏笔。所有"说漏嘴"都停留在**困惑态**，真正的坦白留给隐藏触发器。

### 1.2 三档状态与偏离值

旁白有三个内部状态。**状态是单向递增的**（只升不降），跨关累计——因为它是一个记得你的编织者。

| 状态 | 触发阈值 | 语气 | 视觉/声音 |
|------|---------|------|----------|
| **引导**（默认） | 偏离值 0–3 | 耐心、解释、教学命名、轻微自嘲 | 无特殊表现 |
| **困惑** | 偏离值 4–7 | 试探、自我怀疑、说漏嘴 | 开口前**先沉默一拍**（1.5s） |
| **坦白** | 偏离值 8+ | 承认编织者身份、承认循环、温柔 | 部分台词**完全沉默**，只留环境反馈 |

**偏离值（Deviation）增量表：**

| 行为类别 | 增量 | 例 |
|---------|------|----|
| 拒绝配合（长时间不行动） | +1 | 15s 不攻击、不回收 |
| 逆行 / 折返 | +1 | 走向反方向、返回出生点 |
| 机制重复（过度使用） | +1 | 破坏同一面墙 3 次 |
| 元行为 | +1 | 暂停、长时间静止、撞墙、盯视 |
| 病态行为（极端重复） | +2 | 破坏同一面墙 8 次、反复重开 |
| 隐藏发现 | +2（且反应**至少**为坦白） | 发现内壁纹路、异常液滴 |

**反应档位 = max(当前状态, 该触发器的档位下限)**

- 主线 / 机制首触 → 档位下限 = 引导（但用当前状态的口吻）
- 重复 / 偏离 / 元行为 → 档位下限 = 引导（随状态变化）
- 病态行为 → 档位下限 = 困惑
- **隐藏 → 档位下限 = 坦白**

> 设计意图：**顺从的玩家永远停在引导态**，看不到困惑/坦白的内容。只有探索、偏离、较真的玩家才会"逼出"编织者的另一面。这让"不听话"有正向奖励。

### 1.3 沉默与共鸣

这是本作**区别于《艾希》的核心机制**，也是"治愈"气质的落点。

**沉默的三种用法：**

| 用法 | 触发 | 表现 |
|------|------|------|
| **沉默一拍** | 状态跨入困惑 / 坦白的那一次 | 开口前 1.5s 无字幕，环境音微变（音量下沉 20%） |
| **完全沉默** | 坦白态下的特定触发器（见 §3 标注 `[静默]`） | 旁白**不说话**，只留环境反馈 + 画面边缘一句极短文字 |
| **主动沉默** | 玩家长时间静止（`PY-01-X-002`） | 旁白自述"我试着不说话"，然后真的不说话 |

**共鸣的落点**：当旁白和玩家"都发现了同一个东西"时（例如都数过破坏次数），播放**共鸣表现**——环境光轻微脉动一次，无台词。这是全系统最高级的反馈，**全第 1 关只出现 1–2 次**。

> 与《艾希》的关键差异：**旁白不会崩溃，它会先沉默，再坦白。** "沉默"本身就是它在"看见"你。

### 1.4 台词密度规范

| 层 | 用途 | 长度 | 出现位置 |
|----|------|------|---------|
| **主线旁白** | 教学命名、机制解释、推进 | **短**（≤3 句） | 画面中央下方 |
| **反应旁白** | 行为触发、编织者个性 | **可长**（不限） | 画面中央下方 |
| **记忆低语** | 世界观伏笔 | **一句**（≤15 字） | **画面边缘**，淡入淡出 |

> 只有**反应旁白**可以长。主线必须短（符合策划案 §12.3"反馈优先于文字"），记忆低语必须极短（符合 §10.5"最多一句"）。

### 1.5 反应表数据结构

给程序的实现契约（伪结构）：

```lua
Trigger = {
  id            = "PY-01-B-001",     -- 唯一 ID
  trigger       = "no_attack_15s",   -- 行为事件名
  scene         = "02",              -- 所属场景
  category      = "deviation",       -- main / repeat / deviation / meta / hidden
  deviation     = 1,                 -- 偏离增量
  once          = false,             -- 是否一次性
  min_tier      = "guide",           -- 档位下限
  cooldown      = 20,                -- 冷却秒数（0 = 无）
  priority      = 30,                -- 优先级（见 §1.6）
  variants      = {                  -- 按状态取台词
    guide   = { silence = 0,   text = "..." },
    puzzle  = { silence = 1.5, text = "..." },
    confess = { silence = 0,   text = "..." },  -- 或 silence_only = true
  },
}
```

**行为事件名（程序侧需要埋点）**：`no_attack_15s` / `no_attack_30s` / `first_break` / `attack_x8` / `return_to_spawn` / `hit_indestructible` / `watch_heal` / `break_same_wall_3` / `break_same_wall_8` / `no_ammo` / `refuse_recycle` / `charge_max` / `charge_cancel` / `charge_break` / `convert_material` / `self_launch` / `move_wrong_way` / `keep_wrong_way` / `idle_60s` / `idle_120s` / `pause_spam` / `stare_10s` / `reload_spam` / `exit_return` …

### 1.6 触发优先级（覆盖规则）

同一时刻多个条件满足时，取**优先级最高**的一条播放；其余进入队列，冷却结束后可补播。

```
隐藏(90) > 病态(70) > 元行为(50) > 偏离(30) > 重复(20) > 主线(10)
```

**打断规则**：
- **主线**（强制推进）可被任意偏离/元行为**打断**，偏离反应播完后主线**恢复**。
- **一次性**触发器播过即销毁。
- **升级型**（如"拒绝攻击 15s→30s"）用同一 `trigger` 的不同 ID，前者播完不销毁，后者在其基础上覆盖。

### 1.7 验收映射（对齐策划案 §8.4）

| 验收 | 对应触发器 |
|------|-----------|
| L1-01 首次破坏后解锁移动 | `PY-01-M-005` → `PY-01-M-006` |
| L1-02 理解资源有限并实际回收 | `PY-01-M-008` → `PY-01-M-009` → `PY-01-M-010` |
| L1-03 独立完成蓄力 | `PY-01-M-011` → `PY-01-M-012` |
| L1-04 理解弹力泡泡的双重属性 | `PY-01-M-013` |
| L1-05 恢复过程可见 + 存档点识别 | `PY-01-M-007` + `PY-01-H-001` |

## 3. 完整台词

> 格式：**触发条件** → **档位 / 增量 / 一次性** → 三档台词（引导 / 困惑 / 坦白）。
> `[静默]` = 该档位下旁白完全沉默，只留环境反馈。
> `[共鸣]` = 播完触发一次环境光脉动，无额外台词。

---

### 场景 01 · 苏醒（在语言之前）

#### PY-01-M-001 · 最初的空白
**触发**：进入新游戏，画面由黑渐变至白。玩家暂不可移动。
**档位**：固定 ｜ 一次性：是

> 一开始，什么都没有。
>
> 请不要急着纠正我。
>
> 我知道你现在已经看见了一些东西。比如白色。也许还有屏幕边缘那些不太自然的阴影。
>
> 但白色并不意味着存在。
>
> 一张没有写过字的纸是白色的。一张写满了字、又被人仔细擦干净的纸，也可以是白色的。
>
> 你能分辨它们吗？
>
> ……不能？
>
> 很好。
>
> 这意味着我们可以开始了。

> 💡 **伏笔**："擦干净的纸"= 循环暗示，引导态下不作解释。

#### PY-01-M-002 · 一个意外
**触发**：初始泡泡逐渐显现，出现第一次轻微膨胀。
**档位**：固定 ｜ 一次性：是

> 后来，这里出现了一个泡泡。
>
> 我本来想说，它是凭空出现的。
>
> 不过"凭空"这个词似乎有些不准确。毕竟，如果真的什么都没有，那么连所谓的"空"也不应该存在。
>
> 你看，描述一件事情总是这样。
>
> 我们不得不借用一些已经存在的概念，去解释那些概念尚未存在的时刻。
>
> 真是个令人头疼的问题。
>
> 幸好，这不是你现在需要考虑的。
>
> 你只需要知道，那个泡泡就是你。
>
> 至少，暂时是。

#### PY-01-M-003 · 关于名字
**触发**：镜头第一次完整展示玩家泡泡。
**档位**：固定 ｜ 一次性：是

> 我们需要给你一个名字吗？
>
> 或许应该。
>
> 毕竟一个没有名字的主角，会让后续的叙述变得非常麻烦。
>
> "它移动了。"
> "它停下了。"
> "它又做了一件令人费解的事情。"
>
> 听起来像是在记录某种实验动物。
>

### 4.2 状态机伪代码

```lua
local deviation = 0            -- 偏离值（跨关累计）
local TIER = { GUIDE = 0, PUZZLE = 1, CONFESS = 2 }

local function current_tier()
  if deviation >= 8 then return TIER.CONFESS end
  if deviation >= 4 then return TIER.PUZZLE  end
  return TIER.GUIDE
end

local function on_trigger(t)
  -- 一次性检查
  if t.once and fired[t.id] then return end
  -- 冷却检查
  if os.clock() - last_fired[t.id] < t.cooldown then return end

  local tier = math.max(current_tier(), TIER[t.min_tier])
  local v = t.variants[tier_name(tier)]

  if v.silence_only then play_environment_only()
  else play_line(v.text, v.silence) end

  deviation = deviation + t.deviation
  fired[t.id] = true
  last_fired[t.id] = os.clock()

  -- 状态跨档时，下一次开口前强制沉默一拍
  if tier > prev_tier then queue_silence_beat(1.5) end
  prev_tier = tier
end
```
