# 核心设计

> 版本 1.0 ｜ 2026-10-03 ｜ 本稿取代《游戏策划案 0.3》（载体「墙」已废弃）

## 一句话概念

**在意识之海里拨动泡泡——三条规则让它们自行聚散，拼出你从未设计过的过去。**

玩家以为自己在"打开泡泡、通过关卡"，
最后发现自己在"拼回一个已经破碎的家"，
而这个故事的结局，正好是它的开头。

## 一、主题如何落地

**涌现 = 简单规则 + 个体交互 → 宏观复杂行为。**

本作用**两层结构**实现，但两层互相咬合：

```
世界层   泡泡按自身规则涌现          ← 分裂 / 融合 / 膨胀
   ↑     （玩家不能直接控制）
玩家层   主角用能力拨动世界          ← 5 种能力
         （能力本身也是世界规则的一部分）
```

**关键**：玩家的能力**不是外挂的作弊器，是世界规则的杠杆**。
玩家撬动规则，规则自己演化，玩家看到的是**自己没设计过的结果**。

> 这就是"少即是多"：5 个工具 × 3 条规则 × N 种材质 = 玩家无法一次性推演的局面。

---

## 二、世界设定

| 项 | 内容 |
|----|------|
| 画风 | 二次元 |
| 世界 | **一个大泡泡**——所有场景、陷阱、UI 都在其中 |
| 意识空间 | 大泡泡内部分裂出的各种泡泡 |
| 载体 | **记忆碎片**（以泡泡形态呈现） |
| 边界 | **黑色深渊**——遗忘与消失的所在 |
| 主角 | **意识体**，操控泡泡行动 |

**美术统一原则**：一切皆泡泡。陷阱是泡泡，地图主题是泡泡，UI 也是泡泡。
玩家目之所及没有"非泡泡"的元素——这是视觉上的统一，也是设定上的自洽。

**材质差异**：不同关卡使用不同材质的泡泡（弹性 / 黏性 / 透明 / 易碎…）。
材质是**关卡差异化的主要手段**——同一套规则，换材质就是新关卡。

---

## 三、核心规则（世界层）

**只有三条。这是全作的地基，不可轻易增加。**

### 规则 ①：同类相融，异类相斥

同类泡泡靠近自动融合；异类互相推开。

### 规则 ②：扰动则裂

泡泡受到扰动时分裂。**玩家的一切操作都是扰动**——
所以不需要"分裂键"，你碰它，它就裂。

### 规则 ③：弥散则规则随变

泡泡膨胀时，向四周弥散影响，**改变全场的相吸相斥强度**。

> **规则③是反馈回路，也是涌现的引擎：**
> 膨胀 → 场强变化 → 规则①的强弱变化 → 泡泡行为变化 → 场强再变化
>
> **非线性从这里来。玩家无法穷举，就是因为这条回路。**

---

## 四、玩家能力（玩家层）

**五种能力，全部是对三条规则的拨动——不新增独立玩法。**

| 能力 | 拨动哪条规则 | 玩法效果 |
|------|-------------|---------|
| **黏合** | → 规则①（融合） | 强制两个泡泡融合 |
| **弹力** | → 规则③（膨胀） | 让泡泡弹性膨胀 |
| **延长** | → 规则③（膨胀） | 让泡泡拉长延伸 |
| **浮空** | → 规则③ 衍生 | 让泡泡上浮 |
| **重力** | → 规则③ 衍生 | 让泡泡下沉 |

**设计要点**：
- 分裂**没有专属能力**——规则②说"扰动则裂"，玩家的任何操作都是扰动
- 五种能力不是五套系统，是**同一套规则的五个杠杆**
- 新增能力必须回答："它拨动哪条规则？" 答不上来就不加

---

## 五、核心循环

```
        分裂
       ↗    ↘
    扰动      融合
       ↖    ↙
        膨胀
```

**玩家目标**：让关卡的阻挡物（泡泡）**短暂打开**，然后通过。

```
阻挡的泡泡 → 分裂 → 出现通道 → 玩家通过 → 泡泡重新融合闭合
                      ↑
                窗口期有限，必须抓住
```

**关键**：分裂是**暂时的**，融合会把它合上。
这带来时间压力，也让"通过"变成一个需要判断的决策，而不是无脑操作。

## 六、关卡结构（5 关 / 5 章节）

```
大泡泡 →（分裂成碎片）→ 进入下一关
```

| 关卡 | 定位 | 内容 |
|------|------|------|
| 第 1 关 | **教学** | 基础操作：分裂、融合。单一材质泡泡 |
| 第 2 关 | **教学** | 引入能力：黏合。两种材质 |
| 第 3 关 | **能力展示** | 弹力 / 延长。材质成为解谜核心 |
| 第 4 关 | **能力展示** | 浮空 / 重力。空间维度打开 |
| 第 5 关 | **综合 + 高潮** | 全部能力 + 叙事收束 |

**每关的结构**：一个"大泡泡"内部 → 玩家分裂它 → 碎片构成下一关。

**难度曲线**：教学关（1-2）建立规则认知；能力展示关（3-5）制造组合复杂度。

## 七、叙事结构

### 7.1 情感内核

> **主角是"家"的最后一段记忆。**
> 他必须放弃自己，才能让被留下的人继续活下去。

### 7.2 序破急

| 阶段 | 关卡 | 内容 |
|------|------|------|
| **序** | 1-2 | 主角在空白中醒来，不知自己是谁。通过拼合泡泡，逐渐拼出"家"的轮廓 |
| **破** | 3-4 | 越拼越发现：家是破的，泡泡里全是裂痕。真相浮现——家已不存在 |
| **急** | 5 | 主角意识到：自己不肯放手，才困住了那个人。必须放弃记忆，才能让他自由 |

### 7.3 莫比乌斯环

```
第 1 关的开头：一片空白
        ↑                    ↓
   放弃记忆  ←──────  第 5 关的结局
```

**结局 = 开头。**

主角在第 5 关放弃记忆 → 变回空白 → **正是第 1 关开场的那片空白**。

玩家通关后恍然大悟：**原来我一开始看到的空白，就是结局。**

> ⚠️ 这是本作最强的叙事钩子，也是最容易做砸的地方。
> 建议在 MVP 阶段就用占位文本验证这个"恍然大悟"能否成立。

### 7.4 两条涌现线

| 线 | 含义 | 落地方式 |
|----|------|---------|
| **记忆涌现** | 结构 + 行为 → 一段记忆显现 | 玩家拼出的结构触发记忆碎片 |
| **情感涌现** | 玩家的行为后果 → 情绪冲击 | 例：你想保护一个泡泡，它还是破了 |

## 八、记忆涌现如何触发（叙事 × 玩法的接口）

**核心矛盾**：涌现产出的是「状态」，叙事需要的是「事件」。
**解法**：造一台翻译机，把状态翻译成事件。

### 三层判定

```
① 结构约束   硬条件：泡泡数量、分布、位置是否满足      ← 过滤掉不可能的
② 情绪倾向   打分：当前配置"有多像"某段记忆            ← 只打分，不触发
③ 玩家确认   玩家做出动作（触碰 / 停留 / 注入）        ← 只有这一步才触发
```

**关键在第③层**：系统不因为"看起来像"就发剧情，**必须玩家用行为表态**。

### 语义走廊

```
严格配方：  只有拼出特定形状才触发
完全开放：  任何沾边的东西都触发  → 剧情漂移
语义走廊：  多种表达都能触发，但必须满足「必要条件 + 玩家确认 + 上下文」
```

**设计者控制"什么意义值得被识别"，玩家控制"用什么结构去表达"。**

### 记忆节点数据结构

| 字段 | 用途 |
|------|------|
| 核心问题 | 这个节点要让玩家理解什么？ |
| 必要条件 | 缺少什么就绝不成立？ |
| 支持条件 | 哪些特征提高显现强度？ |
| 确认行为 | 什么行为代表玩家的主动表达？ |
| 记忆反馈 | 残影 / 声音 / 画面 |
| 下一问题 | 这个理解会留下什么新问题？ |

## 九、设计原则

1. **不设计答案，设计规则**——不告诉玩家"怎么过"，只定义世界允许发生什么
2. **自由在表达层，约束在意义层**——玩家随便拼，但剧情不乱触发
3. **机制少而互相咬合**——新增机制必须与至少 2 个旧机制产生组合
4. **反馈优先于文字**——玩家一操作，世界立刻变化，不靠大段教程
5. **不做机制孤岛**——形状、材质、能力必须互相作用，不能各玩各的

## 十、MVP 与风险

### MVP（第一垂直切片）

```
1 个空间 + 30 个泡泡 + 3 条规则 + 3 种能力 + 1 个记忆节点 + 1 段记忆
```

**唯一要验证的问题**：
> 随便搅几下，它会不会长出一个**我没设计过、但看得懂**的东西？

**不含**：美术资产、多关卡、存档、音效、完整剧情。
用纯色球体验证规则土壤。

### 最大风险

**规则③数值发散。**

反馈回路最容易炸——膨胀改变场强，场强改变行为，行为又改变场强，**很容易泡成一锅混沌**。

**对策**：MVP 阶段只调这一个参数（弥散系数），用纯色球反复试。
**别等美术进来才发现规则不稳。**

### 第二风险

**叙事穿帮**——玩家搅出的结果对不上写的文案。

**对策**：每条记忆准备 2-3 个触发模式（宽容度）；文案最后写，等玩法定型。

### 关于结局的强制设计

结局参照《尼尔：机械纪元》E 结局——**玩家必须主动执行"放弃"，但剧情不给第二个选项**。

```
玩家被要求：放弃自己（记忆），换那个人自由
玩家可以拒绝 → 但拒绝就没有出路
最终玩家亲手执行了放弃
```

**关键**：强制的是"必须放弃"这个事实，**玩家拥有的是"执行权"**。
亲手按下那个键的瞬间，才是情感冲击的所在——**不是被剥夺，是自己放手。**
