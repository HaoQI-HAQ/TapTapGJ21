## 一句话概念

**在意识之海里拨动泡泡——三条规则让它们自行聚散，拼出你从未设计过的过去。**

| 项 | 内容 |

| 术语 | 本版定义 |
|------|----------|
| **泡泡体** | 可交互泡泡的统称 |
| **粉色泡泡（墙）** | 可破坏障碍，过一定时间恢复；时间 TBD（T01） |
| **诞生泡泡体** | 主角诞生点，也是最初存档点 |

**旧称对照**：“泡泡值”仅是泡泡液资源数值的旧称；“炸弹”改“爆炸”；“浮粘”改用“浮力 / 黏合”。正文统一用**黏合**。能力保持三类：**弹力、浮力/黏合、爆炸**，浮力与黏合不拆成第四种能力；实体/状态关系仍需细化（D02、D04）。

## 一、主题如何落地

**涌现 = 简单规则 + 个体交互 → 宏观复杂行为。**

```
世界层    泡泡之间的物理法则          ← 分裂 / 融合 / 膨胀
   ↑
玩家层    主角用三类泡泡能力拨动        ← 弹力 / 浮力与黏合 / 爆炸
```

**关键**：玩家的能力**不是外挂的作弊器，是世界规则的杠杆**。

> **少即是多**：3 类泡泡能力 × 1 个蓄力输入 × N 种材质 = 玩家无法一次性推演的局面。

## 二、世界层：三条规则

| 规则 | 内容 |
|------|------|
| **① 分裂** | 泡泡受到扰动时分裂 |
| **② 融合** | 同类泡泡靠近自动融合；不等于所有黏合判定和可逆性已定案 |
| **③ 膨胀** | 膨胀时弥散，**改变全场的相吸相斥强度** |

> **规则③是反馈回路，也是涌现的引擎。**

### 本版障碍恢复

**粉色泡泡墙被破坏后按时间恢复**（T01）。既有“分裂 → 膨胀 → 融合”的愈合表现方向保留，让恢复可见；具体过程参数仍需确认，不能用旧“周围无材料必永久”覆盖本次恢复要求。

**场景恢复与资源回收分开**：墙恢复不等于给玩家加液；回收返还的是已发射普通泡泡中的液体。

### 旧扩展方案待确认：场景可破坏（参考咚奇刚，D05）

旧稿将墙壁、天花板、地面都视为泡泡构成的活体物质，保留以下方向，但**不作为此次前三关必验收**：

| 旧破坏源 | 旧结果候选 |
|----------|------------|
| **弹力泡泡** | 暂时破坏，周围泡泡分裂/膨胀/融合，把缺口补上 |
| **爆炸泡泡**（旧称“炸弹”） | 永久破坏，泡泡被彻底消灭，无法愈合 |

**旧表现意图保留**：不是突兀重置，而是旁边泡泡流回补洞。

**旧涌现示例保留**：先用爆炸清空周围，再用弹力破坏 → 周围没有泡泡可愈合 → 人为制造永久空洞。适用材质、关键通路保护及是否采用永久破坏待确认（D05）；与爆炸泡泡液消耗可慢恢复是两回事。

## 三、玩家层：三类泡泡能力

| 泡泡 | 本版能力 | 资源规则 |
|------|----------|----------|
| **弹力** | 破坏物体 / 弹射自己；是粉色泡泡的**前置材料** | 普通泡泡可回收，返还前面已发射泡泡的液体 |
| **浮力 / 黏合** | 黏合拼成连接体，自制通关工具；浮力泡泡够大时**包裹玩家飞行** | 普通泡泡可回收；黏合态回收与结算细节 TBD（D01） |
| **爆炸** | 大质量、惯性和组合可能甩飞玩家；可控爆炸提供向外力，**力 = f（大小）** | 不可回收；爆炸产生不可回收消耗，随时间缓慢恢复 |

**已确认关系不等于已定参数**：包裹阈值 T05、爆炸不可回收量 T06、慢恢复速率 T07、爆炸力大小曲线 T08 均 TBD。爆炸可控不等于已指定远程按键；具体操作见 D03。

### 旧漂浮 / 黏合 / 爆炸候选对照（非新定案）

| 旧候选 | 原方案保留内容 | 当前状态 |
|--------|----------------|----------|
| **蓄力漂浮** | 泡泡 > 角色 2 倍，持续 5 秒，可控方向，结束时“爆炸落地” | 2 倍为旧阈值候选（T05）；5 秒、控制及结束方式为旧候选（D02），结束是否伤玩家待确认 |
| **泡泡空间漂浮** | 进入泡泡空间，无限持续、只能向上；碰到泡泡后黏合固定 | 仅旧飞行/退出候选（D02），不作为第 2–3 关已定限制 |
| **黏合判定** | 接触自动黏合且不可逆，固定并失去漂浮能力；黏合作为 Z 轴“刹车” | 接触/主动、可逆性、能否再进入/退出仍 TBD（D02、D04） |
| **释放方式** | 弹力可发射/放置；浮力与爆炸只能放置 | 保留旧操作候选，不替代当前逐关验收与后续操作细化 |
| **爆炸控制** | 压开关、一次只控制单枚、远程专用键引爆（如 F） | 单枚/远程 F 等仅旧候选；触发、并发数、是否伤玩家 TBD（D03） |

> **Z 轴闸门的设计意图保留**：让高度移动与关卡布局咬合；具体限制未定，不能再写成“唯一刹车”或“有去无回”。

## 四、输入：蓄力释放

**本版关系**：持续操作 → 泡泡变大 → 效果变化。蓄力时间与力度曲线 TBD（T03）；资源消耗曲线另列 D09。

```
旧键鼠候选：左键长按蓄力 → 泡泡变大 → 右键释放
```

> **大小、强度、资源成本互相关联，但不假定等比。** 旧“1 到 10 线性消耗”仅是资源消耗候选，不是蓄力力度曲线。回收操作、飞行控制、引爆具体操作均待细化（D01–D03）。

## 五、泡泡液资源系统（对应 04 §6）

| 项 | 本版规则 |
|----|----------|
| **有限** | 玩家可用液体有限，每个泡泡体内也有限；不代表场景泡泡可无限产液 |
| **普通泡泡回收** | 回收前面已发射普通泡泡的液体并返还；液上限与回收效率 TBD（T04） |
| **爆炸泡泡** | 不可回收；爆炸消耗量 TBD（T06），该消耗会慢恢复，速率 TBD（T07） |
| **存量与结算** | 玩家可用液体、已发射泡泡中的液体、爆炸不可回收消耗需区分；容量关系与消耗曲线 TBD（D09） |
| **未细化项** | 回收操作/范围、普通黏合态回收、自动消散时间及结算 TBD（D01） |

**旧“铅笔 / 钢笔”比喻保留作对照**：普通泡泡可回收，爆炸有较长时间成本；但不再用“一笔定生死”解释资源，永久环境改变仅是旧扩展方案（D05）。

## 六、失败、返回与旧惩罚方案

### 本版处理

| 风险 | 处理 |
|------|------|
| **掉入空洞** | 返回**房间初始点**；精确返回点与重置范围 TBD（T09） |
| **初始存档** | 诞生泡泡体为最初存档点；持久化内容、保存时机与存档位仍需补充 |
| **泡泡液归零** | 暂时不能发射；可回收场上普通存量，或等爆炸不可回收消耗慢恢复，**不是必死/只能重开** |
| **风险反馈** | 保留低资源提示与自愿重开，提示可用恢复方式；不强制判定“无法通关” |

> **资源失误仍有代价，但恢复路径可见。** 存档初始点已有定义，重要缺口是返回和重置边界，不是“存档全空白”。

### 旧扩展方案待确认（D05、D06）

| 旧框架 | 原候选与设计意图 |
|--------|------------------|
| **黑色深渊** | 原为空间失误、掉入即死；本版空洞按返回规则处理，不直接沿用硬死亡 |
| **增值泡泡潮** | 原为第 3 关起、进入房间后从角落向中心扩散，追上即死，可摆脱/破坏但无法根除；是否加入第 3 关和启动点 TBD（D06） |
| **破坏回复** | 原为主要资源补给，时间恢复作保底；是否采用及适用范围 TBD（D05），不能声称唯一恢复途径 |
| **泡泡潮补给** | 原“既是威胁，也是补给”依赖破坏回复，需与泡泡潮共同确认（D05、D06） |
| **软死亡** | 原“归零还能动但只能重开”的规则已被本版恢复路径替代；懊悔/责任感作为风险反馈设计意图保留 |

**旧数值测试基准（不是已定数值）**：上限 **100**（T04）；小泡泡消耗 **1** / 单次蓄力消耗上限 **10、线性递增**（D09）；破坏大泡泡恢复 **50、容积 8**、泡泡潮回复 **容积基础 + 1**（D05、D06）。不将旧消耗曲线混入 T03 力度曲线。

## 七、核心循环

```
        分裂
       ↗    ↘
    扰动      融合
       ↖    ↙
        膨胀
```

**通关**：让阻挡的粉色泡泡墙**短暂打开** → 通过 → 障碍按时间恢复。

**资源**：普通泡泡发射/组合 → 回收返液 → 再使用；爆炸泡泡不可回收，爆炸消耗慢恢复。

## 八、关卡结构与教学验收（对应 04 §8.4–8.6）

**通用节奏**：**限制行动 → 操作 → 反馈 → 命名 → 自由**；允许反馈后的简短命名提示，不能用长篇说明取代体验。前三关白色为主、少量交互，可窥见记忆景观。

| 关 | 类型 | 最新教学顺序 / 方向 |
|----|------|----------------------|
| 1 | 教学 | 固定视角限制移动 → 破首个粉色泡泡解锁移动 → 破坏一定数量后教液体有限与回收前面已发射普通泡泡 → 蓄力 → 弹力是粉色泡泡的前置材料 |
| 2 | 教学 | 空洞与顶部黏合群 → 拼连接体自制工具 → 跨越空洞、掉落回房间初始点 → 浮力泡泡够大包裹飞行 |
| 3 | 教学 | 已有飞行 → 定向运动实体/爆炸陷阱推向空洞 → 组合物理 → 不可回收消耗慢恢复 → 大质量惯性可能甩飞 → 可控爆炸 → 向外力 = f（大小） |
| 4 | 正式 | 组合：三类泡泡综合运用，具体设计待细化（D07） |
| 5 | 正式 | 共鸣：全部机制与叙事收束，具体设计待细化（D07） |

### 逐关验收焦点

- **第 1 关**：首次破坏后解锁移动；实际回收已发射普通泡泡并观察返液，回收先于蓄力教学；玩家独立完成蓄力并辨认效果差异，理解弹力是粉色泡泡的前置材料；诞生泡泡体为初始存档，粉色泡泡墙恢复可见。破坏数 T02、蓄力时间/力度 T03、前置转化 D04 待定。
- **第 2 关**：玩家实际拼出连接体作为自制工具，并利用浮力包裹飞行跨越空洞；失败返回房间初始点可验证。阈值 T05、返回/重置 T09、飞行与黏合操作 D02 待定，不用旧 2 倍/5 秒/只向上/不可逆作阈值。
- **第 3 关**：玩家实际利用爆炸向外力与泡泡组合完成移动或解谜；理解不可回收消耗缓慢回复、力与大小相关；定向运动、陷阱推力及大质量惯性可读。T06–T08、D03 待定，泡泡潮 D06 不列此次必验收。

## 九、叙事结构

**情感内核**：主角是“家”的最后一段记忆，必须放弃自己，才能让被留下的人自由。

**序破急**：

| 阶段 | 关卡 | 内容 |
|------|------|------|
| 序 | 1-2 | 空白中醒来，拼出“家”的轮廓 |
| 破 | 3-4 | 发现家是破的，真相浮现 |
| 急 | 5 | 必须放弃记忆，才能让它自由 |

**莫比乌斯环**：

```
第 1 关的开头：一片空白
        ↑                ↓
   放弃记忆 ←──── 第 5 关的结局
```

> **结局 = 开头。** 玩家通关后恍然大悟：原来我一开始看到的空白，就是结局。

以上叙事方向保留；角色、逐关记忆、对白/旁白、伏笔与结局演出仍是独立缺口，不因前三关机制整理而视为补齐。

## 十、设计原则

1. **不设计答案，设计规则**
2. **自由在表达层，约束在意义层**
3. **机制少而互相咬合**
4. **反馈优先于文字**——按“限制行动 → 操作 → 反馈 → 命名 → 自由”，允许简短命名提示
5. **不做机制孤岛**
6. **状态与候选分开**——新规范可验收，TBD 不编数值，旧扩展不冒充定案
