## 二、🔴 阻塞级缺口

### 2.1 剧情设计（第 9 章）

**现状**：只有一句情感内核，9.2 角色 / 9.3 剧情均为"待补充"。

**缺什么**：

| 项 | 说明 |
|----|------|
| 角色设定 | 主角是谁？"那个人"是谁？两人关系？ |
| 故事线 | 5 关分别对应什么叙事节点？ |
| 记忆碎片内容 | 每个节点具体显现什么记忆？ |
| 对白/旁白文案 | 全作台词 |
| 结局呈现 | 莫比乌斯环具体怎么演？ |
| 伏笔设计 | 前 4 关埋什么，第 5 关回收什么？ |

**影响**：关卡设计的叙事节点无法确定。

> ⚠️ **团队决定**：剧情素材由团队提供，AI 负责整理。

---

### 2.2 数值设计（缺独立章节）

**现状**：参数散落在各章，无独立章节。

**缺什么**：

| 类别 | 参数 |
|------|------|
| 泡泡值 | 上限、消耗曲线、回收比例、炸弹恢复速度 |
| 泡泡基础 | 尺寸范围、蓄力时长、发射速度 |
| 三种泡泡 | 各自的强度参数 |
| 角色 | 移动速度、跳跃高度、重力 |
| 愈合 | **开始时间、速度、是否受大小影响**（程序暂定） |

**影响**：程序无法调手感，关卡难度无法定。

---

### 2.3 第 4、5 关设计

**现状**：1-3 关（教学关）已详设，**4、5 关（正式关卡）只有方向性描述**。

**缺什么**：

| 项 | 说明 |
|----|------|
| 房间平面图 | 空间尺寸、形状 |
| 机关位置 | 泡泡、开关、深渊的具体摆放 |
| 玩家动线 | 从起点到终点的路径 |
| 谜题设计 | 具体的组合解法 |

**影响**：程序无法搭建 4、5 关。
