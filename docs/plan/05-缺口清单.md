## 二、阻塞级缺口

### 2.1 剧情设计（第 9 章）

**现状**：有情感内核、序破急与莫比乌斯方向，角色 / 剧情仍待补充。本次机制整理不替代叙事内容。

| 项 | 缺什么 |
|----|--------|
| 角色设定 | 主角是谁？“那个人”是谁？两人关系？ |
| 故事线 | 5 关分别对应什么叙事节点？前三关伏笔与后续展开如何衔接？ |
| 记忆碎片内容 | 每个节点具体显现什么记忆，远景可窥见哪些景观？ |
| 对白/旁白文案 | 全作台词与必要的简短机制命名提示 |
| 结局呈现 | 莫比乌斯环具体怎么演？ |
| 伏笔设计 | 前 4 关埋什么，第 5 关回收什么？ |

**影响**：关卡记忆反馈与叙事节点无法具体制作。机制命名允许简短提示，不再要求“完全零文字”。

> **团队决定保留**：剧情素材由团队提供，AI 负责整理。

### 2.2 数值设计：从旧“已定”改为 TBD / 旧候选

**现状**：资源机制已明确，**关键数值未定**。旧 100 上限、1/10 线性消耗不再是最终规格，不能以“程序自定”冒充验收阈值。

| 类别 | 当前状态 |
|------|----------|
| 泡泡液上限、回收效率 | TBD（T04）；100 仅旧测试基准 |
| 回收教学触发破坏数 | TBD（T02），不能直接沿用旧大泡泡破坏数量 |
| 蓄力时间与力度曲线 | TBD（T03），与资源消耗曲线分开 |
| 浮力包裹阈值 | TBD（T05）；旧 > 角色 2 倍不定案，衡量口径也需确认 |
| 爆炸不可回收消耗 / 慢恢复速率 | TBD（T06、T07），不是永久损失 |
| 爆炸力与大小关系 | 已知向外力 = f（大小），具体曲线 TBD（T08） |
| 粉色泡泡墙恢复时间 | TBD（T01），恢复过程开始/速度/大小影响需细化 |
| 泡泡基础物理 | 尺寸范围、发射速度、重力、质量、各能力强度参数仍待调试 |
| 角色参数 | 移动速度、跳跃高度、重力仍待调试 |

**影响**：手感和难度无法锁定。测试可以使用明确标记的临时参数，策划不得把它们写成最新已定标准。

## 三、重要但可分阶段补齐

### 3.1 回收机制与资源结算（D01、D09）

**已经明确**：普通泡泡可回收并返还其中已发射的泡泡液；爆炸泡泡不可回收，爆炸消耗可慢恢复。不是破坏场景回复。

**尚缺**：回收按键/操作、范围、目标选择、普通黏合态能否/如何回收；自动消散时间及消散后的资源结算；玩家可用液体、泡泡内液体与爆炸消耗的容量关系。

**验收相关**：第 1 关必须回收前面已发射的普通泡泡。回收效率见 T04，自动消散结算不能继续无条件沿用旧“不返还”方案。

### 3.2 存档与失败返回（T09）

| 已知 / 待定 | 内容 |
|-------------|------|
| **已知** | 诞生泡泡体是最初存档点；掉入空洞返回房间初始点 |
| **重要 TBD** | 房间初始点的精确位置、安全落点；角色位置/速度/飞行状态、资源、连接体、场景泡泡、陷阱/运动状态、教学进度等哪些保留、哪些重置 |
| **持久化缺口** | 存什么、怎么存、什么时候保存、多存档位/继续游戏；这些与落穴返回规则分别设计 |
| **自愿重开** | 保留交互与风险提示，但重开不能是资源归零的唯一出路；它与落穴返回的重置范围是否不同需确认 |

**影响**：第 2–3 关反复试错、资源守恒与教学连续性。初始点已知，但重置范围**不能降为可选装饰项**。

### 3.3 音频设计（第 11 章）

**缺什么**：音乐情绪曲线、动态音乐方案、音效触发时机；回收返液、爆炸不可回收消耗与慢恢复如何被听见。

### 3.4 UI / UX（第 12 章）

| 界面 / 交互 | 待补与核对 |
|-------------|------------|
| 主菜单 | 开始/继续/设置/退出 |
| 暂停菜单 | 恢复/自愿重开/设置/返回 |
| 设置界面 | 音量、画质、键位重映射 |
| 关卡结算 | 是否有关卡结算？ |
| 记忆图鉴 | 是否展示已收集的记忆？ |
| 资源反馈 | 区分可用液体、可回收存量与爆炸消耗慢恢复；不能显示“只能重开” |
| 教学提示 | 反馈后简短命名；回收、包裹飞行、引爆的具体操作提示待 D01–D03 定案 |

### 3.5 美术 / 风格应用缺口

**方向保留**：手绘厚涂、果冻水母 + 耳机（v2.26）、粉紫/水青参考与海洋元素。

**本次明确边界**：前三关白色主色、少量交互；记忆景观可窥见。旧第 2–3 关粉紫水下主色不再定案，转为远景与第 4–5 关方向。

**待细化**：每关交互焦点与远景层级、泡泡恢复/回收/爆炸慢恢复反馈的视觉区别、角色与厚涂场景的统一程度；记忆景观具体内容需与叙事共同确定。

## 五、与 04 §15 对齐的待确认项

**固定编号共 19 项：核心 TBD 9 项 + 补充设计 10 项。** 下表不填任何未确认数值；“已有规则”与“待定参数”分列，其他叙事/风格/存档等缺口继续按上文章节维护。

### 5.1 核心 TBD（T01–T09，九项）

| ID | 核心 TBD | 已确认边界 / 待确认内容 |
|----|----------|--------------------------|
| **T01** | **粉色泡泡恢复时间** | 粉色泡泡墙会按时间恢复；何时开始、多久完成及过程节奏待定，不编秒数 |
| **T02** | **回收教学触发的破坏数量** | 第 1 关先破首个粉色泡泡解锁移动，再破一定数量后教有限与回收；具体数量待定 |
| **T03** | **蓄力时间与力度曲线** | 蓄力影响泡泡大小与效果；时长与力度映射待定，不能把旧线性资源消耗当成力度曲线 |
| **T04** | **泡泡液上限与回收效率** | 玩家与泡泡体内液体均有限，普通泡泡可回收返液；上限/效率待定，100 仅旧测试基准 |
| **T05** | **浮力包裹阈值** | 浮力泡泡够大时能包裹玩家飞行；具体阈值及大小衡量口径待定，旧 2 倍仅候选 |
| **T06** | **爆炸不可回收量** | 爆炸泡泡不可回收，爆炸产生不可回收消耗；具体量及其与大小的关系待定，不视为永久损失 |
| **T07** | **慢恢复速率** | 爆炸不可回收消耗随时间缓慢恢复；速率、开始时机与结算节奏待定，不虚构全资源统一自动补满规则 |
| **T08** | **爆炸力与大小曲线** | 爆炸提供向外力，力 = f（大小）；具体函数、范围与受力衰减待定，不默认线性 |
| **T09** | **空洞精确返回点与重置范围** | 已知返回房间初始点、诞生泡泡体为最初存档点；精确位置和哪些状态重置待定，不直接等同整关重开 |

| ID | 补充设计 | 必须细化 / 确认的内容 |
|----|----------|------------------------|

## 六、建议的补充顺序

1. **平台正式确认（D08）**——跨实现路径的决策优先完成。
2. **核心 TBD（T01–T09）与操作细化（D01–D04、D09）**——先保障前三关资源、教学与失败返回闭环，未定值明确标记。
3. **剧情素材与记忆节点**——最大内容缺口，影响景观、反馈与后续关卡；可与前三关机制验证并行。
4. **第 4–5 关设计（D07）**——明确正式关卡空间、谜题与叙事落点。
5. **旧扩展是否采用（D05、D06）**——不要默认塞进前三关或当前验收。
6. **UI / UX、音频与风格应用**——按最终操作、资源口径完善体验。
7. **存档持久化与性能/无障碍等**——返回点和重置范围已在 T09 优先处理，不随扩展体验后移。
