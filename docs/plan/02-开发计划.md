## 一、里程碑

| 阶段 | 目标 | 出口标准 | 状态 |
|------|------|---------|------|
| **P0 概念验证** | 证明泡泡机制好玩 | 蓄力释放 + 泡泡空间可玩 | 🟡 进行中 |
| **P1 垂直切片** | 证明一关成立 | 第 1 关完整可玩，覆盖首次破坏解锁、回收、蓄力、前置材料（04 §8.4） | ⬜ 未开始 |
| **P2 内容生产** | 5 关完成 | 前三关逐项验收 + 第四/五关综合运用；完整叙事仍为后续目标 | ⬜ 未开始 |
| **P3 打磨** | 手感、美术、音频 | 可发布 | ⬜ 未开始 |

### P0 关键验证（最高优先级）

**要验证的问题**：

1. **蓄力手感**——大小与力度反馈是否直觉；蓄力力度曲线和资源消耗曲线分开测试。
2. **资源闭环**——普通泡泡回收返还、爆炸不可回收消耗缓慢回复可被辨认，不直接沿用旧上限 100。
3. **连接与浮力**——能拼接自制泡泡连接体，达到待定阈值后包裹玩家飞行；控制与黏合限制作为候选验证。
4. **组合物理**——大质量惯性和与大小相关的向外力能否用于移动/解谜。
5. **教学与失败**——首次破坏后解锁移动；回收教学触发时有此前发射的普通泡泡可回收；掉入空洞返回房间初始点。
6. **参数确认**——04 §15 的 T01–T09 全部保持 TBD；墙体恢复、回复速率、飞行阈值等先测试再定案。

**不含**：美术、多关卡、存档、完整剧情。

## 三、风险

| 风险 | 表现 | 对策 | 优先级 |
|------|------|------|--------|
| **规则③数值发散** | 泡成一锅混沌 | 只调弥散系数，灰盒反复试 | 🔴 最高 |
| **叙事穿帮** | 玩家搅出的对不上文案 | 每条记忆备 2-3 个触发模式 | 🔴 高 |
| **开发平台未定** | 阻塞开发 | 尽快确认 Unity / UrhoX | 🔴 高 |
| **涌现不可读** | 玩家看不懂发生了什么 | 加强反馈，让因果可见 | 🟠 中 |
| **莫比乌斯不成立** | 玩家没有"恍然大悟" | MVP 阶段用占位文本先验证 | 🟠 中 |
| **箱庭视角限制** | 垂直玩法难表现 | 第 4 关重点验证 | 🟡 低 |
| **资源耗尽反馈误导** | 玩家误以为归零必须重开 | 提示普通泡泡回收或不可回收消耗缓慢回复；重开自愿，不暗示永久死亡 | 🟠 中 |
| **教学资源死锁** | 触发回收教学时此前泡泡已消散或不可达 | 联动确认回收操作、泡泡生命周期与返回结算（04 D01、D09） | 中 |
| **旧方案混入定案** | 2 倍/5 秒/单枚/破坏回复被当成固定验收 | 分离旧候选与 T01–T09；泡泡潮、永久破坏须确认适用范围 | 中 |

## 四、关卡开发顺序

```
第 1 关（弹力）      ← P1：首次破坏解锁 / 回收 / 蓄力 / 材料认知
   ↓
第 2 关（黏合/浮力） ← 连接体 / 包裹飞行 / 空洞返回
   ↓
第 3 关（爆炸）      ← 组合物理 / 可控爆炸 / 不可回收消耗缓慢回复
   ↓
第 4、5 关           ← 待设计细化后再做
```

**逐关验收依据**：04 §8.4、§8.5、§8.6。泡泡潮、破坏回复和永久破坏保留为待确认旧扩展，不追加为本次前三关核心验收。
