# 开发计划

> **版本 v2.22** ｜ 2026-10-09 ｜ 与 [04-完整策划案.md](04-完整策划案.md) 同步

## 一、里程碑

| 阶段 | 目标 | 出口标准 | 状态 |
|------|------|---------|------|
| **P0 概念验证** | 证明泡泡机制好玩 | 蓄力释放 + 泡泡空间可玩 | 🟡 进行中 |
| **P1 垂直切片** | 证明一关成立 | 第 1 关完整可玩 | ⬜ 未开始 |
| **P2 内容生产** | 5 关完成 | 全部关卡 + 叙事 | ⬜ 未开始 |
| **P3 打磨** | 手感、美术、音频 | 可发布 | ⬜ 未开始 |

### P0 关键验证（最高优先级）

**要验证的问题**：

1. **蓄力手感**——长按蓄力是否直觉？大小与强度的对应是否清晰？
2. **泡泡空间**——进入空间、弹射、漂浮的体验是否爽快？
3. **三泡泡组合**——互相影响时，能否产生"我没设计过"的结果？
4. **愈合参数**——愈合开始时间与速度（**程序暂定，需反复测试**）

**不含**：美术、多关卡、存档、完整剧情。

## 二、分工

| 角色 | 负责内容 |
|------|---------|
| **策划** | 玩法设计、语义节点、关卡设计、数值 |
| **程序** | 核心系统（泡泡/规则/场/能力/判定）、工具链 |
| **美术** | 视觉语言、场景、角色、记忆反馈表现 |

**协作方式**：不采用"策划→美术→程序"的瀑布，而是**围绕可玩闭环的短周期迭代**。

## 三、风险

| 风险 | 表现 | 对策 | 优先级 |
|------|------|------|--------|
| **规则③数值发散** | 泡成一锅混沌 | 只调弥散系数，灰盒反复试 | 🔴 最高 |
| **叙事穿帮** | 玩家搅出的对不上文案 | 每条记忆备 2-3 个触发模式 | 🔴 高 |
| **开发平台未定** | 阻塞开发 | 尽快确认 Unity / UrhoX | 🔴 高 |
| **涌现不可读** | 玩家看不懂发生了什么 | 加强反馈，让因果可见 | 🟠 中 |
| **莫比乌斯不成立** | 玩家没有"恍然大悟" | MVP 阶段用占位文本先验证 | 🟠 中 |
| **箱庭视角限制** | 垂直玩法难表现 | 第 4 关重点验证 | 🟡 低 |
| **软死亡挫败感** | 玩家资源用光后白耗时间 | 必须有明确视觉/文字提示 + 一键重开 | 🟠 中 |

## 四、关卡开发顺序

```
第 1 关（弹力）    ← P1 垂直切片，最先做
   ↓
第 2 关（浮粘）    ← 验证 Z 轴闸门
   ↓
第 3 关（爆炸）    ← 验证物理组合
   ↓
第 4、5 关         ← 待设计细化后再做
```
