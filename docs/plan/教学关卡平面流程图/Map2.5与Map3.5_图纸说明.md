# Map2.5 / Map3.5 图纸说明

本次输出两张 2500 × 1800 PNG：`Map2_5_卡奥玛卡_平面流程图.png`、`Map3_5_夏塔瓦_平面流程图.png`。依据项目当前 `LevelWhiteboxSetup.cs` 中对应构建函数及场景物件名称整理，图纸属于当前白盒的平面定位与预期流程说明，不是原作实测复原图。未进行通关测试，本次未修改 Unity 场景。

## 读图

- X/Z 为俯视坐标，北向为 +Z；单位按 Unity 米制约定。
- Y 为平台可站立的顶面高度，等于未旋转方块中心 Y 加厚度的一半。
- 蓝箭头为预期主流程，橙虚线为支线或回返顺序；不表示已验证可达。
- Map2.5 的青虚线是现有 A/B/C 门桥参考姿态，没有碰撞。Map3.5 的青虚线是移动平台中心轨迹。
- 红色为尚未贯通或存在几何冲突的位置。
- Map3.5 右图是 Z/Y 投影，位于不同 X 的物件会重叠，不是切开柱体后的真实剖面。
