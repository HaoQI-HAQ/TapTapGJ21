# 一、项目概述

## 1.1 一句话

**在意识之海里吹出泡泡——三种泡泡互相影响、彼此组合，搭出你从未设计过的路。**

## 1.2 定位

| 项 | 内容 |
|----|------|
| 类型 | 关卡解谜 |
| 表现 | **3D** |
| 画风 | 卡通 |
| 平台 | **PC 优先**（键鼠 + 手柄）；移动端仅预留适配方向 |
| 规模 | 5 关，线性推进 |
| 主题 | 涌现（Emergence） |

## 1.3 核心体验

玩家作为**意识体**，用**泡泡**在记忆空间中搭建通路、破解机关。

三种泡泡（弹力 / 浮力 / 炸弹）**互相影响、彼此组合**——
单独看每一种都很简单，组合起来却能做出玩家自己都没想到的事。

玩家逐渐发现：自己在**重拾一个已经破碎的自我**，
最终**抛却原有的"标签"，得到自我的成长**。

最后明白：**这个故事的结局，正是它的开头。**

## 1.4 主题如何落地

**涌现 = 简单规则 + 个体交互 → 宏观复杂行为。**

**三层结构，两层咬合：**

```
世界层    泡泡之间的物理交互           ← 分裂 / 融合 / 膨胀（玩家不能直接控制）
   ↑
玩家层    主角用三种泡泡能力干预        ← 弹力 / 浮力 / 炸弹
```

**关键**：玩家的能力**不是外挂的作弊器，而是世界规则的杠杆**。

**三种泡泡互相影响组合** → 这就是本作的涌现来源。

> **少即是多**：3 种泡泡 × 1 个蓄力输入 × N 种材质 = 玩家无法一次性推演的局面。

# 二、世界观与设定

## 2.1 空间结构

```
┌─────────────────────────────────────────┐
│           大泡泡（世界本身）              │
│                                         │
│   ┌──────┐   ┌──────┐   ┌──────┐        │
│   │ 房间 │   │ 房间 │   │ 房间 │  ...   │  ← 意识空间（分裂出的泡泡）
│   └──────┘   └──────┘   └──────┘        │
│                                         │
│   ▓▓▓▓▓▓▓▓ 黑色深渊（死亡）▓▓▓▓▓▓▓▓     │
└─────────────────────────────────────────┘
```

| 概念 | 设定 |
|------|------|
| **大泡泡** | 整个世界。一切都在它内部 |
| **意识空间** | 大泡泡内部分裂出的各个房间 |
| **记忆碎片** | 以泡泡形态存在的记忆 |
| **黑色深渊** | 遗忘与消失的所在。**掉入 = 死亡** |
| **主角** | **意识体**——操控泡泡行动 |

## 2.2 美术统一原则

**一切皆泡泡，但主角是 3D 小人的形象。**

- 陷阱是泡泡
- 地图主题是泡泡
- **UI 也是泡泡**

玩家目之所及**没有"非泡泡"的元素**。

## 2.3 泡泡材质

**材质是关卡差异化的主要手段。**

| 材质 | 特性 | 玩法含义 |
|------|------|---------|
| **易碎** | 一碰就裂 | 高风险通道 |
| **黏性** | 与其他泡泡强吸附 | 搭桥、粘连 |
| **透明** | 可穿透 | 穿过障碍、看见内部 |
| **坚硬** | 分裂不开 | 需要先软化才能处理 |
| **弹性** | 可被弹力大幅拉伸 | 弹跳、远距离移动 |

# 三、核心规则系统（世界层）

> **这一层是泡泡自己的物理法则，玩家不能直接控制——只能通过泡泡能力去拨动。**

## 规则 ①：分裂

泡泡受到扰动时分裂。

> **玩家的一切操作都是扰动**——所以不需要"分裂键"。

## 规则 ②：融合

同类泡泡靠近自动融合。

## 规则 ③：膨胀

泡泡膨胀时，向四周弥散影响，**改变全场的相吸相斥强度**。

> **这是反馈回路，也是涌现的引擎。**
> **非线性从这里来。玩家无法穷举，就是因为这条回路。**

## 规则之间的关系

```
        分裂
       ↗    ↘
    扰动      融合
       ↖    ↙
        膨胀
```

# 四、泡泡能力系统（玩家层）

> **三种泡泡，是玩家拨动世界规则的三种杠杆。**

## 4.1 三种泡泡

### 弹力泡泡

| 项 | 内容 |
|----|------|
| **能力** | 弹出破坏物体 / 创建**弹射泡泡空间** |
| **泡泡空间** | 像三维弹球——把玩家自身**弹射出去** |
| **释放** | **可发射，也可放置** |
| **典型用途** | 破坏障碍、弹射移动、跨越地形 |

### 浮力泡泡

| 项 | 内容 |
|----|------|
| **能力** | 创建**浮力泡泡空间**让自己漂浮 / 多个泡泡**连接成桥** |
| **泡泡空间** | 内部失重漂浮 |
| **释放** | 只能放置（或放入泡泡空间） |
| **典型用途** | 上升、搭桥、跨过深渊 |

### 炸弹泡泡

| 项 | 内容 |
|----|------|
| **能力** | 压住开关 / **远程按键引爆** |
| **泡泡空间** | — |
| **释放** | 只能放置（或放入泡泡空间） |
| **典型用途** | 压机关、爆破障碍 |
| **⚠️ 限制** | **一次只能控制一枚炸弹** |

## 4.2 三种泡泡的相互影响

**这是本作涌现的核心来源。**

```
弹力 × 浮力 = 弹上去，浮住
弹力 × 炸弹 = 炸开后弹射
浮力 × 炸弹 = 炸开后被浮力托起
三种组合   = ？
```

> 单独看每种泡泡都很简单，**组合起来玩家无法穷举**。

## 4.3 泡泡空间

**三种泡泡都能创建泡泡空间**——这是统一的底层机制。

![泡泡空间（蓝）](images/bubble-space-blue.png)
![泡泡空间（橙）](images/bubble-space-orange.png)

| 项 | 内容 |
|----|------|
| **形态** | 半透明球体，有边缘光晕，内部可见 |
| **颜色** | 按泡泡类型区分（弹力 / 浮力 / 炸弹） |
| **作用** | 进入后获得对应效果 |
| **入口** | 玩家走进去，或泡泡包裹玩家 |

**设计要点**：三种泡泡共享"创建空间"这一底层机制，
**不是三套独立系统**——这保证了机制的咬合。

# 五、输入与释放

## 5.1 蓄力释放

```
左键长按蓄力 → 泡泡变大 → 右键释放
```

![发射引导线](images/aim-line.png)

| 步骤 | 操作 | 效果 |
|------|------|------|
| 1 | **左键长按** | 开始蓄力，泡泡逐渐变大 |
| 2 | 蓄力中 | 泡泡越大 → **能力强度越高** |
| 3 | **右键** | 释放出去 |

## 5.2 大小决定强度

**一个输入维度，同时控制三件事：**

```
长按越久 → 泡泡越大 → 能力越强
```

| 泡泡 | 越大则 |
|------|--------|
| 弹力 | 弹得越远 / 破坏力越强 |
| 浮力 | 浮力越大 / 空间越大 |
| 炸弹 | 爆炸范围越大 |

> **玩家每一次点击都在做一个连续的权衡**——蓄多久？
> 这是"少即是多"的又一次应用：**一个输入，三种能力，无限组合**。

## 5.3 释放方式

| 泡泡 | 可发射 | 可放置 |
|------|--------|--------|
| **弹力泡泡** | ✅ | ✅ |
| **浮力泡泡** | ❌ | ✅（或放入泡泡空间） |
| **炸弹泡泡** | ❌ | ✅（或放入泡泡空间） |

## 5.4 引导线

释放时显示**瞄准引导线**（见图三）：

- 从主角发出的虚线
- 末端有落点标记
- 蓄力时线条随泡泡大小变化

## 5.5 操作映射

### 键鼠

| 操作 | 按键 |
|------|------|
| 移动 | WASD |
| 视角 | 鼠标 |

| 释放 | 鼠标右键 |
| 切换泡泡 | 数字键 1-3 / 滚轮 |
| 引爆炸弹 | 专用键（如 F） |

### 手柄

|------|------|

# 七、关卡设计（v1：5 个教学关）

> **v1 目标**：用 5 关教会玩家三种泡泡与蓄力机制。
> 每关**只教一件事**，教完立刻用一次。

## 7.1 总览

| 关 | 名称 | 教学目标 | 新内容 | 情绪 |
|----|------|---------|--------|------|
| 1 | 苏醒 | 理解蓄力释放 | 弹力泡泡 | 茫然 |
| 2 | 相连 | 理解"空间可以创造" | 浮力泡泡 | 温暖 |
| 3 | 爆破 | 理解"远程控制" | 炸弹泡泡 | 好奇 |
| 4 | 组合 | 理解"泡泡可以互相影响" | 三种组合 | 紧张 |
| 5 | 共鸣 | 综合运用 | 全部 | 成就 |

## 7.2 教学关设计原则

**每关遵循"引入 → 练习 → 考核"三段式：**

```
引入   新机制以最纯粹的形式出现，玩家必然遇到
  ↓
练习   在一个安全环境里用 2-3 次
  ↓
考核   组合一次，通过即出关
```

**零文字教学**：全部通过行为反馈完成。

## 7.3 各关详细

### 第 1 关：苏醒

**教学目标**：教会**蓄力释放**与**弹力泡泡**。

```
[玩家] --蓄力--> (泡泡) --右键--> →→→ [障碍]
```

| 阶段 | 内容 |
|------|------|
| 引入 | 前方有障碍，获得弹力泡泡。长按左键蓄力，右键射出 |
| 练习 | 蓄力大小不同，弹射距离不同。让玩家体会"大小 = 强度" |
| 考核 | 用弹力泡泡弹射自己跨过一个缺口 |

**教学点**：**一个输入控制强度**——蓄多久，决定了能做多大事。

### 第 2 关：相连

**教学目标**：教会**浮力泡泡**。

```
[玩家] --放置浮力泡泡--> (○) → 漂浮上去
[玩家] --放置多个--> (○)(○)(○) → 连成桥
```

| 阶段 | 内容 |
|------|------|
| 引入 | 高台够不到。放置浮力泡泡，进入后漂浮上升 |
| 练习 | 多个浮力泡泡连成桥，跨过深渊 |
| 考核 | 用浮力泡泡搭出一条通路 |

**教学点**：**空间可以被创造**。

### 第 3 关：爆破

**教学目标**：教会**炸弹泡泡**与**远程引爆**。

```
[玩家] --放置炸弹--> (●) → 压住开关
[玩家] --按 F 键--> 💥 远程引爆
```

| 阶段 | 内容 |
|------|------|
| 引入 | 开关在远处够不到。放置炸弹泡泡压住它 |
| 练习 | 炸弹泡泡可以远程引爆（⚠️ 一次只能控制一枚） |
| 考核 | 用炸弹炸开障碍，同时用它压住开关 |

**教学点**：**远程控制** + **一次只能一枚**的取舍。

### 第 4 关：组合

**教学目标**：教会**三种泡泡的相互影响**。

```
弹力 + 浮力 = 弹上去，浮住
浮力 + 炸弹 = 炸开后被浮力托起
```

| 阶段 | 内容 |
|------|------|
| 引入 | 一个需要两种泡泡配合的谜题 |
| 练习 | 逐个尝试组合，观察泡泡如何互相影响 |
| 考核 | 一次性用上三种泡泡 |

**教学点**：**泡泡不是孤立的，组合起来才有力量**。

### 第 5 关：共鸣

**教学目标**：综合运用，并引出**泡泡组合**（后续版本）的概念。

| 阶段 | 内容 |
|------|------|
| 引入 | 一个复杂谜题，需要多种组合 |
| 练习 | 分阶段，每阶段考验一种组合 |
| 考核 | 一次性通过完整流程 |

```
2. 泡泡空间系统      —— 空间创建、进入判定、效果

4. 蓄力输入系统      —— 长按蓄力 → 大小 → 强度
5. 瞄准引导线        —— 抛物线预测、落点标记
6. 世界规则引擎      —— 分裂 / 融合 / 膨胀
7. 3D 角色控制       —— 移动、跳跃、相机
8. 关卡/房间管理     —— 房间切换、状态保存
```

## 13.2 P0 关键验证（最高优先级）

**要验证的问题**：

1. **蓄力手感**——长按蓄力是否直觉？大小与强度的对应是否清晰？
2. **泡泡空间**——进入空间、弹射、漂浮的体验是否爽快？
3. **三泡泡组合**——三种泡泡互相影响时，能否产生"我没设计过"的结果？

**不含**：美术、多关卡、存档、完整剧情。
