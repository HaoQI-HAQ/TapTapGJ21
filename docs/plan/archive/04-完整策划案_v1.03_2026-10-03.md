# 一、项目概述

## 1.1 一句话

**在意识之海里拨动泡泡——三条规则让它们自行聚散，拼出你从未设计过的过去。**

## 1.2 定位

| 项 | 内容 |
|----|------|
| 类型 | 叙事解谜 |
| 表现 | 固定房间式 **2.5D 斜俯视** |
| 画风 | 二次元 |
| 平台 | **PC 优先**（键鼠 + 手柄）；移动端仅预留适配方向 |
| 规模 | 5 关 / 5 章节，线性推进 |
| 主题 | 涌现（Emergence） |

## 1.3 核心体验

玩家以为自己在**"打开泡泡、通过关卡"**。

逐渐发现自己在**"拼回一个已经破碎的家"**。

最后明白：**这个故事的结局，正是它的开头。**

## 1.4 主题如何落地

**涌现 = 简单规则 + 个体交互 → 宏观复杂行为。**

```
世界层   泡泡按自身规则涌现        ← 分裂 / 融合 / 膨胀（玩家不能直接控制）
   ↑
玩家层   主角用能力拨动世界        ← 5 种能力（本身也是世界规则的一部分）
```

**关键**：玩家的能力**不是外挂的作弊器，是世界规则的杠杆**。
玩家撬动规则，规则自己演化，玩家看到的是**自己没设计过的结果**。

> **少即是多**：5 个工具 × 3 条规则 × N 种材质 = 玩家无法一次性推演的局面。

# 二、世界观与设定

## 2.1 空间结构

```
┌─────────────────────────────────────┐
│           大泡泡（世界本身）          │
│                                     │
│   ┌──────┐  ┌──────┐  ┌──────┐     │
│   │ 房间 │  │ 房间 │  │ 房间 │ ...  │  ← 意识空间（分裂出的泡泡）
│   └──────┘  └──────┘  └──────┘     │
│                                     │
│   ▓▓▓▓▓▓ 黑色深渊（死亡）▓▓▓▓▓▓     │
└─────────────────────────────────────┘
```

| 概念 | 设定 |
|------|------|
| **大泡泡** | 整个世界。一切都在它内部 |
| **意识空间** | 大泡泡内部分裂出的各个房间 |
| **记忆碎片** | 以泡泡形态存在的记忆 |
| **黑色深渊** | 遗忘与消失的所在。**掉入 = 死亡** |
| **主角** | **意识体**——操控泡泡行动 |

## 2.2 美术统一原则

**一切皆泡泡。**

- 陷阱是泡泡
- 地图主题是泡泡
- **UI 也是泡泡**

玩家目之所及**没有"非泡泡"的元素**。这是视觉上的统一，也是设定上的自洽。

## 2.3 泡泡材质

材质是**关卡差异化的主要手段**——同一套规则，换材质就是新关卡。

| 材质 | 特性 | 玩法含义 |
|------|------|---------|
| **弹性** | 可被弹力大幅拉伸 | 弹跳、远距离移动 |
| **黏性** | 与其他泡泡强吸附 | 搭桥、粘连 |
| **透明** | 可穿透 | 穿过障碍、看见内部 |
| **易碎** | 一碰就裂 | 高风险通道 |
| **坚硬** | 分裂不开 | 需要先软化才能处理 |

# 三、核心规则系统

**只有三条。这是全作的地基，不可轻易增加。**

## 规则 ①：同类相融，异类相斥

同类泡泡靠近自动融合；异类互相推开。

## 规则 ②：扰动则裂

泡泡受到扰动时分裂。

> **玩家的一切操作都是扰动**——所以不需要"分裂键"，你碰它，它就裂。

## 规则 ③：弥散则规则随变

泡泡膨胀时，向四周弥散影响，**改变全场的相吸相斥强度**。

```
膨胀 → 场强变化 → 规则①强弱变化 → 泡泡行为变化 → 场强再变化
        ↑                                              │
        └──────────────────────────────────────────────┘
```

> **这是反馈回路，也是涌现的引擎。**
> **非线性从这里来。玩家无法穷举，就是因为这条回路。**

## 规则之间的关系

```
        ①同类相融
         ↙      ↘
   规则强弱      泡泡行为
         ↖      ↙
        ③弥散（反馈回路）
              ↑
        ②扰动则裂（玩家输入）
```

# 四、玩家能力系统

**五种能力，全部是对三条规则的拨动——不新增独立玩法。**

| 能力 | 拨动哪条规则 | 玩法效果 | 典型用途 |
|------|-------------|---------|---------|
| **黏合** | → 规则①（融合） | 强制两个泡泡融合 | 搭桥、连接 |
| **弹力** | → 规则③（膨胀） | 让泡泡弹性膨胀 | 弹跳、软化硬泡 |
| **延长** | → 规则③（膨胀） | 让泡泡拉长延伸 | 够到远处 |
| **浮空** | → 规则③ 衍生 | 让泡泡上浮 | 形成踏脚石 |
| **重力** | → 规则③ 衍生 | 让泡泡下沉 | 压住机关 |

## 设计要点

- **分裂没有专属能力**——规则②说"扰动则裂"，玩家任何操作都是扰动
- 五种能力不是五套系统，是**同一套规则的五个杠杆**
- **新增能力必须回答："它拨动哪条规则？"** 答不上来就不加

## 能力解锁节奏（v1）

| 关卡 | 解锁 |
|------|------|
| 第 1 关 | （无能力，纯规则） |
| 第 2 关 | 黏合 |
| 第 3 关 | 弹力、延长 |
| 第 4 关 | 浮空、重力 |
| 第 5 关 | 全部综合运用 |

## 能力融合（后续版本方向）

**v1 只做 5 种基础能力。** 后续版本引入**能力融合**。

```
弹力 + 黏合 = ?        （膨胀 + 融合）
浮空 + 延长 = ?        （上浮 + 延伸）
重力 + 弹力 = ?        （下沉 + 膨胀）
```

### 为什么这个方向重要

**涌现原则从世界层延伸到了玩家的工具箱。**

```
v1      5 种能力，玩家逐个学会
  ↓
后续    能力可以互相融合，产生新解法
  ↓
结果    玩家无法穷举所有组合
```

**设计价值**：能力融合是"少即是多"的又一次应用——
不新增能力，靠**组合**产生复杂度。这与核心规则的设计哲学完全一致。

> ⚠️ 融合规则的具体设计待后续版本确定。v1 阶段**只做基础能力**，
> 但要保证能力系统**预留融合接口**（每种能力的效果可叠加、可组合）。

# 五、核心循环

## 5.1 操作循环

```
        分裂
       ↗    ↘
    扰动      融合
       ↖    ↙
        膨胀
```

## 5.2 通关循环

**玩家目标**：让关卡的阻挡物（泡泡）**短暂打开**，然后通过。

```
阻挡泡泡 → 分裂 → 通道出现 → 玩家通过 → 泡泡重新融合闭合
                      ↑
                窗口期有限，必须抓住
```

> **关键**：分裂是**暂时的**，融合会把它合上。
> 这带来时间压力，也让"通过"变成需要判断的决策，而不是无脑操作。

## 5.3 叙事循环

```
空白 → 记忆显现 → 意义理解 → 回归新的空白
  ↑                              │
  └──────────────────────────────┘
```

**总循环**：

```
结构操作 → 新现象 → 记忆显现 → 理解意义 → 世界改变 → 新空白 → 再次操作
```

# 六、关卡设计（v1：5 个教学关）

> **v1 目标**：用 5 关教会玩家全部核心机制。
> 每关**只教一件事**，教完立刻用一次，然后进入下一关。

## 6.1 总览

| 关 | 名称 | 教学目标 | 新机制 | 材质 | 情绪 |
|----|------|---------|--------|------|------|
| 1 | 苏醒 | 理解"碰它，它就裂" | 分裂、融合 | 单一 | 茫然 |
| 2 | 相连 | 理解"关系可以被创造" | 黏合 | 弹性 + 黏性 | 温暖 |
| 3 | 变形 | 理解"材料可以被改变" | 弹力、延长 | 坚硬 + 易碎 | 好奇 |
| 4 | 坠落 | 理解"空间是三维的" | 浮空、重力 | 透明 + 弹性 | 紧张 |
| 5 | 共鸣 | 综合运用全部能力 | 全部组合 | 全部 | 成就 |

## 6.2 教学关设计原则

**每关遵循"引入 → 练习 → 考核"三段式：**

```
引入   新机制以最纯粹的形式出现，玩家必然遇到
  ↓
练习   在一个安全环境里用 2-3 次
  ↓
考核   组合一次，通过即出关
```

**零文字教学**：全部通过行为反馈完成，不弹教程框。

## 6.3 各关详细

### 第 1 关：苏醒

**教学目标**：教会"扰动则裂"（规则②）与"同类相融"（规则①）。

```
[玩家]  →  [泡泡墙]  →  [通路]
              ↑
        碰一下裂开，1.5 秒后合上
```

| 阶段 | 内容 |
|------|------|
| 引入 | 玩家前方是唯一的通路——一堵泡泡墙。撞上去，墙裂开 |
| 练习 | 连续三堵墙，节奏越来越快，玩家学会"要快" |
| 考核 | 两个同类泡泡挡路，玩家推它们靠近 → 自动融合 → 通路出现 |

**教学点**：不需要"分裂键"，**玩家的移动本身就是操作**。

### 第 2 关：相连

**教学目标**：教会**黏合**能力。

```
[玩家] → [两个分离的泡泡] → 黏合 → [桥] → 通过
```

| 阶段 | 内容 |
|------|------|
| 引入 | 两个泡泡相距太远，跳不过去。获得**黏合**能力 |
| 练习 | 黏合两泡泡搭桥；黏住弹性泡泡防止被弹开 |
| 考核 | 三个泡泡需要按顺序黏合，才能形成完整通路 |

**教学点**：玩家第一次理解"**关系可以被创造**"。

### 第 3 关：变形

**教学目标**：教会**弹力**与**延长**。

```
[坚硬泡泡] --弹力软化--> [可分裂] --延长--> 够到远处
```

| 阶段 | 内容 |
|------|------|
| 引入 | 坚硬泡泡分裂不开。获得**弹力**——膨胀后变软，就能分裂 |
| 练习 | 弹力软化 + 分裂的组合；延长够到远处开关 |
| 考核 | 易碎泡泡挡路：碰了就碎，必须用**延长**隔空操作 |

**教学点**：材料不是固定的，**可以被改变**。

### 第 4 关：坠落

**教学目标**：教会**浮空**与**重力**，并引入死亡机制。

```
        [目标]
           ↑
    [泡泡] ← 浮空，形成踏脚石
           ↓
   ▓▓▓ 黑色深渊（掉落即死）▓▓▓
```

| 阶段 | 内容 |
|------|------|
| 引入 | 深渊隔断，过不去。获得**浮空**能力 |
| 练习 | 浮空泡泡形成踏脚石；重力让泡泡下沉压住机关 |
| 考核 | 浮空 + 重力的组合，跨越深渊 |

**教学点**：空间不只是平面，**垂直方向也是解谜维度**。
**死亡机制**：掉入深渊 = 回到本关起点，**不做惩罚性重来**。

### 第 5 关：共鸣

**教学目标**：综合运用全部 5 种能力。

```
[散落的泡泡] → 组合运用 → [通路] → 出关
```

| 阶段 | 内容 |
|------|------|
| 引入 | 一个需要多种能力配合的复合谜题 |
| 练习 | 分阶段，每阶段考验一种能力的组合运用 |
| 考核 | 一次性通过完整流程 |

**教学点**：能力不是孤立的，**组合起来才有力量**。
这也是**能力融合**（后续版本）的预告。

# 七、剧情设计（详细）

> ⚠️ **本章为后续版本目标，v1 不实现。**
>
> v1 的 5 个教学关**只埋伏笔、不讲完整故事**。
> 完整叙事（序破急 + 莫比乌斯结局）在后续版本展开。
>
> 本章保留，作为叙事方向的定稿参考。

## 7.1 情感内核

> **主角是"家"的最后一段记忆。**
> 它必须放弃自己，才能让被留下的人继续活下去。

## 7.2 角色

| 角色 | 身份 | 说明 |
|------|------|------|
| **主角** | 家的记忆（意识体） | 玩家操控。不知道自己是什么 |
| **那个人** | 曾住在这里的人 | 从未出场，通过记忆碎片被拼出 |

> **设计意图**："那个人"**全程不出现**。玩家只能通过记忆碎片拼出他的样子。
> 越是拼不全，越是想拼全——**这就是玩家继续玩的动力**。

## 7.3 序破急

### 序（第 1-2 关）— 温暖

主角在**空白**中醒来。它不知道自己是什么，也不知道这是哪里。

它开始拼合泡泡，逐渐拼出一个**家的轮廓**：
一张床、一扇门、一个窗。

**玩家以为**：这是一个"找回记忆"的温馨故事。

### 破（第 3-4 关）— 崩塌

越拼越发现不对。家的每一处都有**裂痕**。

记忆开始想起碎片：
- 有人离开
- 有人等待
- 家碎了

**玩家意识到**：这不是"找回"，是"面对"。

### 急（第 5 关）— 抉择

主角终于明白：

> **它不肯放手，才让那个人困在这里。**
> 只要它还在，那个人就永远走不出去。

它必须消失。

## 7.4 结局

**玩家亲手让记忆消散。**

```
系统提示：放弃记忆，让它自由
        ↓
玩家按下确认键（唯一的出路）
        ↓
所有泡泡消散
        ↓
空白
```

**最后一句独白**：

> *"忘了我吧。*
> *然后，好好活着。"*

## 7.5 莫比乌斯环

```
第 1 关的开头：一片空白
        ↑                    ↓
   放弃记忆  ←──────  第 5 关的结局
```

**结局 = 开头。**

玩家通关后恍然大悟：

> **原来我一开始看到的空白，就是结局。**

### 更深的解读

这片空白，是**记忆消散后的世界**。

每一次那个人想起家，记忆就会**重新醒来一次**，走一遍这 5 关，然后再消散一次。

**这是一场永远的告别，也是一次次的陪伴。**

> **记忆明知会消散，却依然一次次醒来。**
>
> 这是全作最动人的地方——**不是"不得不放弃"，是"心甘情愿地重来"。**

## 7.6 叙事与玩法的咬合

| 叙事阶段 | 玩法表现 |
|---------|---------|
| 序 | 泡泡干净、明亮、好操作 |
| 破 | 出现裂痕材质、易碎泡泡增多 |
| 急 | 深渊、不稳定、操作变难 |
| 结局 | 所有泡泡消散 |

**叙事不靠文字推进，靠玩法的物理感受推进。**

# 八、记忆涌现系统

## 8.1 核心矛盾

**涌现产出的是「状态」，叙事需要的是「事件」。**

**解法**：造一台翻译机，把状态翻译成事件。

## 8.2 三层判定

```
① 结构约束   硬条件：泡泡数量、分布、位置是否满足      ← 过滤掉不可能的
② 情绪倾向   打分：当前配置"有多像"某段记忆            ← 只打分，不触发
③ 玩家确认   玩家做出动作（触碰 / 停留 / 注入）        ← 只有这一步才触发
```

> **关键在第③层**：系统不因为"看起来像"就发剧情，**必须玩家用行为表态**。

## 8.3 语义走廊

```
严格配方：  只有拼出特定形状才触发
完全开放：  任何沾边的东西都触发  → 剧情漂移
─────────────────────────────────────────
语义走廊：  多种表达都能触发，但必须满足
           「必要条件 + 玩家确认 + 上下文」
```

**设计者控制"什么意义值得被识别"，玩家控制"用什么结构去表达"。**

## 8.4 记忆节点数据结构

| 字段 | 用途 | 示例（休息） |
|------|------|-------------|
| 核心问题 | 要让玩家理解什么？ | 这里有人睡过 |
| 必要条件 | 缺少就绝不成立 | 存在可承托的结构 |
| 支持条件 | 提高显现强度 | 靠墙、封闭、柔软 |
| 确认行为 | 玩家的主动表达 | 停留 3 秒 |
| 记忆反馈 | 残影 / 声音 / 画面 | 墙上浮现人影 |
| 下一问题 | 留下什么新问题 | 这个人后来去哪了？ |

## 8.5 本作需要的语义节点

| 章节 | 语义节点 |
|------|---------|
| 序 | 休息、进出 |
| 破 | 等待、离开 |
| 急 | 坠落、放手 |

# 九、美术设计

## 9.1 风格

| 项 | 内容 |
|----|------|
| 画风 | 二次元 |
| 视角 | 2.5D 斜俯视（固定机位） |
| 统一原则 | **一切皆泡泡** |

## 9.2 色彩

| 阶段 | 主色调 | 情绪 |
|------|--------|------|
| 序 | 暖白、淡黄、浅粉 | 温暖、朦胧 |
| 破 | 冷灰、暗蓝、出现裂纹 | 不安、崩坏 |
| 急 | 深蓝、近乎黑 | 压抑 |
| 结局 | 纯白 | 释然、空白 |

## 9.3 泡泡材质表现

| 材质 | 视觉 | 音效 |
|------|------|------|
| 弹性 | 半透明、高光、可拉伸 | 弹性"啵"声 |
| 黏性 | 表面有黏丝 | 黏腻的拉扯声 |
| 透明 | 几乎不可见，有边缘光 | 极轻的嗡鸣 |
| 易碎 | 有裂纹纹理 | 玻璃碎裂感 |
| 坚硬 | 高反光、厚重 | 沉闷的撞击声 |

## 9.4 记忆反馈表现

**克制原则**：不弹窗、不打断、不用大段文字。

| 反馈类型 | 表现 |
|---------|------|
| 残影 | 墙上浮现半透明人影，数秒后消失 |
| 声音 | 环境音变化，或一句极轻的旁白 |
| 画面 | 色调微变、光晕 |
| 文字 | **最多一句**，出现在画面边缘 |

## 9.5 主角表现

**意识体**：一个发光的核心，被泡泡包裹。

- 移动时拖出淡淡的光尾
- 施放能力时核心闪光
- 接近记忆时微微脉动

# 十、音频设计

## 10.1 音频层次

| 层 | 内容 |
|----|------|
| 环境层 | 水声、气泡声、低频嗡鸣 |
| 交互层 | 分裂、融合、膨胀的音效 |
| 记忆层 | 记忆触发时的音乐变化 |
| 叙事层 | 极少的旁白 |

## 10.2 核心音效

| 事件 | 音效 |
|------|------|
| 泡泡分裂 | 清脆的"啵" |
| 泡泡融合 | 低沉的水泡合并声 |
| 泡泡膨胀 | 拉长的滑音 |
| 泡泡破裂 | 玻璃碎裂 + 水声 |
| 掉入深渊 | 声音被吸入、消失 |
| 记忆显现 | 音乐进入一段温柔旋律 |

## 10.3 音乐设计

| 章节 | 音乐 |
|------|------|
| 序 | 钢琴单音，稀疏、温柔 |
| 破 | 加入低频弦乐，逐渐不和谐 |
| 急 | 弦乐紧张，节奏加快 |
| 结局 | 回到开头的钢琴单音，然后归于静默 |

> **音乐也是莫比乌斯**：结局的音乐 = 开头的音乐。

# 十二、数值设计

## 12.1 泡泡基础参数

| 参数 | 建议值 | 说明 |
|------|--------|------|
| 泡泡半径 | 0.3 - 1.0 米 | 视关卡而定 |
| 分裂数量 | 2 - 4 个 | 一个泡泡分裂后的碎片数 |
| 融合窗口 | 1.5 秒 | 分裂后重新融合的时间 |
| 膨胀倍率 | 1.0 → 1.8 | 最大膨胀 |
| 相吸强度 | 待调 | 规则① |
| 相斥强度 | 待调 | 规则① |
| **弥散系数** | **待调（关键）** | 规则③，**最需要反复测试** |

## 12.2 数值调优优先级

```
1. 弥散系数（规则③）  ← 最高优先级，决定系统是否稳定
2. 相吸/相斥强度（规则①）
3. 融合窗口时长（决定难度）
4. 膨胀倍率
```

> ⚠️ **弥散系数是最大风险点**。反馈回路容易发散成一锅混沌。
> MVP 阶段**只调这一个参数**，用纯色球反复试。

## 12.3 难度曲线

| 关 | 谜题数 | 时间压力 | 死亡风险 |
|----|--------|---------|---------|
| 1 | 3 | 无 | 无 |
| 2 | 3 | 低 | 无 |
| 3 | 3 | 中 | 低 |
| 4 | 3 | 中 | **有**（深渊） |
| 5 | 4 | 高 | 中 |

# 十六、风险与对策

| 风险 | 表现 | 对策 | 优先级 |
|------|------|------|--------|
| **规则③数值发散** | 泡成一锅混沌 | 只调弥散系数，纯色球反复试 | 🔴 最高 |
| **叙事穿帮** | 玩家搅出的对不上文案 | 每条记忆备 2-3 个触发模式；文案最后写 | 🔴 高 |
| **涌现不可读** | 玩家看不懂发生了什么 | 加强反馈，让因果可见 | 🟠 中 |
| **莫比乌斯不成立** | 玩家没有"恍然大悟" | MVP 阶段用占位文本先验证 | 🟠 中 |
| **平台未定** | 阻塞开发 | 尽快确认 Unity 还是 TapMaker | 🔴 高 |
| **2.5D 视角限制** | 垂直玩法难表现 | 第 4 关需重点验证 | 🟡 低 |

# 附录：设计原则

1. **不设计答案，设计规则**——不告诉玩家"怎么过"，只定义世界允许发生什么
2. **自由在表达层，约束在意义层**——玩家随便拼，但剧情不乱触发
3. **机制少而互相咬合**——新增机制必须与至少 2 个旧机制产生组合
4. **反馈优先于文字**——玩家一操作，世界立刻变化，不靠大段教程
5. **不做机制孤岛**——形状、材质、能力必须互相作用，不能各玩各的
6. **叙事靠感受推进**——不靠文字堆砌，靠玩法本身的物理感受
