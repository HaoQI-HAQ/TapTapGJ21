# 一、项目概述

## 1.1 一句话

**在意识之海里吹出泡泡——三种泡泡互相影响、彼此组合，搭出你从未设计过的路。**

## 1.2 定位

| 项 | 内容 |
|----|------|
| 类型 | 关卡解谜 |
| 表现 | **3D** |
| 画风 | 卡通 |
| 平台 | **PC 优先**（键鼠 + 手柄）；移动端仅预留适配方向 |
| 规模 | 5 关，线性推进 |
| 主题 | 涌现（Emergence） |

## 1.3 核心体验

玩家作为**意识体**，用**泡泡**在记忆空间中搭建通路、破解机关。

三种泡泡（弹力 / 浮粘 / 炸弹）**互相影响、彼此组合**——
单独看每一种都很简单，组合起来却能做出玩家自己都没想到的事。

玩家逐渐发现：自己在**重拾一个已经破碎的自我**，
最终**抛却原有的"标签"，得到自我的成长**。

最后明白：**这个故事的结局，正是它的开头。**

## 1.4 主题如何落地

**涌现 = 简单规则 + 个体交互 → 宏观复杂行为。**

**三层结构，两层咬合：**

```
世界层    泡泡之间的物理交互           ← 分裂 / 融合 / 膨胀（玩家不能直接控制）
   ↑
玩家层    主角用三种泡泡能力干预        ← 弹力 / 浮粘 / 炸弹
```

**关键**：玩家的能力**不是外挂的作弊器，而是世界规则的杠杆**。

**三种泡泡互相影响组合** → 这就是本作的涌现来源。

> **少即是多**：3 种泡泡 × 1 个蓄力输入 × N 种材质 = 玩家无法一次性推演的局面。

# 二、世界观与设定

## 2.1 空间结构

```
┌─────────────────────────────────────────┐
│           大泡泡（世界本身）              │
│                                         │
│   ┌──────┐   ┌──────┐   ┌──────┐        │
│   │ 房间 │   │ 房间 │   │ 房间 │  ...   │  ← 意识空间（分裂出的泡泡）
│   └──────┘   └──────┘   └──────┘        │
│                                         │
│   ▓▓▓▓▓▓▓▓ 黑色深渊（死亡）▓▓▓▓▓▓▓▓     │
└─────────────────────────────────────────┘
```

| 概念 | 设定 |
|------|------|
| **大泡泡** | 整个世界。一切都在它内部 |
| **意识空间** | 大泡泡内部分裂出的各个房间 |
| **记忆碎片** | 以泡泡形态存在的记忆 |
| **黑色深渊** | 遗忘与消失的所在。**掉入 = 死亡** |
| **主角** | **意识体**——操控泡泡行动 |

## 2.2 美术统一原则

**一切皆泡泡，但主角是 3D 小人的形象。**

- 陷阱是泡泡
- 地图主题是泡泡
- **UI 也是泡泡**

玩家目之所及**没有"非泡泡"的元素**。

## 2.3 泡泡材质

**材质是关卡差异化的主要手段。**

| 材质 | 特性 | 玩法含义 |
|------|------|---------|
| **易碎** | 一碰就裂 | 高风险通道 |
| **黏性** | 与其他泡泡强吸附 | 搭桥、粘连 |
| **透明** | 可穿透 | 穿过障碍、看见内部 |
| **坚硬** | 分裂不开 | 需要先软化才能处理 |
| **弹性** | 可被弹力大幅拉伸 | 弹跳、远距离移动 |

# 三、核心规则系统（世界层）

> **这一层是泡泡自己的物理法则，玩家不能直接控制——只能通过泡泡能力去拨动。**

## 规则 ①：分裂

泡泡受到扰动时分裂。

> **玩家的一切操作都是扰动**——所以不需要"分裂键"。

## 规则 ②：融合

同类泡泡靠近自动融合。

## 规则 ③：膨胀

泡泡膨胀时，向四周弥散影响，**改变全场的相吸相斥强度**。

> **这是反馈回路，也是涌现的引擎。**
> **非线性从这里来。玩家无法穷举，就是因为这条回路。**

## 规则之间的关系

```
        分裂
       ↗    ↘
    扰动      融合
       ↖    ↙
        膨胀
```

# 四、泡泡能力系统（玩家层）

> **三种泡泡，是玩家拨动世界规则的三种杠杆。**

## 4.1 三种泡泡

### 弹力泡泡

| 项 | 内容 |
|----|------|
| **能力** | 弹出破坏物体 / 创建**弹射泡泡空间** |
| **泡泡空间** | 像三维弹球——把玩家自身**弹射出去** |
| **释放** | **可发射，也可放置** |
| **典型用途** | 破坏障碍、弹射移动、跨越地形 |

### 浮粘泡泡

| 项 | 内容 |
|----|------|
| **能力** | **两种漂浮方式** / 与其他泡泡**粘合成桥** |
| **释放** | 只能放置（或放入泡泡空间） |
| **典型用途** | 上升、搭桥、跨过深渊 |
| **⚠️ 代价** | 两种漂浮都有硬性限制，且**最终都会失去浮粘能力** |

#### 两种漂浮方式

浮粘泡泡提供**两种漂浮**，代价不同——**这是 Z 轴移动的闸门**：

| 方式 | 触发条件 | 持续 | 方向控制 | 结束方式 |
|------|---------|------|---------|---------|
| **蓄力漂浮** | 蓄力时泡泡 **> 角色 2 倍** | **5 秒** | ✅ 可控制方向 | 时间到 → **爆炸** → 落地 |
| **泡泡空间漂浮** | 进入泡泡空间 | **无限** | ❌ **只能向上** | 碰到其他泡泡 → **粘合固定** |

**两种方式的取舍**：

| | 优点 | 代价 | 适合 |
|---|------|------|------|
| **蓄力漂浮** | 可控方向 | 只有 5 秒 | **精确位移** |
| **泡泡空间漂浮** | 时间无限 | 只能向上、终点不可控 | **到达高处** |

### 蓄力漂浮（流程）

![蓄力漂浮流程](images/float-charge.png)

```
手持泡泡 → 蓄力变大 → 包裹角色上浮 → 可控方向移动 → 泡泡消失 → 角色下落
```

| 步骤 | 说明 |
|------|------|
| 1 | 手持泡泡 |
| 2 | 蓄力，泡泡变大 |
| 3 | 泡泡包裹角色，**开始上浮** |
| 4 | **可控方向移动**（前后左右都能调整） |
| 5 | 5 秒到，泡泡消散 |
| 6 | 角色下落 |

> **特点**：全程可控，但时间有限。适合**精确位移**。

### 泡泡空间漂浮（流程）

![泡泡空间漂浮流程](images/float-space.png)

```
手持泡泡 → 放置（人泡分离）→ 进入泡泡空间 → 向上飘 → 到达顶部粘合固定 → 站上去
```

| 步骤 | 说明 |
|------|------|
| 1 | 手持泡泡 |
| 2 | **放置**（人与泡泡分离） |
| 3 | 角色**进入泡泡空间** |
| 4 | 泡泡**向上飘**（角色随之上浮） |
| 5 | 飘到上方结构，**粘合固定** |
| 6 | 角色**站到粘合后的泡泡上** |

> **特点**：时间无限，但**只能向上**、不能主动停。
> **落点由关卡布局决定**——这正是 Z 轴闸门能成立的原因。

#### ⚠️ Z 轴闸门（关卡设计保护）

> **这是本作最重要的关卡约束之一。**

给玩家 Z 轴能力，会破坏所有基于 XY 平面的关卡设计。
**必须加闸门**，否则关卡设计失控。

| 闸门 | 作用 |
|------|------|
| 蓄力漂浮**限时 5 秒** | 飞不远，无法横跨整个关卡 |
| 泡泡空间**只能向上** | 不能自由悬停、不能主动下降 |
| 泡泡空间**靠粘合终止** | 落点由**关卡布局**决定，不由玩家决定 |
| 粘合**不可逆** | 用过就不能改，一次性的承诺 |

**设计意图**：

> 玩家能上 Z 轴，但**每次上升都是一次有去无回的承诺**。
>
> 落点不是"我想去哪就去哪"，而是"**关卡允许我去哪**"。
> 这样 Z 轴就变成了**关卡设计的一部分**，而不是破坏关卡的工具。

#### 终态：粘合

两种漂浮**最终都会进入粘合态**——接触其他泡泡后固定不动，**永久失去浮粘能力**。

| 状态 | 行为 | 用途 |
|------|------|------|
| **漂浮态** | 向上浮（两种方式） | 载玩家上升 |
| **粘合态** | 固定不动，失去浮粘能力 | 连接成桥、锚定位置 |

> **粘合后原地固定**——这意味着**桥可以悬空**，
> 玩家可以用浮粘泡泡在高处搭建通路。

### 炸弹泡泡

| 项 | 内容 |
|----|------|
| **能力** | **爆炸推力** / 压住开关 / **远程按键引爆** |
| **泡泡空间** | — |
| **释放** | 只能放置（或放入泡泡空间） |
| **典型用途** | **改变运动方向**、压机关、爆破障碍 |
| **⚠️ 限制** | **一次只能控制一枚炸弹** + **不可回收** |

#### 爆炸推力：位移工具

**炸弹不只是"破坏"——它产生一个力，能改变运动方向。**

参考《旷野之息》的炸弹：**爆炸把物体/角色推向某个方向**。

```
        爆炸前              爆炸后
          ●                  ↗
         ／                  ●  ← 被推出去
        💥                  ／
       静止              改变方向
```

| 用途 | 说明 |
|------|------|
| **改变方向** | 角色/物体在运动中，被爆炸推向新方向 |
| **加速** | 朝运动方向爆炸，获得额外推力 |
| **制动** | 反向爆炸，减速或停下 |
| **弹射** | 与弹力泡泡组合，形成**二次弹射** |

> **设计价值**：这让炸弹从"一次性道具"变成了**空中控制手段**。
>
> 玩家在跳跃/飞行途中引爆，可以**实时修正轨迹**——
> 这打开了大量空间玩法，也是"三种泡泡组合"的关键一环。

> ⚠️ 爆炸推力**对玩家自身也生效**（这是它能当位移工具的前提）。
> 需要确认：是否会对玩家造成伤害？（见待确认项）

## 4.2 三种泡泡的相互影响

**这是本作涌现的核心来源。**

```
弹力 × 浮粘 = 弹上去，浮住
弹力 × 炸弹 = 弹射出去，空中爆炸二次修正方向
浮粘 × 炸弹 = 炸开后被浮粘托起
三种组合   = 见 4.4 组合玩法举例
```

> 单独看每种泡泡都很简单，**组合起来玩家无法穷举**。

### 浮粘泡泡的粘合是"接触即触发"

**浮粘泡泡与任何泡泡接触，就会粘合并失去浮粘能力**——这个判定是**自动的**，不需要玩家按键。

```
浮粘泡泡  ──接触──→  弹力泡泡 / 炸弹泡泡 / 另一个浮粘泡泡
                          ↓
                    自动粘合，固定不动，失去浮粘能力
```

**这意味着玩家必须小心摆放**：

| 想要的效果 | 必须避免 |
|-----------|---------|
| 让它浮上去 | 别让它碰到别的泡泡 |
| 让它粘成桥 | 主动让它接触 |

> **设计价值**：这条规则让"摆放位置"本身成为解谜的一部分。
> 玩家不能无脑乱放——**一次误触就永久改变了这个泡泡的性质**。

**涌现示例**：
- 浮粘泡泡粘住弹力泡泡 → 弹力泡泡被"锚定"在原地，成为稳定的弹射点
- 浮粘泡泡粘住炸弹泡泡 → 炸弹被固定住，可以精确控制爆炸位置
- 多个浮粘泡泡互相粘合 → 形成一条**悬空的桥**

### 粘合是 Z 轴的"着陆机制"

**泡泡空间漂浮只能向上，玩家无法主动停止**——
**粘合就是唯一的刹车**。

```
泡泡空间漂浮中  →  碰到泡泡  →  粘合固定  →  玩家站在这里
      ↑                                          ↓
   只能向上                                这就是落点
```

> **这条规则把"落点决定权"从玩家交给了关卡设计者。**
>
> 玩家能选择"什么时候上升"，但**不能选择"在哪里停"**——
> 停在哪里，取决于关卡的泡泡布局。
>
> 这正是 Z 轴闸门能成立的原因：**上升是自由的，落点是被设计的。**

> ⚠️ 粘合是**不可逆**的。这带来决策压力，也让"误操作"产生后果。

## 4.3 泡泡空间

**三种泡泡都能创建泡泡空间**——这是统一的底层机制。

![泡泡空间（蓝）](images/bubble-space-blue.png)
![泡泡空间（橙）](images/bubble-space-orange.png)

| 项 | 内容 |
|----|------|
| **形态** | 半透明球体，有边缘光晕，内部可见 |
| **颜色** | 按泡泡类型区分（弹力 / 浮粘 / 炸弹） |
| **作用** | 进入后获得对应效果 |
| **入口** | 玩家走进去，或泡泡包裹玩家 |

**设计要点**：三种泡泡共享"创建空间"这一底层机制，
**不是三套独立系统**——这保证了机制的咬合。

## 4.4 组合玩法举例

> ⚠️ **本节只举一个例子，不是全部解法。**
> 目的是说明"三种泡泡组合"能产生什么，而不是穷举玩法。

### 示例：三段式空中弹射

**用三种泡泡组合，把角色送上原本到不了的高处。**

```
① 浮粘泡泡        ② 弹力泡泡          ③ 炸弹泡泡
   连接成平台        弹射出去             空中二次弹射
                                                    ↗
   (○)-(○)    →     ↗  ●  →→→    →     💥 ●
                     ／                  修正方向
```

| 步骤 | 用哪个泡泡 | 做什么 |
|------|-----------|--------|
| ① | **浮粘泡泡** | 两个浮粘泡泡粘合，在高处搭一个**落脚平台** |
| ② | **弹力泡泡** | 站在平台上，用弹力泡泡**把自己弹射出去** |
| ③ | **炸弹泡泡** | 在空中引爆，**二次修正方向**，落到更远/更高的地方 |

**关键点**：

- ① 浮粘泡泡提供**起点高度**（Z 轴闸门 → 靠粘合固定）
- ② 弹力泡泡提供**初始速度**（弹射）
- ③ 炸弹泡泡提供**空中修正**（爆炸推力改变方向）

> **三段缺一不可**——这正是"组合产生复杂度"的体现。
>
> 玩家不是学会了三个工具，而是学会了**把它们串起来**。

### 为什么这个例子重要

它展示了本作的核心设计意图：

| 单独看 | 组合起来 |
|--------|---------|
| 浮粘 = 搭桥 | 浮粘 + 弹力 + 炸弹 = **到达任意位置** |
| 弹力 = 弹跳 | |
| 炸弹 = 破坏 | |

> **玩家无法一次性穷举**——因为组合数远大于机制数。
> 这就是"少即是多"。

> 💡 **关卡设计提示**：这个例子可以作为**第 4 关（组合）**的核心谜题。
> 但不要直接教"三段式"——让玩家自己摸索出这条链。

# 五、输入与释放

## 5.1 蓄力释放

```
左键长按蓄力 → 泡泡变大 → 右键释放
```

![发射引导线](images/aim-line.png)

| 步骤 | 操作 | 效果 |
|------|------|------|
| 1 | **左键长按** | 开始蓄力，泡泡逐渐变大 |
| 2 | 蓄力中 | 泡泡越大 → **能力强度越高** |
| 3 | **右键** | 释放出去 |

## 5.2 大小决定强度

**一个输入维度，同时控制三件事：**

```
长按越久 → 泡泡越大 → 能力越强
```

| 泡泡 | 越大则 |
|------|--------|
| 弹力 | 弹得越远 / 破坏力越强 |
| 浮粘 | 浮粘越大 / 空间越大 |
| 炸弹 | 爆炸范围越大 |

> **玩家每一次点击都在做一个连续的权衡**——蓄多久？
> 这是"少即是多"的又一次应用：**一个输入，三种能力，无限组合**。

### ⚠️ 浮粘泡泡的阈值：2 倍体积

**浮粘泡泡有一个关键阈值**——蓄力时泡泡 **大于角色 2 倍**，才能带角色漂浮。

```
蓄力不足 2 倍  →  泡泡太小，托不起角色  →  只能放置
蓄力超过 2 倍  →  可以带角色漂浮 5 秒  →  可控方向
```

> **这是"大小决定强度"最直接的一次体现**：
> 蓄力不够，连"能用"都做不到——**不是强弱问题，是能不能的问题**。
>
> 玩家会自然地学会："浮粘泡泡要蓄满"。

## 5.3 释放方式

# 六、泡泡值系统

> **玩家的核心资源。** 所有泡泡能力都从这里支出。

## 6.1 什么是泡泡值

**泡泡值 = 玩家能使用泡泡能力的总量。**

| 项 | 内容 |
|----|------|
| 作用 | 限制玩家能施放多少泡泡 |
| 消耗 | **蓄力也等比消耗**——蓄得越久，花得越多 |
| 上限 | 待定（见待确认项） |

**核心规则**：

```
蓄力越久 → 泡泡越大 → 强度越高 → 消耗越多
```

> **蓄力不再是"免费的权衡"，而是"有代价的投资"。**

## 6.2 三种泡泡的回收差异

**这是泡泡值系统最重要的设计点。**

| 泡泡 | 消耗 | 回收 | 策略含义 |
|------|------|------|---------|
| **弹力泡泡** | ✅ | ✅ **可回收** | 可以先大手大脚，再收回 |
| **浮粘泡泡** | ✅ | ✅ **可回收** | 可以先大手大脚，再收回 |
| **炸弹泡泡** | ✅ | ❌ **不可回收** | **用一次少一次** |

```
弹力 / 浮粘    →  用掉 → 可以收回 → 资源可循环
炸弹          →  用掉 → 永久消失 → 资源单向消耗
```

## 6.3 这个设计带来了什么

### ① 给"蓄力"加了成本

| 之前 | 现在 |
|------|------|
| 蓄力 = 大小 = 强度 | 蓄力 = 大小 = 强度 = **消耗** |

**玩家多了一个判断维度**：这个场合值不值得蓄满？

### ② 三种泡泡产生了策略分层

| 泡泡 | 玩家心态 |
|------|---------|
| 弹力 / 浮粘 | "先试试，不行再收回来" |
| 炸弹 | "**想清楚再放**——放错了就没了" |

> **同一个资源系统，让三种泡泡有了不同的"心理重量"。**
> 弹力/浮粘是铅笔（可以擦掉重来），炸弹是钢笔（一笔定生死）。

### ③ 与"炸弹一次只能一枚"形成双重限制

炸弹泡泡**既不可回收，又同时只能存在一枚**——这给它加了两道枷锁。

> 玩家会自然地珍视炸弹，把它当作"关键时刻的底牌"，
> 而不是随手就用的普通工具。

## 6.4 回收机制（待细化）

| 问题 | 现状 |
|------|------|
| 怎么回收？ | 待定——靠近收回？按键收回？泡泡自动返回？ |
| 回收时泡泡值全退还是打折？ | 待定 |
| 粘合态还能回收吗？ | 待定（粘合后已固定） |

> ⚠️ **回收方式直接影响手感**，需要尽早确定。
> 建议：**靠近自动回收**最直观，不增加操作负担。

## 6.5 UI 表现

| 元素 | 表现 |
|------|------|
| 泡泡值条 | 屏幕边缘，泡泡形态（符合"一切皆泡泡"） |
| 蓄力消耗预览 | 蓄力时高亮显示将要消耗的量 |
| 不可回收提示 | 切换到炸弹时，泡泡值条变为"红色/警告色" |

> **设计要点**：让玩家**随时看得见**自己的资源，
> 尤其是切换到炸弹时，要立刻感知到"这个不能回收"。

# 八、关卡设计（v1：5 个教学关）

> **v1 目标**：用 5 关教会玩家三种泡泡与蓄力机制。
> 每关**只教一件事**，教完立刻用一次。

## 8.1 总览

| 关 | 名称 | 教学目标 | 新内容 | 情绪 |
|----|------|---------|--------|------|
| 1 | 苏醒 | 理解蓄力释放 | 弹力泡泡 | 茫然 |
| 2 | 相连 | 理解"空间可以创造" | 浮粘泡泡 | 温暖 |
| 3 | 爆破 | 理解"远程控制" | 炸弹泡泡 | 好奇 |
| 4 | 组合 | 理解"泡泡可以互相影响" | 三种组合 | 紧张 |
| 5 | 共鸣 | 综合运用 | 全部 | 成就 |

## 8.2 教学关设计原则

**每关遵循"引入 → 练习 → 考核"三段式：**

```
引入   新机制以最纯粹的形式出现，玩家必然遇到
  ↓
练习   在一个安全环境里用 2-3 次
  ↓
考核   组合一次，通过即出关
```

**零文字教学**：全部通过行为反馈完成。

## 8.3 各关详细

### 第 1 关：苏醒

**教学目标**：教会**蓄力释放**与**弹力泡泡**。

```
[玩家] --蓄力--> (泡泡) --右键--> →→→ [障碍]
```

| 阶段 | 内容 |
|------|------|
| 引入 | 前方有障碍，获得弹力泡泡。长按左键蓄力，右键射出 |
| 练习 | 蓄力大小不同，弹射距离不同。让玩家体会"大小 = 强度" |
| 考核 | 用弹力泡泡弹射自己跨过一个缺口 |

**教学点**：**一个输入控制强度**——蓄多久，决定了能做多大事。

### 第 2 关：相连

**教学目标**：教会**浮粘泡泡的两种漂浮**，以及**粘合取舍**。

```
蓄力漂浮      可控方向，5 秒      ← 教"精确位移"
   ↓
泡泡空间漂浮   只能向上，无限时    ← 教"到达高处"
   ↓
碰到泡泡     粘合固定            ← 教"落点由关卡决定"
```

| 阶段 | 内容 |
|------|------|
| 引入 | 一个矮台够不到。**蓄力漂浮**——蓄满泡泡，带自己飞过去（体验 5 秒限时） |
| 练习 | 一个高台**蓄力飞不到**。改用**泡泡空间漂浮**——进入后一直向上，直到碰到顶部的泡泡**粘合停住** |
| 考核 | 需要先粘合一个泡泡当"着陆点"，再用泡泡空间漂上去 |

**教学点**：
1. **两种漂浮各有代价**——一个可控但短暂，一个持久但只能向上
2. **落点由关卡决定**——玩家不能随意停，必须找"能停的地方"
3. **粘合是刹车**——想停，就得有泡泡接着

> **教学顺序很关键**：先让玩家体验"可控但短暂"（引入），
> 再让他遇到"够不到"的困境，**被迫**尝试泡泡空间（练习）。
>
> 不弹提示，让玩家自己撞上限制——**限制本身就是教学**。

> **关卡设计要点**：本关的泡泡布局决定玩家能停在哪。
> 必须保证"能停的地方"是唯一解或少数解，否则 Z 轴失控。

### 第 3 关：爆破

**教学目标**：教会**炸弹泡泡**与**远程引爆**。

```
[玩家] --放置炸弹--> (●) → 压住开关
[玩家] --按 F 键--> 💥 远程引爆
```

| 阶段 | 内容 |
|------|------|
| 引入 | 开关在远处够不到。放置炸弹泡泡压住它 |
| 练习 | 炸弹泡泡可以远程引爆（⚠️ 一次只能控制一枚） |
| 考核 | 用炸弹炸开障碍，同时用它压住开关 |

**教学点**：**远程控制** + **一次只能一枚**的取舍。

### 第 4 关：组合

**教学目标**：教会**三种泡泡的相互影响**。

```
弹力 + 浮粘 = 弹上去，浮住
浮粘 + 炸弹 = 炸开后被浮粘托起
```

| 阶段 | 内容 |
|------|------|
| 引入 | 一个需要两种泡泡配合的谜题 |
| 练习 | 逐个尝试组合，观察泡泡如何互相影响 |
| 考核 | 一次性用上三种泡泡 |

**教学点**：**泡泡不是孤立的，组合起来才有力量**。

### 第 5 关：共鸣

**教学目标**：综合运用，并引出**泡泡组合**（后续版本）的概念。

| 阶段 | 内容 |
|------|------|
| 引入 | 一个复杂谜题，需要多种组合 |
| 练习 | 分阶段，每阶段考验一种组合 |
| 考核 | 一次性通过完整流程 |

**不含**：美术、多关卡、存档、完整剧情。

| 5 | 泡泡值耗尽时怎么办？**如何恢复**？ | 决定是否会卡死——必须有兜底 |
