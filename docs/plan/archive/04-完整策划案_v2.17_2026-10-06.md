# 一、项目概述

## 1.1 一句话

**在意识之海里吹出泡泡——三种泡泡互相影响、彼此组合，搭出你从未设计过的路。**

## 1.2 定位

| 项 | 内容 |
|----|------|
| 类型 | 关卡解谜 |
| 表现 | **3D 箱庭**（斜俯视，固定机位） |
| 画风 | **手绘厚涂** |
| 配色 | **粉紫基调 + 水青**（参考明日方舟·火山旅梦，详见 §10.2） |
| 场景 | 第 1 关纯白空间；**第 2 关起为海洋水下/水底**（珊瑚等元素） |
| 主角 | **蓝色水母**（游戏内）+ **人形立绘**（剧情/宣传） |
| 平台 | **PC 优先**（键鼠 + 手柄）；移动端仅预留适配方向 |
| 规模 | 5 关（1-3 教学 / 4-5 正式），线性推进 |
| 主题 | 涌现（Emergence） |

## 1.3 核心体验

玩家作为**意识体**，用**泡泡**在记忆空间中搭建通路、破解机关。

三种泡泡（弹力 / 浮粘 / 炸弹）**互相影响、彼此组合**——
单独看每一种都很简单，组合起来却能做出玩家自己都没想到的事。

玩家逐渐发现：自己在**重拾一个已经破碎的自我**，
最终**抛却原有的"标签"，得到自我的成长**。

最后明白：**这个故事的结局，正是它的开头。**

## 1.4 主题如何落地

**涌现 = 简单规则 + 个体交互 → 宏观复杂行为。**

**三层结构，两层咬合：**

```
世界层    泡泡之间的物理交互           ← 分裂 / 融合 / 膨胀（玩家不能直接控制）
   ↑
玩家层    主角用三种泡泡能力干预        ← 弹力 / 浮粘 / 炸弹
```

**关键**：玩家的能力**不是外挂的作弊器，而是世界规则的杠杆**。

**三种泡泡互相影响组合** → 这就是本作的涌现来源。

> **少即是多**：3 种泡泡 × 1 个蓄力输入 × N 种材质 = 玩家无法一次性推演的局面。

# 二、世界观与设定

## 2.1 空间结构

```
┌─────────────────────────────────────────┐
│           大泡泡（世界本身）              │
│                                         │
│   ┌──────┐   ┌──────┐   ┌──────┐        │
│   │ 房间 │   │ 房间 │   │ 房间 │  ...   │  ← 意识空间（分裂出的泡泡）
│   └──────┘   └──────┘   └──────┘        │
│                                         │
│   ▓▓▓▓▓▓▓▓ 黑色深渊（死亡）▓▓▓▓▓▓▓▓     │
└─────────────────────────────────────────┘
```

| 概念 | 设定 |
|------|------|
| **大泡泡** | 整个世界。一切都在它内部 |
| **意识空间** | 大泡泡内部分裂出的各个房间——**以箱庭形式呈现**（见 10.2.2） |
| **场景演进** | 第 1 关为纯白空间；**第 2 关起进入海洋水下**——珊瑚、海草、水泡 |
| **记忆碎片** | 以泡泡形态存在的记忆 |
| **黑色深渊** | 遗忘与消失的所在。**掉入 = 死亡** |
| **主角** | **意识体**——操控泡泡行动 |

## 2.2 美术统一原则

**一切皆泡泡，但主角是 3D 小人的形象。**

- 陷阱是泡泡
- 地图主题是泡泡
- **UI 也是泡泡**

玩家目之所及**没有"非泡泡"的元素**。

## 2.3 泡泡材质

**材质是关卡差异化的主要手段。**

### 玩家泡泡的材质

| 材质 | 特性 | 玩法含义 |
|------|------|---------|
| **易碎** | 一碰就裂 | 高风险通道 |
| **黏性** | 与其他泡泡强吸附 | 搭桥、粘连 |
| **透明** | 可穿透 | 穿过障碍、看见内部 |
| **坚硬** | 分裂不开 | 需要先软化才能处理 |
| **弹性** | 可被弹力大幅拉伸 | 弹跳、远距离移动 |

### 场景墙体的材质

> ⚠️ **不同功能的墙用不同配色**——配色表见 [10.2 色彩](#102-色彩)。

| 材质 | 配色 | 玩法 |
|------|------|------|
| **普通墙** | 云粉 `#F5C6D8` | 可破坏，会愈合（最常见） |
| **不可破坏墙** | 雾紫 `#B48BC4` | 无法破坏，关卡边界 |
| **弹性墙** | 水青 `#7ED4D4` | 可弹跳、可穿过 |
| **爆炸墙** | 暖橙 `#FFB87C` | 触碰会爆炸 |
| **脆弱墙** | 珊瑚 `#FF9E9E` | 一碰就碎，不愈合 |
| **虚空/深渊** | 夜紫 `#4A3F6B` | 掉入即死 |

**视觉规则**：

```
浅色（云粉）  →  可破坏，"轻"
深色（雾紫）  →  不可破坏，"重"
暖色（橙/珊瑚）→  危险，需谨慎
```

> **玩家不需要教程——看颜色就知道这面墙能不能碰。**

# 三、核心规则系统（世界层）

> **这一层是泡泡自己的物理法则，玩家不能直接控制——只能通过泡泡能力去拨动。**
>
> ⚠️ **本章是 v2.12 重点重写章节**——三条规则从"抽象法则"升级为**玩家能看见的物理过程**。

## 3.0 场景可破坏：世界是一整块泡泡

**参考《咚奇刚：蕉力全开》的破坏玩法。**

```
┌─────────────────────────┐
│  █████████████████████  │  ← 天花板（可破坏）
│                         │
│  ███   玩家   ███       │  ← 墙壁（可破坏）
│                         │
│  █████████████████████  │  ← 地面（可破坏）
└─────────────────────────┘
```

**场景（墙壁、天花板、地面）本身就是泡泡构成的**——它们不是静态碰撞体，而是**可以被破坏、也会自己愈合的活体物质**。

| 破坏方式 | 结果 |
|---------|------|
| **弹力泡泡** | **暂时破坏**——过一段时间会恢复 |
| **炸弹泡泡** | **永久破坏**——不再恢复 |

> **设计价值**：
> 玩家不是在"解一道固定的谜题"，而是在**改造一个活的场景**。
> 每一关的场景都是**可塑的**，但塑形有代价。

---

## 3.1 规则 ①：分裂

泡泡受到扰动时分裂。

> **玩家的一切操作都是扰动**——所以不需要"分裂键"。

**在场景破坏中的体现**：

```
    ████          ██  ██
    ████   ──→    ██  ██
    ████          ██  ██
   完整墙体        分裂成小块
```

墙体被击中后**分裂成若干小块**——这是恢复的第一步。

---

## 3.2 规则 ②：融合

同类泡泡靠近自动融合。

**在场景恢复中的体现**：

```
    ██  ██
    ██  ██   ──→   ██████
    ██  ██         ██████
   分散的小块       重新融合
```

**这是"愈合"的关键一步**——分散的泡泡重新聚合成完整墙体。

---

## 3.3 规则 ③：膨胀

泡泡膨胀时，向四周弥散影响，**改变全场的相吸相斥强度**。

> **这是反馈回路，也是涌现的引擎。**
> **非线性从这里来。玩家无法穷举，就是因为这条回路。**

**在场景恢复中的体现**：

```
    ██  ██
    ██  ██   ──→   ██████   ← 膨胀，填满空隙
    ██  ██         ██████
   有缺口          完全填满
```

**膨胀负责"填缝"**——让分裂开的泡泡能够重新贴合，不留空隙。

---

## 3.4 恢复机制：不是重置，是愈合

> ⚠️ **这是本章最重要的设计点。**

### 恢复的三个步骤

```
破坏后的墙体
     ↓  ① 分裂
  小块散开
     ↓  ② 膨胀
  向外弥散，填补空隙
     ↓  ③ 融合
  重新结合成完整墙体
     ↓
   恢复完成
```

**关键**：恢复**不是**"时间到了，墙自己变回来"，
**而是旁边的泡泡自己执行了「分裂 → 膨胀 → 融合」三个动作，把缺口补上**。

> **这就是"愈合"，不是"重置"。**
>
> 它让三条规则从**设定文字**，变成了**玩家看得见的物理过程**。

### 两种破坏，两种后果

| 破坏源 | 机制 | 恢复 | 设计意图 |
|--------|------|------|---------|
| **弹力泡泡** | 物理冲击 | ✅ **会恢复**（周围泡泡愈合） | 低风险，鼓励实验 |
| **炸弹泡泡** | 彻底消灭 | ❌ **永久破坏** | 高风险，改变关卡 |

```
弹力破坏  →  墙碎了 → 旁边泡泡愈合 → 墙回来    （可逆）
炸弹破坏  →  墙没了 → 没有泡泡能愈合 → 永久空洞  （不可逆）
```

> **为什么炸弹是永久的？**
>
> 因为炸弹**彻底消灭了那部分泡泡**——周围没有足够的泡泡来"愈合"它。
>
> 这不是规则强加的限制，而是**规则自然推导出的结果**。

### 这个设计带来了什么

| 效果 | 说明 |
|------|------|
| **降低挫败** | 弹力破坏可恢复 → 玩家敢试错 |
| **制造决策** | 炸弹破坏不可逆 → 用之前要想清楚 |
| **主题契合** | "愈合"呼应"记忆可以重新拼合" |
| **规则可见** | 玩家**亲眼看到**三条规则在工作 |

---

### 💡 涌现玩法：人为制造不可逆的洞

**愈合依赖"周围有泡泡"**——这个前提本身就是一个可被玩家利用的机制。

```
① 先用炸弹清空周围的泡泡
        ↓
② 再用弹力泡泡破坏中间的墙
        ↓
③ 周围没有泡泡可以愈合它
        ↓
   弹力破坏，却产生了永久空洞
```

**这是纯粹的涌现结果**——规则里没有写"弹力破坏也能永久"，但**两条规则交叉作用，自然产生了这个结果**。

| 效果 | 说明 |
|------|------|
| **玩家自主性** | 玩家自己发现了"规则之外"的解法 |
| **组合深度** | 炸弹 + 弹力 = 一个设计者没写死的效果 |
| **符合主题** | 简单规则交叉 → 产生超出预期的结果 |

> ⚠️ **关卡设计提示**：
> 这意味着**任何用弹力破坏就能通过的地方，玩家都可能用炸弹"焊死"**。
> 设计关卡时要考虑：**这会不会让关卡变得不可解？**
>
> 建议：关键通路的关键部分，用**炸弹也炸不掉**的材质保护。

### ⚠️ 愈合参数（待程序调优）

| 参数 | 状态 |
|------|------|
| **愈合开始时间** | 🟡 程序暂定 |
| **愈合速度** | 🟡 程序暂定 |
| **是否受泡泡大小影响** | 🟡 程序暂定 |

> 这三个参数**直接影响关卡节奏**，需要在 P0 阶段用灰盒反复测试。
> 详见 [十三、技术架构] 与 [十四、开发计划]。

## 3.5 三条规则的关系

```
        分裂 ①
       ↗      ↘
    扰动         融合 ②
       ↖      ↙
        膨胀 ③
          ↑
      恢复循环
```

**三条规则不只作用于玩家的泡泡，也作用于整个场景。**

| 场景 | 规则如何体现 |
|------|-------------|
| **破坏** | ① 分裂——墙体裂成小块 |
| **恢复** | ①分裂 → ③膨胀 → ②融合——完整的愈合链 |
| **不可逆** | 炸弹消灭了泡泡，① ② ③ 都无法执行 |

> 💡 **玩家不需要读规则说明**——他们破坏一面墙，看着它自己长回来，
> 就**理解了全部三条规则**。

# 四、泡泡能力系统（玩家层）

> **三种泡泡，是玩家拨动世界规则的三种杠杆。**

## 4.1 三种泡泡

### 弹力泡泡

| 项 | 内容 |
|----|------|
| **能力** | 弹出破坏物体 / 创建**弹射泡泡空间** |
| **泡泡空间** | 像三维弹球——把玩家自身**弹射出去** |
| **释放** | **可发射，也可放置** |
| **典型用途** | 破坏障碍、弹射移动、跨越地形 |

### 浮粘泡泡

| 项 | 内容 |
|----|------|
| **能力** | **两种漂浮方式** / 与其他泡泡**粘合成桥** |
| **释放** | 只能放置（或放入泡泡空间） |
| **典型用途** | 上升、搭桥、跨过深渊 |
| **⚠️ 代价** | 两种漂浮都有硬性限制，且**最终都会失去浮粘能力** |

#### 两种漂浮方式

浮粘泡泡提供**两种漂浮**，代价不同——**这是 Z 轴移动的闸门**：

| 方式 | 触发条件 | 持续 | 方向控制 | 结束方式 |
|------|---------|------|---------|---------|
| **蓄力漂浮** | 蓄力时泡泡 **> 角色 2 倍** | **5 秒** | ✅ 可控制方向 | 时间到 → **爆炸** → 落地 |
| **泡泡空间漂浮** | 进入泡泡空间 | **无限** | ❌ **只能向上** | 碰到其他泡泡 → **粘合固定** |

**两种方式的取舍**：

| | 优点 | 代价 | 适合 |
|---|------|------|------|
| **蓄力漂浮** | 可控方向 | 只有 5 秒 | **精确位移** |
| **泡泡空间漂浮** | 时间无限 | 只能向上、终点不可控 | **到达高处** |

### 蓄力漂浮（流程）

![蓄力漂浮流程](images/float-charge.png)

```
手持泡泡 → 蓄力变大 → 包裹角色上浮 → 可控方向移动 → 泡泡消失 → 角色下落
```

| 步骤 | 说明 |
|------|------|
| 1 | 手持泡泡 |
| 2 | 蓄力，泡泡变大 |
| 3 | 泡泡包裹角色，**开始上浮** |
| 4 | **可控方向移动**（前后左右都能调整） |
| 5 | 5 秒到，泡泡消散 |
| 6 | 角色下落 |

> **特点**：全程可控，但时间有限。适合**精确位移**。

### 泡泡空间漂浮（流程）

![泡泡空间漂浮流程](images/float-space.png)

```
手持泡泡 → 放置（人泡分离）→ 进入泡泡空间 → 向上飘 → 到达顶部粘合固定 → 站上去
```

| 步骤 | 说明 |
|------|------|
| 1 | 手持泡泡 |
| 2 | **放置**（人与泡泡分离） |
| 3 | 角色**进入泡泡空间** |
| 4 | 泡泡**向上飘**（角色随之上浮） |
| 5 | 飘到上方结构，**粘合固定** |
| 6 | 角色**站到粘合后的泡泡上** |

> **特点**：时间无限，但**只能向上**、不能主动停。
> **落点由关卡布局决定**——这正是 Z 轴闸门能成立的原因。

#### ⚠️ Z 轴闸门（关卡设计保护）

> **这是本作最重要的关卡约束之一。**

给玩家 Z 轴能力，会破坏所有基于 XY 平面的关卡设计。
**必须加闸门**，否则关卡设计失控。

| 闸门 | 作用 |
|------|------|
| 蓄力漂浮**限时 5 秒** | 飞不远，无法横跨整个关卡 |
| 泡泡空间**只能向上** | 不能自由悬停、不能主动下降 |
| 泡泡空间**靠粘合终止** | 落点由**关卡布局**决定，不由玩家决定 |
| 粘合**不可逆** | 用过就不能改，一次性的承诺 |

**设计意图**：

> 玩家能上 Z 轴，但**每次上升都是一次有去无回的承诺**。
>
> 落点不是"我想去哪就去哪"，而是"**关卡允许我去哪**"。
> 这样 Z 轴就变成了**关卡设计的一部分**，而不是破坏关卡的工具。

#### 终态：粘合

两种漂浮**最终都会进入粘合态**——接触其他泡泡后固定不动，**永久失去浮粘能力**。

| 状态 | 行为 | 用途 |
|------|------|------|
| **漂浮态** | 向上浮（两种方式） | 载玩家上升 |
| **粘合态** | 固定不动，失去浮粘能力 | 连接成桥、锚定位置 |

> **粘合后原地固定**——这意味着**桥可以悬空**，
> 玩家可以用浮粘泡泡在高处搭建通路。

### 炸弹泡泡

| 项 | 内容 |
|----|------|
| **能力** | **爆炸推力** / 压住开关 / **远程按键引爆** |
| **泡泡空间** | — |
| **释放** | 只能放置（或放入泡泡空间） |
| **典型用途** | **改变运动方向**、压机关、爆破障碍 |
| **⚠️ 限制** | **一次只能控制一枚炸弹** + **不可回收** |

#### 爆炸推力：位移工具

**炸弹不只是"破坏"——它产生一个力，能改变运动方向。**

参考《旷野之息》的炸弹：**爆炸把物体/角色推向某个方向**。

```
        爆炸前              爆炸后
          ●                  ↗
         ／                  ●  ← 被推出去
        💥                  ／
       静止              改变方向
```

| 用途 | 说明 |
|------|------|
| **改变方向** | 角色/物体在运动中，被爆炸推向新方向 |
| **加速** | 朝运动方向爆炸，获得额外推力 |
| **制动** | 反向爆炸，减速或停下 |
| **弹射** | 与弹力泡泡组合，形成**二次弹射** |

> **设计价值**：这让炸弹从"一次性道具"变成了**空中控制手段**。
>
> 玩家在跳跃/飞行途中引爆，可以**实时修正轨迹**——
> 这打开了大量空间玩法，也是"三种泡泡组合"的关键一环。

> ⚠️ 爆炸推力**对玩家自身也生效**（这是它能当位移工具的前提）。
> 需要确认：是否会对玩家造成伤害？（见待确认项）

## 4.2 三种泡泡的相互影响

**这是本作涌现的核心来源。**

```
弹力 × 浮粘 = 弹上去，浮住
弹力 × 炸弹 = 弹射出去，空中爆炸二次修正方向
浮粘 × 炸弹 = 炸开后被浮粘托起
三种组合   = 见 4.4 组合玩法举例
```

> 单独看每种泡泡都很简单，**组合起来玩家无法穷举**。

### 浮粘泡泡的粘合是"接触即触发"

**浮粘泡泡与任何泡泡接触，就会粘合并失去浮粘能力**——这个判定是**自动的**，不需要玩家按键。

```
浮粘泡泡  ──接触──→  弹力泡泡 / 炸弹泡泡 / 另一个浮粘泡泡
                          ↓
                    自动粘合，固定不动，失去浮粘能力
```

**这意味着玩家必须小心摆放**：

| 想要的效果 | 必须避免 |
|-----------|---------|
| 让它浮上去 | 别让它碰到别的泡泡 |
| 让它粘成桥 | 主动让它接触 |

> **设计价值**：这条规则让"摆放位置"本身成为解谜的一部分。
> 玩家不能无脑乱放——**一次误触就永久改变了这个泡泡的性质**。

**涌现示例**：
- 浮粘泡泡粘住弹力泡泡 → 弹力泡泡被"锚定"在原地，成为稳定的弹射点
- 浮粘泡泡粘住炸弹泡泡 → 炸弹被固定住，可以精确控制爆炸位置
- 多个浮粘泡泡互相粘合 → 形成一条**悬空的桥**

### 粘合是 Z 轴的"着陆机制"

**泡泡空间漂浮只能向上，玩家无法主动停止**——
**粘合就是唯一的刹车**。

```
泡泡空间漂浮中  →  碰到泡泡  →  粘合固定  →  玩家站在这里
      ↑                                          ↓
   只能向上                                这就是落点
```

> **这条规则把"落点决定权"从玩家交给了关卡设计者。**
>
> 玩家能选择"什么时候上升"，但**不能选择"在哪里停"**——
> 停在哪里，取决于关卡的泡泡布局。
>
> 这正是 Z 轴闸门能成立的原因：**上升是自由的，落点是被设计的。**

> ⚠️ 粘合是**不可逆**的。这带来决策压力，也让"误操作"产生后果。

## 4.3 泡泡空间

**三种泡泡都能创建泡泡空间**——这是统一的底层机制。

![泡泡空间（蓝）](images/bubble-space-blue.png)
![泡泡空间（橙）](images/bubble-space-orange.png)

| 项 | 内容 |
|----|------|
| **形态** | 半透明球体，有边缘光晕，内部可见 |
| **颜色** | 按泡泡类型区分（弹力 / 浮粘 / 炸弹） |
| **作用** | 进入后获得对应效果 |
| **入口** | 玩家走进去，或泡泡包裹玩家 |

**设计要点**：三种泡泡共享"创建空间"这一底层机制，
**不是三套独立系统**——这保证了机制的咬合。

## 4.4 组合玩法举例

> ⚠️ **本节只举一个例子，不是全部解法。**
> 目的是说明"三种泡泡组合"能产生什么，而不是穷举玩法。

### 示例：三段式空中弹射

**用三种泡泡组合，把角色送上原本到不了的高处。**

```
① 浮粘泡泡        ② 弹力泡泡          ③ 炸弹泡泡
   连接成平台        弹射出去             空中二次弹射
                                                    ↗
   (○)-(○)    →     ↗  ●  →→→    →     💥 ●
                     ／                  修正方向
```

| 步骤 | 用哪个泡泡 | 做什么 |
|------|-----------|--------|
| ① | **浮粘泡泡** | 两个浮粘泡泡粘合，在高处搭一个**落脚平台** |
| ② | **弹力泡泡** | 站在平台上，用弹力泡泡**把自己弹射出去** |
| ③ | **炸弹泡泡** | 在空中引爆，**二次修正方向**，落到更远/更高的地方 |

**关键点**：

- ① 浮粘泡泡提供**起点高度**（Z 轴闸门 → 靠粘合固定）
- ② 弹力泡泡提供**初始速度**（弹射）
- ③ 炸弹泡泡提供**空中修正**（爆炸推力改变方向）

> **三段缺一不可**——这正是"组合产生复杂度"的体现。
>
> 玩家不是学会了三个工具，而是学会了**把它们串起来**。

### 为什么这个例子重要

它展示了本作的核心设计意图：

| 单独看 | 组合起来 |
|--------|---------|
| 浮粘 = 搭桥 | 浮粘 + 弹力 + 炸弹 = **到达任意位置** |
| 弹力 = 弹跳 | |
| 炸弹 = 破坏 | |

> **玩家无法一次性穷举**——因为组合数远大于机制数。
> 这就是"少即是多"。

> 💡 **关卡设计提示**：这个例子可以作为**第 4 关（组合）**的核心谜题。
> 但不要直接教"三段式"——让玩家自己摸索出这条链。

# 五、输入与释放

## 5.1 蓄力释放

```
左键长按蓄力 → 泡泡变大 → 右键释放
```

![发射引导线](images/aim-line.png)

| 步骤 | 操作 | 效果 |
|------|------|------|
| 1 | **左键长按** | 开始蓄力，泡泡逐渐变大 |
| 2 | 蓄力中 | 泡泡越大 → **能力强度越高** |
| 3 | **右键** | 释放出去 |

## 5.2 大小决定强度

**一个输入维度，同时控制三件事：**

```
长按越久 → 泡泡越大 → 能力越强
```

| 泡泡 | 越大则 |
|------|--------|
| 弹力 | 弹得越远 / 破坏力越强 |
| 浮粘 | 浮粘越大 / 空间越大 |
| 炸弹 | 爆炸范围越大 |

> **玩家每一次点击都在做一个连续的权衡**——蓄多久？
> 这是"少即是多"的又一次应用：**一个输入，三种能力，无限组合**。

### ⚠️ 浮粘泡泡的阈值：2 倍体积

**浮粘泡泡有一个关键阈值**——蓄力时泡泡 **大于角色 2 倍**，才能带角色漂浮。

```
蓄力不足 2 倍  →  泡泡太小，托不起角色  →  只能放置
蓄力超过 2 倍  →  可以带角色漂浮 5 秒  →  可控方向
```

> **这是"大小决定强度"最直接的一次体现**：
> 蓄力不够，连"能用"都做不到——**不是强弱问题，是能不能的问题**。
>
> 玩家会自然地学会："浮粘泡泡要蓄满"。

|------|--------|--------|

| **炸弹泡泡** | ❌ | ✅（或放入泡泡空间） |

# 六、泡泡值系统

> **玩家的核心资源。** 所有泡泡能力都从这里支出。

## 6.1 什么是泡泡值

**泡泡值 = 玩家能使用泡泡能力的总量。**

| 项 | 内容 |
|----|------|
| 作用 | 限制玩家能施放多少泡泡 |
| 消耗 | **蓄力也等比消耗**——蓄得越久，花得越多 |
| 上限 | 待定（见待确认项） |

**核心规则**：

```
蓄力越久 → 泡泡越大 → 强度越高 → 消耗越多
```

> **蓄力不再是"免费的权衡"，而是"有代价的投资"。**

## 6.2 三种泡泡的回收差异

**这是泡泡值系统最重要的设计点。**

| 泡泡 | 消耗 | 回收 | 恢复 | 策略含义 |
|------|------|------|------|---------|
| **弹力泡泡** | ✅ | ✅ **可回收** | — | 可以先大手大脚，再收回 |
| **浮粘泡泡** | ✅ | ✅ **可回收** | — | 可以先大手大脚，再收回 |
| **炸弹泡泡** | ✅ | ❌ **不可回收** | ✅ **随时间缓慢回复** | **要付出时间成本** |

```
弹力 / 浮粘    →  用掉 → 可以收回 → 资源可循环
炸弹          →  用掉 → 不可收回 → 但会缓慢自然回复
```

> **⚠️ 炸弹泡泡的"缓慢回复"是防卡死机制**（详见 8.6）：
> 不可回收意味着用一点少一点，但**随时间缓慢回复**保证了
> 玩家**不会因为资源耗尽而永久卡死**——只是要付出等待的时间成本。
>
> **这比"完全不恢复"更安全，比"可回收"更有分量。**

## 6.3 这个设计带来了什么

### ① 给"蓄力"加了成本

| 之前 | 现在 |
|------|------|
| 蓄力 = 大小 = 强度 | 蓄力 = 大小 = 强度 = **消耗** |

**玩家多了一个判断维度**：这个场合值不值得蓄满？

### ② 三种泡泡产生了策略分层

| 泡泡 | 玩家心态 |
|------|---------|
| 弹力 / 浮粘 | "先试试，不行再收回来" |
| 炸弹 | "**想清楚再放**——放错了就没了" |

> **同一个资源系统，让三种泡泡有了不同的"心理重量"。**
> 弹力/浮粘是铅笔（可以擦掉重来），炸弹是钢笔（一笔定生死）。

### ③ 与"炸弹一次只能一枚"形成双重限制

炸弹泡泡**既不可回收，又同时只能存在一枚**——这给它加了两道枷锁。

> 玩家会自然地珍视炸弹，把它当作"关键时刻的底牌"，
> 而不是随手就用的普通工具。

## 6.4 回收机制（待细化）

| 问题 | 现状 |
|------|------|
| 怎么回收？ | 待定——靠近收回？按键收回？泡泡自动返回？ |
| 回收时泡泡值全退还是打折？ | 待定 |
| 粘合态还能回收吗？ | 待定（粘合后已固定） |

> ⚠️ **回收方式直接影响手感**，需要尽早确定。
> 建议：**靠近自动回收**最直观，不增加操作负担。

## 6.5 UI 表现

| 元素 | 表现 |
|------|------|
| 泡泡值条 | 屏幕边缘，泡泡形态（符合"一切皆泡泡"） |
| 蓄力消耗预览 | 蓄力时高亮显示将要消耗的量 |
| 不可回收提示 | 切换到炸弹时，泡泡值条变为"红色/警告色" |

> **设计要点**：让玩家**随时看得见**自己的资源，
> 尤其是切换到炸弹时，要立刻感知到"这个不能回收"。

## 8.2 世界基础：粉色泡泡

**粉色泡泡是关卡的基本材料**——它同时是障碍物，也是玩家的建造材料。

| 属性 | 说明 |
|------|------|
| **可破坏** | 被弹力泡泡击中即碎（**暂时**）；被炸弹击中则**永久** |
| **会愈合** | 被弹力破坏后，周围泡泡**分裂→膨胀→融合**，把缺口补上 |
| **可回收** | 玩家发射的泡泡可以回收泡泡液 |

> **恢复机制的设计价值**：
> 它让关卡**永远可解**——玩家不会因为炸错一个泡泡而卡死。
> 但同时，恢复是**有时间成本的**，所以玩家仍要为鲁莽付出代价。

> ⚠️ **恢复的准确说法是"愈合"**——详见 3.4。
> 不是"时间到了墙自己变回来"，而是**周围的泡泡自己流回去把缺口补上**。
>
> **玩家能亲眼看到这个过程**，从而理解三条规则。

### ⚠️ 关键设定：弹力泡泡 = 粉色泡泡的「前置泡泡」

```
粉色泡泡（环境材料）  ←──  弹力泡泡（玩家发射的）
       ↑                          │
       └──────────────────────────┘
              本质是同一种东西
```

**弹力泡泡是粉色泡泡的"前置形态"**——玩家发射的弹力泡泡，本质上就是在**就地制造粉色泡泡**。

**这个设定的价值**：

| 效果 | 说明 |
|------|------|
| **工具即材料** | 玩家不是在"使用工具"，而是在"构建世界" |
| **降低认知负担** | 不需要学两套东西，发射出去的泡泡就是场景里的泡泡 |
| **主题契合** | 呼应"记忆碎片可以重新拼合" |

> 💡 玩家最终会意识到：**自己一直在用记忆本身，重新搭建记忆。**

## 8.3 教学关设计原则

**每关遵循"引入 → 练习 → 考核"三段式：**

```
引入   新机制以最纯粹的形式出现，玩家必然遇到
  ↓
练习   在一个安全环境里用 2-3 次
  ↓
考核   组合一次，通过即出关
```

**零文字教学**：全部通过行为反馈完成。

## 8.4 第 1 关：弹力

**教学目标**：蓄力释放 → 破坏 → 资源回收 → 理解"泡泡即材料"

### 环境

| 项 | 说明 |
|----|------|
| 主色调 | **白色为主**，干净、空旷 |
| 可交互物 | **少量类型**——主要是**粉色泡泡（墙）** |
| 粉色泡泡 | 过一段时间**会自动恢复** |
| 特殊物件 | **诞生主角的泡泡体**——最初的地点（存档点） |

> **设计意图**：白色 + 少量元素，让玩家**没有干扰地**理解核心机制。

### 引导流程

| # | 阶段 | 内容 |
|---|------|------|
| 1 | **限制行动** | 玩家**被限制行动**，固定视角。破坏面前的第一个粉色泡泡后，**获得自由移动能力** |
| 2 | **资源意识** | 破坏一定数量泡泡后，提示：**泡泡液有限**，需要**回收**前面发射的泡泡 |
| 3 | **蓄力机制** | 学会**蓄力**——蓄多久，泡泡多大，效果多强 |
| 4 | **材料认知** | 弹力泡泡能破坏粉色泡泡，**但它自己也是粉色泡泡的前置形态**——是构建世界的材料 |

### 关键教学点

```
① 破坏 → ② 发现资源有限 → ③ 学会回收 → ④ 理解"我发的是材料"
```

> **教学顺序的巧思**：
> 先让玩家**挥霍**（破坏很爽），再让他**意识到有限**，最后**学会回收**。
>
> 不是一上来就教"节约"，而是让玩家**自己撞上资源墙**。

## 8.5 第 2 关：黏合（浮粘）

**教学目标**：理解"泡泡可以拼成结构" → 跨越空洞 → 浮粘泡泡的包裹飞行

### 环境

| 项 | 说明 |
|----|------|
| 核心障碍 | **一片巨大的空洞**——通往下一个记忆空间的必经之路 |
| 顶部 | **黏合泡泡群**——可以粘住泡泡的固定点 |
| 背景 | 玩家可以**窥见记忆泡泡世界的部分景观** |

> **设计意图**：空洞提供**动机**（必须过去），顶部泡泡群提供**解法**（粘在那里）。

### 引导流程

| # | 阶段 | 内容 |
|---|------|------|
| 1 | **拼接连通** | 明确：**泡泡之间可以拼接成泡泡连接体**——这是玩家**自己制作的通关工具** |
| 2 | **跨越空洞** | 玩家需要跨过空洞。**掉进空洞会返回房间初始点** |
| 3 | **包裹飞行** | 浮粘泡泡到**一定大小**可以**包裹玩家飞行** |

### 关键教学点

> **"自己制作通关工具"** 是本关的核心体验。
>
> 前两关的递进：
> - 第 1 关：学会**发射**泡泡
> - 第 2 关：学会**组合**泡泡 → 从"使用工具"变成"制造工具"

**死亡机制**：掉入空洞 = 返回本关起点，**不做惩罚性重来**。

## 8.6 第 3 关：爆炸

**教学目标**：物理组合 → 资源永久消耗 → 可控爆炸

### 环境

| 项 | 说明 |
|----|------|
| 动态元素 | **大量定向移动的泡泡实体** |
| 危险 | **会爆炸的泡泡陷阱**——会把玩家**推向空洞** |

> **设计意图**：引入**动态威胁**，玩家不能再静态地思考，必须**预判运动**。

### 引导流程

| # | 阶段 | 内容 |
|---|------|------|
| 1 | **物理组合** | 玩家（会飞）开始利用泡泡之间的**组合**，搭建独特效果——主要是**物理表现** |
| 2 | **资源规则** | 爆炸泡泡的爆炸会**永久消耗**泡泡液 → **爆炸泡泡不可回收**，但**会随时间缓慢回复** |
| 3 | **质量差异** | 爆炸泡泡**有很大的质量**，结合其它泡泡**可能把玩家甩飞** |
| 4 | **可控爆炸** | 爆炸泡泡是玩家**可控的**爆炸 |
| 5 | **力度与大小** | 爆炸提供**向外的力**，**力度取决于泡泡大小** |

### 关键教学点

**资源系统的完整闭环**（本关补全）：

| 泡泡 | 回收 | 恢复 |
|------|------|------|
| 弹力 / 浮粘 | ✅ 可回收 | — |
| **爆炸** | ❌ 不可回收 | **随时间缓慢回复** |

> **这个设计解决了"卡死"风险**：
> 爆炸泡泡虽然不可回收，但**会缓慢回复**——
> 玩家不会因为用光爆炸泡泡而永远卡住，但**要付出时间成本**。

**物理玩法**：爆炸泡泡的**质量**是一个新维度——它不只是推力，还是**配重**。

### 主色板

**核心三色：粉 / 紫 / 青**——粉紫为基调，青为对比。

| 色名 | 色号 | 环境用途 | **泡泡墙用途** |
|------|------|---------|---------------|
| **云粉** | `#F5C6D8` | 天空、光晕、氛围 | **普通可破坏墙**——最常见的基础墙体 |

| **暖橙** | `#FFB87C` | 暖光、火光、强调点 | **爆炸墙**——会爆炸的危险泡泡 |

| **云白** | `#FAF6F8` | 呼吸空间、高光 | **未激活 / 空状态** |

### 泡泡墙材质配色表

> ⚠️ **不同功能的墙用不同配色**——玩家一眼就能判断这是什么墙。

| 材质 | 主色 | 色号 | 特征 | 玩法 |
|------|------|------|------|------|
| **普通墙** | 云粉 | `#F5C6D8` | 半透明粉，柔和 | **可破坏**，会愈合 |
| **不可破坏墙** | 雾紫 | `#B48BC4` | 深紫，厚重感 | **无法破坏**，关卡边界 |
| **弹性墙** | 水青 | `#7ED4D4` | 半透明青，有弹性 | 可弹跳、可穿过 |
| **爆炸墙** | 暖橙 | `#FFB87C` | 橙色，有脉动感 | 靠近/触碰会爆炸 |
| **脆弱墙** | 珊瑚 | `#FF9E9E` | 浅珊瑚色，有裂纹 | 一碰就碎，不愈合 |
| **虚空/深渊** | 夜紫 | `#4A3F6B` | 近黑紫，无底感 | 掉入即死 |

**配色逻辑**：

```
冷色（粉/紫/青）  →  安全、可交互
暖色（橙/珊瑚）    →  危险、需谨慎
深浅变化           →  可破坏 vs 不可破坏
```

> **设计要点**：
> - **可破坏的墙用浅色**（云粉）——视觉上"轻"
> - **不可破坏的墙用深色**（雾紫）——视觉上"重"
> - **危险物用暖色**（暖橙、珊瑚）——与冷色基调形成警示对比
>
> 玩家不需要教程，**看颜色就知道这面墙能不能碰**。

### 吐泡泡的表情差分

![角色表情差分表](images/character-expression-chart.png)

**蓄力与不蓄力，表情完全不同**——这是给玩家的**即时反馈**。

| 泡泡 | 不蓄力 | 蓄力 |
|------|--------|------|
| **弹力** | 轻松嘟嘴吹小泡泡，开心 | 腮帮鼓到极限，眼睛紧闭，身体后仰 |
| **浮粘** | 温柔吐气，眼神迷离放松 | 憋到脸变紫红，眼睛瞪大凸出，搞怪 |
| **炸弹** | 小心翼翼，抿嘴紧张，冒汗 | 夸张惊恐又兴奋，张嘴瞪眼 |

**设计意图**：

| 作用 | 说明 |
|------|------|
| **即时反馈** | 玩家一看表情就知道"蓄了多少" |
| **角色塑造** | 搞怪表情让角色有性格，不只是工具 |
| **降低认知负担** | 不用看 UI，看角色脸就知道状态 |

> 💡 **表情本身就是 UI**——符合"零文字教学"原则。
> 玩家不需要读条，**看角色表情就知道蓄力进度**。

# 十四、开发计划

## 14.1 里程碑

| 阶段 | 目标 | 出口标准 |
|------|------|---------|
| **P0 概念验证** | 证明泡泡手感好玩 | 蓄力释放 + 泡泡空间可玩 |
| **P1 垂直切片** | 证明一关成立 | 第 1 关完整可玩 |
| **P2 内容生产** | 5 关完成 | 全部关卡 |
| **P3 打磨** | 手感、美术、音频 | 可发布 |

## 14.2 P0 关键验证（最高优先级）

**要验证的问题**：

1. **蓄力手感**——长按蓄力是否直觉？大小与强度的对应是否清晰？
2. **泡泡空间**——进入空间、弹射、漂浮的体验是否爽快？
3. **三泡泡组合**——三种泡泡互相影响时，能否产生"我没设计过"的结果？
4. **浮粘泡泡的粘合取舍**——玩家能否理解"碰了就浮不起来"？这个取舍是有趣还是烦躁？

**不含**：美术、多关卡、存档、完整剧情。
