### 排期执行口径（v2.25 / v2.26）

- 统称**泡泡体**；粉色泡泡（墙）是可破坏、会恢复障碍；诞生泡泡体 = 初始存档。文案使用弹力泡泡、浮力泡泡、黏合能力、爆炸泡泡、泡泡液；“浮粘”只保留为既有图稿/资产名别名，“泡泡值”只为旧 UI 数值名，不改图片路径。
- 泡泡液有限：回收普通已发射泡泡返还液体；爆炸泡泡不可回收，爆炸消耗不返还，但随时间慢回复。资源归零仅资源不足/受限，仍可回收存量普通泡泡或等待爆炸消耗慢回复，不是死亡、不是只能/强制重开。
- 前三关白色为主、少量交互类型，可窥见记忆世界；旧粉紫水下参考保留远景及第 4/5 关方向，不作为第 2/3 关房间主色定案。美术预算沿用 06 现有清单，新增反馈以复用/补状态实现，不编新预算数值。
- 教学遵循**限制行动 → 玩家操作 → 反馈 → 命名 → 自由**，行为反馈优先，允许简短命名。第 1 关固定视角限制移动，破坏第一粉色泡泡解除移动限制；破坏一定数量后提示液有限/回收前面普通泡泡，再教蓄力；弹力既是工具，也是粉色泡泡前置材料。
- 第 2 关巨大空洞/顶部黏合群，拼连接体自制通关工具；落入空洞返回房间初始点；浮力泡泡达到大小阈值包裹飞行。第 3 关已有飞行，定向移动泡泡/爆炸陷阱推向空洞，组合物理、大质量惯性甩飞、可控爆炸，向外力 = f(大小)。
- 主角形象按 v2.26 重设：半透明蓝色果冻水母、**6 条触手**、头戴式大耳机（橙色涂装），旧储液罐不再制作；建模、材质与动画任务以 06 §5 为准，泡泡液承载方式待 D10 确认。
- 泡泡潮旧方案及对应任务保留为**后置扩展**，不是第三关必验收；不得先于核心教学加时间压力。未定数值/操作与旧候选见 7.1，确认前只做可调整验证，不以旧值作验收门槛。

| **第 1 关：04 §8.4** | 固定视角限制移动；弹力破坏第一粉色泡泡后解锁自由移动；粉色障碍会恢复；破坏一定数量后提示泡泡液有限并实际回收前面普通泡泡；随后玩家独立完成蓄力并辨认效果差异，理解弹力既是工具，也是粉色泡泡前置材料 | 粉色恢复时间、回收教学触发数量、蓄力时间/力度曲线 TBD，不用旧固定数值 |

| **第 3 关：04 §8.6** | 已有飞行基础上，定向移动泡泡/爆炸陷阱推向空洞；玩家利用爆炸向外力与组合实际完成移动或解谜；理解爆炸不可回收消耗缓慢回复及力 = f(大小)；大质量惯性甩飞与陷阱反馈可读 | 力大小曲线、爆炸触发操作 TBD；2 倍/5 秒/单枚/F 引爆仅旧候选；泡泡潮非必验收 |
| **有限泡泡液：04 §6** | 普通已发射泡泡回收返液；爆炸泡泡不可回收，爆炸消耗不返还但随时间慢回复；回收动作/液回流、即时消耗、慢回复能区分，粉色障碍恢复不返液 | 液上限/回收效率/爆炸消耗量/慢回复速率 TBD；“破坏回复”仅待确认旧候选 |
| **资源受限与失败：04 §15** | 归零只资源不足/受限，可回收存量普通泡泡或等爆炸消耗慢回复，不能只有重开；诞生泡泡体 = 初始存档；空洞返回房间初始点、仍可重试；UI 不暗示永久死亡，主动重开仅可选 | 返回点精确位置/重置范围 TBD，不擅自全清空或满液；旧软死亡/永久破坏不作通过标准 |

**回归要求**：分别覆盖普通存量可回收、只有爆炸消耗需等待、混合消耗、低液/归零、尝试回收爆炸泡泡、障碍恢复与回收返液区分、空洞返回等状态；验证对应反馈和恢复途径，不以“按 R 重开成功”替代资源闭环验收。未定参数由原负责人按 7.1 确认，保留可调整记录。
