## 二、关键路径

> **程序的核心循环跑通前，其他人都只能做"占位"或"设计"。**

```
洛琪希(主程) 核心循环
    │
    ├──→ 十六夜(工具) 存档/设置/SDK
    ├──→ 氫箐滁濋(UI) UI 逻辑接入
    └──→ 文杰(关卡) 关卡可搭建

油菜花(主美) 美术风格定稿
    │
    ├──→ 风笑(模型) 角色/场景/道具
    └──→ 氫箐滁濋(动画) 动画/特效
```

**⚠️ 关键路径 = 洛琪希 → 文杰 → 全员验收**

> **第 5 天是第一个硬节点**——核心循环跑不通，后面全盘延期。

## 七、协作机制

### 每日站会（15 分钟）

| 问题 | 目的 |
|------|------|
| 昨天做了什么？ | 进度透明 |
| 今天做什么？ | 计划明确 |
| **有什么阻塞？** | **立即解决** |

### 验收机制

```
策划定义 → 程序实现 → 美术表现 → 三方共同体验验证 → 迭代
```

**每个机制必须走完这个闭环才能进入正式内容。**

### 三条铁律

1. **先验证机制，再扩充内容**——新系统没证明价值前，不进入大规模制作
2. **先灰盒，再精美**——程序先验证规则，美术再投入
3. **不允许机制孤岛**——新系统必须与至少 2 个既有系统产生关系
