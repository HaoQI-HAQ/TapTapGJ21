# 玩法设计

> **版本 v2.27** ｜ 2026-10-11 ｜ 与 [04-完整策划案.md](04-完整策划案.md) 同步
>
> 本文档为**玩法速览**——完整设计见 04。本次同步术语、通用规则、资源系统与前三关验收；参数与补充设计对照 04 §15、05 的 T01–T09 / D01–D10。

## 一、一句话

**在意识之海里拨动泡泡——三条规则让它们自行聚散，拼出你从未设计过的过去。**

玩家以为自己在“打开泡泡、通过关卡”，
最后发现自己在“拼回一个已经破碎的家”，
而这个故事的结局，正好是它的开头。

### 术语与本版边界

| 术语 | 本版口径 |
|------|----------|
| **泡泡体** | 可交互泡泡的统称 |
| **粉色泡泡（墙）** | 主要障碍物；被破坏后会按时间恢复，具体时间 TBD（T01） |
| **诞生泡泡体** | 主角诞生点，也是最初的存档点 |
| **泡泡液** | 玩家资源；玩家可用量有限，每个泡泡体内的量也有限 |
| **回收** | 回收前面已发射的普通泡泡，将其中的泡泡液返还玩家；不是“破坏回复” |
| **泡泡连接体** | 通过黏合等方式拼成的结构，是玩家自制通关工具 |
| **前置泡泡** | 构建、生成或转化其他泡泡的基础材料形态；弹力泡泡是粉色泡泡的前置材料 |

**旧称对照**：“泡泡值”仅为泡泡液资源数值的旧称；“炸弹泡泡”改称**爆炸泡泡**；“浮粘泡泡”改用**浮力泡泡 / 黏合能力**表述。能力仍为三类：弹力、浮力/黏合、爆炸，不新增第四种能力。

**本版与旧稿冲突时，以前三关新规范为准。** 旧数值、飞行限制和扩展机制保留在下文明确标记的旧候选区，不作为本次必验收要求。

## 二、主题如何落地

**涌现 = 简单规则 + 个体交互 → 宏观复杂行为。**

**三层结构**（前两层咬合）：

```
世界层    泡泡之间的物理法则          ← 分裂 / 融合 / 膨胀（玩家不能直接控制）
   ↑
玩家层    主角用三类泡泡能力拨动        ← 弹力 / 浮力与黏合 / 爆炸
   ↑
叙事层    语义节点 + 记忆反馈          ← 把玩法结果翻译成故事
```

**关键**：玩家的能力**不是外挂的作弊器，是世界规则的杠杆**。

> **少即是多**：3 类泡泡能力 × 1 个蓄力输入 × N 种材质 = 玩家无法一次性推演的局面。

## 三、世界层规则（三条）

| 规则 | 内容 |
|------|------|
| **① 分裂** | 泡泡受到扰动时分裂——玩家的操作拨动世界规则 |
| **② 融合** | 同类泡泡靠近自动融合；不等于已定案的“所有黏合接触即触发且不可逆” |
| **③ 膨胀** | 膨胀时向四周弥散，**改变全场的相吸相斥强度** |

> **规则③是反馈回路，也是涌现的引擎**——非线性从这里来。

**本次确认**：粉色泡泡墙是可破坏障碍，会按时间恢复。既有“分裂 → 膨胀 → 融合”的愈合表现方向保留；恢复时间与过程参数不得自行填数值。

**旧扩展方案待确认（D05）**：墙壁、天花板、地面都可破坏；弹力破坏靠周围泡泡愈合，爆炸破坏永久；先爆炸清空周围再用弹力制造永久空洞。这些适用范围尚未确认，不覆盖本版粉色泡泡墙恢复规则。

## 四、玩家层能力（三类）

| 泡泡 | 本版能力 | 资源规则 |
|------|----------|----------|
| **弹力** | 破坏物体 / 弹射自己；也是粉色泡泡的前置材料 | 普通泡泡可回收，返还已发射泡泡中的泡泡液 |
| **浮力 / 黏合** | 拼成连接体、搭建工具；浮力泡泡够大时包裹玩家飞行 | 普通泡泡可回收；黏合态的回收细节 TBD（D01） |
| **爆炸** | 大质量与惯性参与组合，可能甩飞玩家；玩家可控爆炸，提供向外力，力与大小相关 | 不可回收；爆炸产生不可回收消耗，该部分随时间缓慢恢复，**不是永久损失** |

**蓄力**：持续操作 → 泡泡变大 → 效果变化。蓄力时间/力度曲线 TBD（T03）；爆炸向外力的大小曲线 TBD（T08）。资源消耗曲线另行确认（D09），不能把旧线性消耗候选当成力度曲线。

**旧操作候选保留**：左键长按蓄力、右键释放；弹力可发射/放置，浮力与爆炸只能放置；爆炸压开关/远程引爆。回收具体操作/范围、飞行控制和引爆具体操作仍 TBD（D01–D03），不借旧键位定案。

> **一个输入维度连接大小、效果与成本**；具体曲线未定，不假设三者等比增长。

## 五、核心循环

```
        分裂
       ↗    ↘
    扰动      融合
       ↖    ↙
        膨胀
```

**通关循环**：让阻挡的粉色泡泡墙**短暂打开** → 通过 → 障碍按时间恢复。

**资源循环**：发射普通泡泡 → 形成工具/通路 → 回收其中的泡泡液 → 再使用；爆炸泡泡不可回收，其爆炸消耗随时间慢恢复。

> **暂时打开的通路带来时机判断**；场景恢复与玩家资源恢复是两件事，不能混写成“破坏即可补液”。

## 六、关卡结构与前三关验收

**通用教学节奏**：**限制行动 → 玩家操作 → 系统反馈 → 机制命名 → 解锁自由**。允许反馈后给简短命名提示，不用长篇说明代替实际操作。

**共同视觉约束**：前三关以**白色为主**，少量可交互泡泡类型；可以窥见记忆泡泡世界的景观。旧粉紫水下、珊瑚等方向保留为远景/第 4–5 关候选，不再把“第 2 关起粉紫水下”作为第 2–3 关主色定案。

| 关 | 类型 | 主题与方向 |
|----|------|------------|
| 1 | 教学 | 弹力：限制移动 → 破坏 → 有限与回收 → 蓄力 → 前置材料 |
| 2 | 教学 | 黏合 / 浮力：拼接工具 → 跨空洞 → 包裹飞行 |
| 3 | 教学 | 爆炸：动态危险 → 组合物理 → 大质量惯性 → 可控爆炸 |
| 4 | 正式 | 组合：三类能力综合运用，具体设计待细化（D07） |
| 5 | 正式 | 共鸣：综合机制与叙事收束，具体设计待细化（D07） |

### 第 1 关：弹力（对应 04 §8.4）

1. **固定视角并限制移动**；主角从诞生泡泡体开始，它是最初的存档点。
2. 玩家破坏面前**第一个粉色泡泡**，收到反馈后**解锁自由移动**。
3. 破坏一定数量后，引导认识泡泡液有限，并**回收前面已发射的普通泡泡**，看到泡泡液返还。触发破坏数量 TBD（T02），不是教“破坏更多场景泡泡来回复”。
4. 在有限与回收之后教**蓄力**：操作时长、泡泡大小与效果的关系可见；参数 TBD（T03）。
5. 理解**弹力泡泡是粉色泡泡的前置材料**，不只是破坏工具；转化细节 TBD（D04）。

**验收重点**：首个破坏确实解锁移动；资源提示能引导实际回收并返液；玩家独立完成蓄力并辨认效果差异，理解弹力是粉色泡泡的前置材料；蓄力不抢在回收教学前，粉色泡泡墙按时间恢复。

### 第 2 关：黏合 / 浮力（对应 04 §8.5）

1. 用**空洞**制造通行需求，顶部布置**黏合泡泡群**；在白色教学空间之外可窥见记忆景观。
2. 引导把泡泡拼接成**泡泡连接体**，由玩家自制通关工具，而不是只领用固定桥。
3. 跨越空洞；掉入后**返回房间初始点**。精确返回位置与重置范围 TBD（T09），不自动等同整关清空。
4. 浮力泡泡达到一定大小后**包裹玩家飞行**；大小阈值 TBD（T05），飞行控制/限时/退出与黏合规则 TBD（D02）。

**验收重点**：玩家实际搭建连接体，并利用浮力泡泡包裹飞行跨越空洞；掉落能返回房间初始点。不以旧 2 倍/5 秒/只向上/不可逆黏合验收。

### 第 3 关：爆炸（对应 04 §8.6）

1. 玩家进入时**已有飞行能力**；场景加入**定向运动的泡泡实体**与**爆炸陷阱**，陷阱可能把玩家推向空洞。
2. 运用前两关能力组合泡泡，观察主要由**物理关系**产生的效果。
3. 明确**爆炸泡泡不可回收**；爆炸造成不可回收消耗，**该消耗随时间缓慢恢复**。消耗量与恢复速率 TBD（T06、T07），不是永久损失。
4. 体验爆炸泡泡的**大质量与惯性**；与其他泡泡组合时可能把玩家**甩飞**。
5. 玩家可以控制爆炸，具体触发操作 TBD（D03）；爆炸提供**向外的力**，**力 = f（泡泡大小）**，具体曲线 TBD（T08）。

**验收重点**：玩家实际利用爆炸向外力与泡泡组合完成移动或解谜，并理解不可回收消耗缓慢回复、爆炸力与大小相关；定向运动、陷阱推力及质量惯性可读。泡泡潮不是此次第 3 关必验收项（D06）。

## 七、资源与失败处理

### 本版资源口径

| 项 | 本版规则 |
|----|----------|
| 容量 | 玩家泡泡液有限，每个泡泡体内也有限；液上限/回收效率 TBD（T04），储罐已移除，承载方式待确认（D10） |
| 普通泡泡 | 可回收，返还前面已发射泡泡中的液体；具体范围、黏合态和自动消散结算 TBD（D01） |
| 爆炸泡泡 | 不可回收；爆炸消耗量 TBD（T06），该部分慢恢复速率 TBD（T07） |
| 归零 | 暂时不能发射，但可回收场上普通存量，或等待爆炸不可回收消耗慢恢复；**不是必死，也不是只能重开** |
| 空洞 | 掉入返回房间初始点；精确位置与重置范围 TBD（T09） |
| 提示与重开 | 保留低资源风险提示与**自愿重开**；提示应说明可用恢复途径，不宣称“无法通关” |

> **资源管理有代价，但不把暂时耗尽判为死亡。** 初始存档点已知，不代表落穴返回的全部重置规则已确认。

### 旧扩展方案待确认：破坏回复 / 泡泡潮 / 永久破坏

这些旧设计留作对照，**不作为本次前三关必验收规则**：

| 旧方案 | 保留的设计意图与候选内容 |
|--------|------------------------|
| **破坏回复（D05）** | 旧稿将其设为主要补给，鼓励主动行动；是否加入、适用材质与比例需确认，不能宣称唯一恢复途径 |
| **增值泡泡潮（D06）** | 旧候选为第 3 关起，玩家进入房间后从角落向中心扩散，追上即死；可摆脱、可破坏、无法根除；“威胁也是补给”依赖破坏回复另行确认 |
| **永久破坏（D05）** | 旧候选为爆炸永久破坏环境，先清空周围再弹力破坏可制造永久空洞；不等于爆炸泡泡液永久损失 |
| **三维惩罚旧框架** | 黑色深渊为空间、泡泡潮为时间、泡泡值归零为资源；旧“软死亡只能重开”不再生效，仅保留风险感与责任感的设计意图 |

### 旧数值测试基准（非定案）

| 项 | 旧值 | 当前状态 |
|----|------|----------|
| 泡泡液上限（旧“泡泡值”） | 100 | 仅旧测试基准；上限 TBD（T04） |
| 小泡泡消耗 | 1 | 旧消耗候选（D09） |
| 单次蓄力消耗上限 | 10，线性递增 | 旧资源消耗候选（D09），**不是蓄力力度曲线（T03）** |
| 破坏大泡泡恢复 | 50，大泡泡容积 8 | 旧破坏回复候选（D05） |
| 泡泡潮回复量 | 容积基础 + 1 | 旧泡泡潮/破坏回复联动候选（D05、D06） |

## 八、玩法特色

| 特色 | 说明 |
|------|------|
| **工具即材料** | 弹力泡泡是粉色泡泡的前置材料——玩家在构建世界 |
| **恢复即愈合** | 粉色泡泡墙按时间恢复；泡泡流回补洞的视觉表现方向保留，不把玩家返液混为场景愈合 |
| **自制工具** | 黏合拼连接体，浮力包裹飞行，爆炸的大质量与向外力参与物理组合 |
| **蓄力即成本** | 蓄力连接大小、强度、资源消耗，但力度曲线与消耗曲线分别待定 |
| **Z 轴闸门（旧候选）** | 旧限时/只能向上/靠黏合终止飞行保留研究，不作为新限制定案（D02） |
| **不可逆决策（旧扩展）** | 旧爆炸永久破坏环境的决策压力待确认；本版爆炸资源消耗可慢恢复（D05） |
