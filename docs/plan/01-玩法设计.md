## 一、主题解读

**涌现（Emergence）= 简单的局部规则，自发产生复杂的整体行为。**

核心体验是**输入与输出严重不对称**：玩家做的每个动作都微不足道，系统却把它放大成远超操作量的复杂度。

评价一个设计是否切题，可以问：

- 玩家看到的现象，是"设计出来的"，还是"长出来的"？
- 如果去掉玩家，系统本身会不会自己动起来？
- 玩家能否预测结果？如果完全可预测，就没有涌现。

## 二、候选玩法方向

以下为团队讨论过的方向，供评估取舍。

### 方向 A：群体智能（推荐优先级最高）

| 项 | 说明 |
|----|------|
| 一句话 | 玩家只投放"诱因"（食物 / 威胁 / 障碍），个体按局部规则自行决策 |
| 局部规则 | 分离（别撞）、对齐（同向）、聚合（靠近）——即 Boids 三规则 |
| 涌现表现 | 全局队形无人设计却自发出现；受惊炸开、绕障、重组 |
| 优势 | 操作极简、视觉冲击强、结果不可预测，短周期最易做出「哇」效果 |
| 风险 | 玩法深度需额外设计，否则易沦为"观赏型 Demo" |

### 方向 B：规则组合

| 项 | 说明 |
|----|------|
| 一句话 | 玩家不直接打怪，而是给环境加一条规则（引力 / 生长 / 分裂），看系统如何演化 |
| 涌现表现 | 玩家与系统共同"养"出一个结果 |
| 优势 | 玩法深度高，可重复游玩 |
| 风险 | 规则设计难，容易变成"看不懂发生了什么" |

### 方向 C：简单到复杂

| 项 | 说明 |
|----|------|
| 一句话 | 玩家只做最简单的操作（点一下、划一下），系统反馈出高复杂度 |
| 涌现表现 | 操作量与结果复杂度严重不对称 |
| 优势 | 上手门槛极低，适合 Jam 演示 |
| 风险 | 与方向 A 高度重叠，可合并 |

### 方向 D：可控的失控

| 项 | 说明 |
|----|------|
| 一句话 | 玩家想控制，系统总有意外；玩法即"驯服混沌" |
| 涌现表现 | 每一次结果都不可完全预测 |
| 优势 | 情绪张力强 |
| 风险 | 挫败感控制是难点 |

### 方向 E：演化与遗传

| 项 | 说明 |
|----|------|
| 一句话 | 单位变异、繁殖、淘汰，玩家施加选择压力 |
| 涌现表现 | 你从未设计过的物种自己长出来了 |
| 优势 | 主题契合度最高，故事性强 |
| 风险 | 需要多代演化才能看到效果，Jam 周期内玩家难有耐心 |
