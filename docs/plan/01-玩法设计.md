# 玩法设计

> **版本 v2.23** ｜ 2026-10-09 ｜ 与 [04-完整策划案.md](04-完整策划案.md) 同步
>
> 本文档为**玩法速览**——完整设计见 04。

## 一、一句话

**在意识之海里拨动泡泡——三条规则让它们自行聚散，拼出你从未设计过的过去。**

玩家以为自己在"打开泡泡、通过关卡"，
最后发现自己在"拼回一个已经破碎的家"，
而这个故事的结局，正好是它的开头。

## 二、主题如何落地

**涌现 = 简单规则 + 个体交互 → 宏观复杂行为。**

**三层结构**（前两层咬合）：

```
世界层    泡泡之间的物理法则          ← 分裂 / 融合 / 膨胀（玩家不能直接控制）
   ↑
玩家层    主角用三种泡泡能力拨动        ← 弹力 / 浮粘 / 炸弹
   ↑
叙事层    语义节点 + 记忆反馈          ← 把玩法结果翻译成故事
```

**关键**：玩家的能力**不是外挂的作弊器，是世界规则的杠杆**。

> **少即是多**：3 种泡泡 × 1 个蓄力输入 × N 种材质 = 玩家无法一次性推演的局面。

## 三、世界层规则（三条）

| 规则 | 内容 |
|------|------|
| **① 分裂** | 泡泡受到扰动时分裂——**玩家的一切操作都是扰动** |
| **② 融合** | 同类泡泡靠近自动融合 |
| **③ 膨胀** | 膨胀时向四周弥散，**改变全场的相吸相斥强度** |

> **规则③是反馈回路，也是涌现的引擎**——非线性从这里来。

**场景可破坏**：墙壁、天花板、地面都是泡泡构成的活体物质。
弹力破坏会**愈合**（分裂→膨胀→融合），炸弹破坏**不可逆**。

## 四、玩家层能力（三种泡泡）

| 泡泡 | 能力 | 释放 | 回收 |
|------|------|------|------|
| **弹力** | 破坏物体 / 弹射自己 | 可发射 + 可放置 | ✅ 破坏回复 |
| **浮粘** | 漂浮 / 粘合成桥 | 只能放置 | ✅ 破坏回复 |
| **炸弹** | 爆炸推力 / 压开关 / 远程引爆 | 只能放置 | ✅ 破坏回复 |

**输入**：左键长按蓄力 → 泡泡变大 → 能力变强 → 右键释放

> **一个输入维度同时控制三件事**——蓄力越久，泡泡越大，效果越强。

## 五、核心循环

```
        分裂
       ↗    ↘
    扰动      融合
       ↖    ↙
        膨胀
```

**通关循环**：让阻挡的泡泡**短暂打开** → 通过 → 泡泡重新融合闭合

> **分裂是暂时的**——这带来时间压力，让"通过"成为需要判断的决策。

## 六、关卡结构

| 关 | 类型 | 主题 |
|----|------|------|
| 1 | 教学 | 弹力 |
| 2 | 教学 | 黏合（浮粘） |
| 3 | 教学 | 爆炸 |
| 4 | 正式 | 组合 |
| 5 | 正式 | 共鸣 |

**场景演进**：第 1 关纯白空间；**第 2 关起为海洋水下**（珊瑚等元素）。

## 七、惩罚机制

本作有三种死亡，**各覆盖一个玩法维度**：

| 惩罚 | 失败类型 | 情绪 | 维度 |
|------|---------|------|------|
| **黑色深渊** | 空间失误 | "我掉下去了" | 空间 |
| **增值泡泡潮** | 时间失误 | "我太慢了" | 时间 |
| **泡泡值归零**（软死亡） | 资源失误 | "我用光了" | 资源 |

### 增值泡泡潮

**从第 3 关起出现的时间压力**：从箱庭角落向中心扩散，追上即死。

| 项 | 设定 |
|----|------|
| 触发 | **玩家进入房间后**才开始（不进入不触发） |
| 应对 | 可摆脱、可破坏，但**无法根除** |
| 设计意图 | **"倒计时"的具象化**——看得见的、正在逼近的威胁 |

### 泡泡值恢复：两条途径

| 途径 | 定位 | 说明 |
|------|------|------|
| **破坏回复** | **主要** | 破坏泡泡回复——鼓励主动行动 |
| **时间恢复** | **保底** | 缓慢自然回复——防止卡死 |

> **鼓励主动破坏，但不惩罚"暂时不动"。**
> 泡泡潮也是可破坏的——**它既是威胁，也是补给**。

### 数值基准

| 项 | 数值 |
|----|------|
| 泡泡值上限 | **100** |
| 小泡泡消耗 | **1** |
| 蓄力消耗上限 | **10**（线性递增） |
| 破坏大泡泡恢复 | **50**（大泡泡容积 8） |
| 泡泡潮回复量 | **容积基础 + 1** |

> **软死亡**：泡泡值归零后还能动，但放不出泡泡——**无法通关，只能重开**。
> 比硬死亡更痛，因为责任在玩家自己。

## 八、玩法特色

| 特色 | 说明 |
|------|------|
| **工具即材料** | 弹力泡泡是粉色泡泡的"前置形态"——玩家在构建世界 |
| **恢复即愈合** | 不是重置，是泡泡自己流回去补上 |
| **Z 轴闸门** | 给了垂直移动能力，但用限时/只能向上/靠粘合终止来约束 |
| **蓄力即成本** | 蓄力同时是"大小""强度""资源消耗" |
| **不可逆决策** | 炸弹破坏永久，用前要想清楚 |
