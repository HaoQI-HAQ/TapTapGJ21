# Map2 / Map3 原始坐标白盒重建

## 范围

- Map2：加·巴希夫 / 破坏之力，数据 ID `Dungeon041`。
- Map3：摩·拉塔尼阿 / 配合摇晃，数据 ID `Dungeon058`。
- 采用公开的原作物件放置数据与 ActorInfo 模型包围尺寸；1 原作坐标单位对应 1 Unity 单位。
- 这是**原始坐标与比例的白盒复建**。没有导入原作网格、贴图、碰撞网格、机关脚本与相机，不能称为像素级复刻。

## 实际构建方式

Unity 菜单：`Tools → PAO → 关卡白盒 → 按原始坐标重建 Map2 + Map3`。

菜单从 `Assets/GameMain/Data/ShrineReferences/Map2_ReferenceLayout.json` 和 `Map3_ReferenceLayout.json` 构建场景。Map2 共 732 个有来源记录的物件代理；Map3 共 783 个。每个物件有 `ShrineWhiteboxReference`，可查看原始 actor、HashId、坐标、旋转和模型包围尺寸。

坐标不平移、不镜像，主流程向世界 `-Z`。保留原始缩放与模型枢轴；局部模型用包围尺寸放置。原始 XYZ 旋转按 `Rz * Ry * Rx` 转换。

重建只替换目标场景下的 `Map2_Whitebox` / `Map3_Whitebox` 根。执行前备份 `.unity` 至本目录 `backups/`。成功保存后写入 `Map2_build_receipt.json` / `Map3_build_receipt.json`。外部根物件不在替换范围内。

## 白盒表达

| 分类 | 表达 |
| --- | --- |
| 地板、墙体、平台 | 原始坐标、朝向、包围尺寸的方块代理 |
| 阶梯 / 斜坡 | 简化台阶 / 楔形碰撞网格 |
| 梯子 | 栏杆与横档，未增加攀爬逻辑 |
| 活塞 | 分开的推面与细长杆，避免把整条包围盒填实 |
| 基座、漏管 | 简化槽形截面，未复原原网格内腔 |
| 绳索 | 按原始链接端点连接的细圆柱，无碰撞 |
| 刺球、吊灯 | 椭球轮廓代理，未复原尖刺与灯架 |
| 祭坛 | 薄底座与终点标志，保留通行空间 |
| 天花、整体房壳与逻辑 actor | 剖去 / 不生成；不将空心房壳变成实心大方块 |

颜色用于区分结构、机关、可破坏物和地标。颜色或物件名称并不代表已经接好功能。

## 机关与可玩状态

本轮主要完成几何重建。原作的活塞周期、炸弹滚入漏管、绳索断裂、摆动、磁力操作滑块、燃烧解锁双门等行为**没有完整移植**。旧白盒根内的组件会随旧几何被替换；不能以旧版机关已实现为依据，认定新布局也自动具备同样行为。

原作磁力操作与本项目的弹力、炸弹、黏浮不是相同机制。保留原作布局，不等于已解决本项目 5 秒飞行限制下的通关条件。没有完成实际跑关、碰撞逐段校正与能力适配。

出生与终点继续提供项目 UI 使用的命名锚点：Map2 的 `Start_Salvage_Court` / `Memory_Beacon_Lower_Platform`，Map3 的 `West_Start_Camp` / `Map3_Corkscrew_Upper_Exit_Shelf`。
