## 空间与流程

1. 入口双门 → 主厅底层。
2. 左侧裂墙区域 → 释放一扇门片，侧室为可选支路。
3. 从右侧阶梯登起步岛，台面 Y=4。
4. 重复使用门片，跨越 Z≈30 至 21.5 的间隙，连接右南岛与右北岛，台面均 Y=4。
5. 可选探索左北岛：台面 Y=8，下层秘密洞底 Y=2，石堆奖励点 Y=16。
6. 取回门片并倾斜使用，从右北岛 Y=4 接到前阶台 Y=8，随后经坡道进入 Y=10 祭坛区。

这些是原作操作后的流程说明，不是本项目已验证的跑关路径。图中紫虚线表示门的临时搭接区域；场景没有增加永久桥。

## 当前边界

- 已搭建地图几何和普通碰撞体；没有导入原网格、贴图、机关脚本。
