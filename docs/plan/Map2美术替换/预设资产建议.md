## 替换方式

1. **只提取独立 mesh 节点。** 不要将整包预摆场景压缩到一个白盒方块。
2. 原节点常有 `scale≈0.01`、`rotation≈Rx90°`。归零预摆 translation，保留或烘焙 rotation＋scale，再做底面中心对齐。直接取 mesh 并设 identity 会放大约 100 倍且方向错误。
3. 地面用 Pavement 按 4 单位模块拼；高台侧面用 Wall/Beam 包覆，下方少量 Rock 作轮廓。优先拼模块，避免将一张薄墙拉成高厚方块。
4. 普通建筑外观与关卡碰撞分开。保留原白盒的落脚面高度、宽度、台阶坡面和机关空间；美术节点不自动生成填满洞口的整体包围盒碰撞。
5. 本轮仅替换普通结构。炸墙、移动平台、活塞、投弹口等机关保留识别与行为，后续可再单独做机关外观。
6. 原材质多共享 `TFD_Atlas_1A` 图集；保留 UV 和贴图关联。06 另有 DesertRock、Cloth、Vegetation 材质。先预览再确定是否需要海底色调调整。

清单尺寸是 accessor 包围盒变换结果，非精确碰撞或渲染后的可见轮廓；不同预摆实例的旋转也会改变轴向尺寸。选材时优先 01 的单件陈列节点，并且一个模型只选择一个 LOD。
