# TapTapGJ21

> 2026 聚光灯 ｜「TapTap 制造」GameJam，赛期 21 天

## 本期主题：涌现（Emergence）

**简单的局部规则，自发产生复杂的整体行为。**

没有人设计全局，全局却出现了。

一条鱼只是跟着身旁的鱼游动，成千上万条鱼却汇聚成整片鱼群——转向、聚散、受惊炸开又重组。没有一条鱼知道「鱼群」是什么形状，可鱼群就在那里。

这正是「涌现」：**个体只遵守几条简单规则，整体却表现出任何单个个体都不具备的复杂行为。**

### 为什么它迷人

| 例子 | 局部规则 | 涌现出的整体行为 |
|------|---------|-----------------|
| 鱼群 / 鸟群 | 分离、对齐、聚合 | 群体转向、避障、受惊逃逸 |
| 蚁群 | 沿路留下信息素 | 找到最短路径、搭桥、分工 |
| 生命游戏 | 三条生死规则 | 滑翔机、振荡器，乃至可计算的图灵机 |
| 神经网络 | 单个神经元的加权求和 | 识别、推理、语言 |

**玩家做的每一个动作都微不足道，系统却把它放大成远超操作量的复杂度——输入与输出严重不对称。** 这是「涌现」最核心的体验，也是本次创作要抓住的东西。

### 我们的设计出发点

| 角度 | 玩法落点 | 涌现体现在哪 |
|------|---------|-------------|
| 群体智能 | 玩家只投放「诱因」（食物 / 威胁 / 障碍），个体自行决策 | 全局队形无人设计，却自发出现 |
| 规则组合 | 玩家给环境加一条规则（引力 / 生长 / 分裂），看系统如何演化 | 玩家与系统共同「养」出一个结果 |
| 简单到复杂 | 玩家只做最简单的操作，系统反馈出高复杂度 | 操作量与结果复杂度不对称 |
| 可控的失控 | 玩家想控制，系统总有意外；玩法即「驯服混沌」 | 每一次结果都不可完全预测 |
| 演化与遗传 | 单位变异、繁殖、淘汰，玩家施加选择压力 | 你从未设计过的物种自己长出来了 |
