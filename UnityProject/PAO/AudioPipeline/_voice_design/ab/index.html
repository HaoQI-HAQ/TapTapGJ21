怎么试

每张卡片是同一句台词的不同音色。重点听三件事：句尾是否自然落平（不要拖、不要上扬卖萌）、有没有播音腔、语速是否稳。B 行高亮，是我按上一轮“克制、不表演”方向给的起点。

候选

  • 现版 · Windows SAPI — 项目正在用的机器音。刻意“不像人”，但语速偏拖。
  • A · Yunxi 常规 — 明亮、干净，接近日常讲述；比现版快很多。
  • B · Yunxi 放慢（推荐起点） — 更稳、更克制，接近“说故事但不表演”；句尾落平。
  • C · Yunxia 儿童 — 真正的“男孩”，但偏卡通可爱，风险最高。
  • D · Yunyang 成年男声 — 新闻播报底子，可靠但“太像播音”，与旁白设定冲突。

三条必须知道的限制
1. Edge TTS 是微软在线朗读服务，用于开发/试听没问题；正式发行请换 Azure Speech（同音色、可商用授权）或国内 MiniMax / 豆包等，并保留同一套参数。
2. 时长变了：现版 5 段 96.6 s，候选 63–73 s。触发器和字幕节拍都能自适应，但“旁白说完再发生”的停顿感会变；锁定音色后要重跑 Tools/PAO/关卡白盒/Map0 教程重构 · 旁白自检 并实机走一遍。
3. 不是 bit 级可复现：同一文本两次生成听觉一致但文件不同；manifest 里记了参数与文本 sha1，重生成请以听觉验收，别做文件哈希校验。
