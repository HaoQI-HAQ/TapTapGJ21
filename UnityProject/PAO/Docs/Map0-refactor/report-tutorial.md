## 本版按你的反馈整体改了什么

1. **关卡目标改为新手教学**：按旁白稿重做第一章——白空间诞生 → 粉泡墙（打破/恢复）→ 泡泡液（消耗/回收）→ 方向选择 → 出口。
2. **横向锥形空间**：出生端是锥尖（窄、矮、白），沿 +Z 逐渐变宽变高，锥底是出口巨拱 + 巨型发光泡。空间尺度：半宽 5.5 m → 56 m，墙高 8 m → 34 m，长度约 150 m。
3. **画面「简单 → 庞大 → 震撼」**：
   - 锥尖：一间小白房间 + 粉色泡泡墙（全画面只有白 + 一抹粉）；
   - 中段：巨柱、26 m 高墙面、雾里逐渐出现彩色光泡；
   - 锥底：抬高的出口平台、30 m 高巨拱、44 m 发光巨泡 + 一圈彩色光泡（约 16 颗）。
4. **环境颜色渐变**：不是只加彩色球——锥形地面/两侧墙面本身用 MaterialPropertyBlock 从白 → 暖白 → 淡紫渐变；出口平台转暖；5 组彩色点光沿锥体排布；外加 30+ 颗彩色发光泡随长度递增。
5. **旁白接入（v3 初版）**：36 段全部进数据（`Map0NarrationData`），26 段生成 SAPI 配音（约 22 分钟音频，`Assets/GameMain/Audio/Map0VO`），场景里 21 个触发区 + 2 个停留区 + 3 条静止反应（15 s / 35 s / 70 s），字幕条从 wengjie 克隆。**现已被精简：只留 5 段关键机制教学（约 1 分 37 秒），见 [`narration-trim.md`](narration-trim.md)。**
6. **去掉不好的设计**：删掉随机散落的白模、漂浮的黑色水滴/刻痕长条、压顶的门楣、纯装饰的 TFD 杂件；黑液滴落在一块小基座上，刻痕只留 4 道细纹。
