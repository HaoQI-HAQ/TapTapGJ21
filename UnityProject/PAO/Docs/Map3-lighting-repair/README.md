# Map3 光照修复（2026-10-20）

远程提交 `ce70a595` 同时提高平面环境光、侧面补光并增加无阴影底部补光，使游戏画面泛白。此次只恢复 Map3 的光照层次；保留无雾状态、水面、主光焦散 Cookie、灯光朝向及现有场景内容。

| 参数 | 修复前 | 修复后 |
|---|---|---|
| 环境光 RGB | (1.08, 1.08, 1.04) | (0.71, 0.81, 0.93) |
| 主灯颜色 RGB / 阴影强度 | (0.98, 0.99, 1) / 0.25 | (0.91, 0.96, 1) / 0.5 |
| Temple_BlueFill 颜色 RGB / 强度 | (0.97, 0.99, 1) / 1.1 | (0.49, 0.77, 0.91) / 0.45 |
| Temple_UnderFill | 启用，0.65 | 禁用，0 |
| 对比度 / 色温 | -12 / 0 | -6 / -6 |

主光强度仍为 2.1，曝光 -0.1、Bloom 0.12。Map2 / Map2_5 的配置不变。`TempleEnvironmentSetup` 的 Map3 Palette 已同步，重新搭建或调整环境时也使用这些值。菜单 `Tools/PAO/环境氛围/修复当前 Map3 光照` 只修改已加载且活动的 Map3，并标记待保存。

## 实际渲染验证

在 Unity 2022.3.34f1 中，使用同一 MainCamera 视角、1600×900、HDR 和后处理，分别渲染 [修复前](before.png) 和 [修复后](after.png)。平均线性亮度由 0.477693 降至 0.351387（约下降 26.4%）。这是相机离屏渲染验证，未执行完整关卡通关测试。

897 个物体及 Transform、686 个 Collider、333 个脚本组件、2 个 Camera 的序列化指纹前后一致，缺失脚本为 0。与运行前场景副本相比，保存文件仅修改 9 行灯光/环境光参数。完整结果见 [verification.json](verification.json)。临时验证脚本已删除。
