## 本轮补强的布局与状态

- 标题、徽记和卡片按内容高度展开，容纳换行与大字号。
- 两列卡片在窄窗口重排；设备图示按可用宽度缩放；建构预览保留场景观察区。
- 建构预览把取消、旋转和确认固定在同一操作区，取消获得初始焦点；窄屏缩小内边距与标题，保留中央预览目标。
- 情境引导控件在创建时隐藏，只在对应动作可用时显示；提示底板使用暖白色，普通进度用海绿，紧急状态用珊瑚色。
- 窄屏字幕上移避开右下能力区，长字幕按内容高度展开。
- 2026-10-14：按截图反馈移除默认 HUD 左下常驻的泡泡名称卡；短时图形引导回到左下边距，不再为已隐藏的卡片预留空间。
- 设置重新构建内容后恢复对应控件的焦点，当前分类标记持续可见。
- 长列表显示细滚动条，焦点移到下方控件时自动将它滚入视口；底部返回与应用区域独立保留。
- 改键等待、冲突确认、空日志、空结局、不可用操作和危险确认继续使用统一的状态语言。
