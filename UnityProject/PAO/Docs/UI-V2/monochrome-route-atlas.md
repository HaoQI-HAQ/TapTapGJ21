# 泡涌：黑白线框界面与章节图册

## 视觉规则

- 功能面板为白底、黑字、黑色细线边框；背景装饰只使用黑、白、灰。泡泡能力的识别色保留在泡膜动效中，形状仍能独立区分。
- 主菜单以冰蓝玻璃质感的整幅背景铺满，标题「泡涌」以超大字号水平居中压在画面中上部，不加底板、边框或标题卡片；首层只显示标题与透明的「开始游戏」入口，文字渐淡后进入第二层：入口列右移到画面下部右侧。四个入口不画方框，只剩图标与文字；版本号在左下，制作人员致谢是小字加跳转链接在右下。
- 玩法 HUD 只显示资源占比与消耗拖尾、重开和暂停图标、图形引导及三颗循环切换的能力泡泡。剧情旁白保留文字。
- 暂停时保留可见的游戏画面，右侧两层底板以 70 毫秒间隔先滑入，白色功能板随后滑入；六项文字依次上移显现。居中大字显示「暂停」，右侧依次是继续、地图、重开、读档、设置、主菜单。关闭时整体向右收回。

## 主菜单海报构图

主菜单不再是一张居中的白纸卡片，而是一整幅铺满的玻璃质感海报：`UIConfig.menuBackdrop`（1920 × 1080，由 `Tools/UIV2/make_menu_glass_backdrop.py` 生成）作为全屏背景按 cover 方式裁切铺满（`UIBackdropCover`）；未配置时退回 `menuPaperArt`。底图本身很淡，高对比与伪本地化下同样保留，黑字对比度不受影响。

- **标题**：220 号字，水平居中，按窗口宽度在 920 设计像素内自动收缩，最小 96；宽屏位于画面中上部，竖屏同样居中。标题下方只保留一条短横线，作为字标的落款而非容器边框。
- **入口列**：位于画面下部右侧（宽屏 60%–96.5%，高 8%–52%），无白底、无描边、无焦点外框；每行只有图标与文字，四个条目统一 32 号字、统一占四个汉字宽度的字块（两个字的条目拉开字距而不是缩小字号），行高按字号自动计算，内容溢出时才出现滚动条。悬停或键盘聚焦时整行右移 12px（按下 6px）、文字下方长出 2px 细线；未选中项文字降到 78% 不透明度，不可用时整行降到 34%。
- **开始层**：标题与「开始游戏」同样水平居中，点击后与第二层标题位置一致，不会左右跳。
- **底栏**：左下角是版本号；右下角「开发人员致谢」改为 18 号小字加一条下划线，整行可点击进入制作人员页，悬停或键盘聚焦时下划线从 42% 延展到整行。
- 页面切换仍使用非缩放时间的淡入与逐项显现；减少动态效果时直接显示终态。

## 章节图册

章节按配置顺序排成一条可横向滚动的航线。每个章节为 390 × 540 设计像素的大卡片，只显示编号、名称和状态；卡片用黑色描边、选中横条及图纸标记建立层次。点击卡片打开独立的章节档案弹窗，展示简介、目标、进度状态和进入操作。状态来自当前旅程：已完成、当前章节、已开放、未解锁。地图页只有已开放且场景存在的章节可进入；进入时从该章起点开始，并先确认会重置尚未保存的探索。

章节图册也位于读档页顶端。每份存档卡片包含所在章节、保存时间、游玩时间与意识碎片数。点击「查看章节进度」会让图册切换到该记录的完成进度和所在章节，再点击「读取」才会恢复该记录。这样地图方格是章节索引，存档卡片是独立旅程快照，两者在同一页互相对应。

## 存档规则

- 一个自动记录和三个手动记录彼此独立。继续游戏读取最近一份可用记录；新游戏开始新旅程、更新自动记录，保留手动记录。
- 进入章节、完成章节、探索中每 60 秒、打开暂停界面、游戏进入后台或退出时更新自动记录。手动记录在玩法中的读档页写入，可覆盖并保留备份。
- 每份记录保存场景、玩家位置、章节完成列表、已收集意识碎片、教学状态、建构记录、结局和游玩时间。读取时重载该场景并恢复这些状态。
- 暂时生成的泡泡、正在进行的物理模拟和未配置为可存档的场景状态会在读档后重置。章节图册的预览不修改当前旅程，只有「读取」才应用存档。

## 动效节奏

以 React Bits 的 [Staggered Menu](https://reactbits.dev/components/staggered-menu)、[Animated Content](https://reactbits.dev/animations/animated-content) 和 [Animated List](https://reactbits.dev/components/animated-list) 为节奏参考，在 Unity 中使用现有 UI 与 DOTween 实现。按钮以短线展开回应悬停和键盘焦点；普通页面的主体轻微上移、内容逐项显现；关卡卡片和档案弹窗分别处理选择与详细信息；暂停页保留独立的两层底板及功能板错时滑入。所有界面使用不受游戏暂停影响的动效时间，开启「减少动态效果」时直接显示最终状态。
