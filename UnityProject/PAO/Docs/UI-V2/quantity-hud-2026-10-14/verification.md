# 泡泡量 HUD（2026-10-14）

左下角保留泡泡图标、当前值 / 上限和量条。移除类型、已用值、松开按键、就绪发射、恢复与不足说明等常驻文字，也不再重复显示小蓄力圈。数字由 22 增至 32，量条由 8 增至 24；蓄力和持有泡泡时面板保持固定高度。右下角选中能力环继续显示真实蓄力进度。

扣值与回收直接改变数字和条长。低资源显示警示色，回收短暂提亮量条，耗尽时填充完全隐藏。暂停隐藏整个 HUD。详细操作说明仍可在帮助和主动开启的详细提示中查看。
