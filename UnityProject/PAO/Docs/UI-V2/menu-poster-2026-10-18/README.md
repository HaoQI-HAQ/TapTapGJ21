## 背景图

两张参考图只有 320–371 px，直接铺 1920 会糊，所以用 `Tools/UIV2/make_menu_glass_backdrop.py`
按它们的材质与配色重新生成了一张 1920 × 1080 的背景，输出到
`Assets/GameMain/UI/Sprites/menu_backdrop_glass.png`，并在 `PAOUIConfig.menuBackdrop` 里指定。
重新生成：`python Tools/UIV2/make_menu_glass_backdrop.py`。

## 关于 `layout-composition.png`

这张图**不是 Unity 运行截图**，而是按上面的锚点、字体（`26汉仪趣报简`）和背景图用
Pillow 合成的排版示意，用于在打开编辑器之前确认构图比例。真实实现里的字号自适应、
焦点细线动效与滚动条以引擎内运行为准。

## 引擎内核对

1. 打开 `Assets/GameMain/UI/Menu.unity`，按 Play。
2. 首屏应只看到居中的超大「泡涌」、下方「开始游戏」与玻璃质感背景；点击后入口列淡入到右下。
3. 改 `UIRuntime.Menu.cs` 里的 `WordmarkSize`（220）与 `UIMenuPosterLayout` 的锚点即可微调；
   入口行高按 `字号 × 2.1` 自动计算，大字号时整列可滚动。
