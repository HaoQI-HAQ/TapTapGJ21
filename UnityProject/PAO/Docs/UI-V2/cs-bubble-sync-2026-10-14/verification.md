# cs 泡泡配置统一

以 cs（测试）场景为基准，统一 Map0–Map5 的浮粘、弹力和炸弹泡泡。

所有玩家读取 `Assets/GameMain/Resources/CSBubbleLoadout.asset`。它包含三种美术预制体及尺寸、发射速度、浮力、载人、爆炸参数，以及蓄力时间、滞留阈值和生成位置。以后修改该资产即可同步测试场景和所有关卡。无共用配置的独立测试对象仍可使用 BubbleLauncher 的局部参数。

| 类型 | 预制体 | 直径 | 消耗 |
| --- | --- | --- | --- |
| 浮粘 | nian_p | 0.2–1.6 m | 2–12 |
| 弹力 | tan_P | 0.3–1.1 m | 2–12 |
| 炸弹 | bao_P | 0.2–0.6 m | 2–12 |

cs 和 Map1 的旧玩家引用已映射为当前预制体，保留出生点。Map5 的局部泡泡覆盖已移除，避免继续使用不同的炸弹大小、消耗和场景模板。各关卡的地形布局、容量和奖励保留。

默认 HUD 在左下角仅显示泡泡值和能量条；蓄力、缺值、回收和待引爆时补充短提示，详细模式提供所选类型的消耗范围。蓄力圈收进资源面板，地形填充提示避开角色。全部共用 UI 使用 lowpoly 风格。滞留泡泡使用原类型显示和发射，再次发射不重复扣值。暂停停止蓄力和扣值并隐藏 HUD。

## 验证

Unity 2022.3.34f1。专项运行 145 条检查通过、0 错误；完整 UI 回归 204 项通过、0 错误。脚本编译通过，唯一警告为已有的 LevelPathPanel 未使用字段。

专项覆盖 cs 与 Map0–Map5 的实际加载、单一玩家/资源/表情组件、三种泡泡真实生成的美术材质、共用配置、逐步扣除、耗尽保持尺寸、回收恢复成长、蓄力锁定、暂停、滞留后切换类型、滞留发射不重复扣除，以及真实地形奖励。58 个继承参数另逐项对照 cs 原玩家配置，完全一致。截图覆盖 1600×900、960×540 及英文 130% 字号。

独立验证工程：`D:/TapTap21/PAO-CSBubbleValidation-20261014`。使用 clone 已解析的依赖 DLL，以 `-noUpm --burst-disable-compilation` 运行。测试副本映射包脚本 GUID，并给 glTF 导入器提供原包的 Built-In 着色器，完成 Map4 模型导入。UI 截图用于检验布局和文本，未用于评估正式 URP 场景光照。

专项入口：`PAO.EditorTools.UIV2Verification.RunBubblesCLI`；UI 回归入口：`RunAllCLI`。入口只允许带 PAO_UI_VERIFICATION_PROJECT 标记的独立副本，避免改写正式工程。
