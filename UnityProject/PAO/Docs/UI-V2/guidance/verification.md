默认探索界面隐藏目标段落、蓄力句子和自动教学段落。目的地符号、屏幕边缘箭头、准星蓄力环、对象附近的交互符号及绑定按键承担日常引导。日志和暂停使用图标。收集、建构和恢复记录使用短暂符号；必要错误、保存、剧情字幕和危险确认保留文字。

交互标记遵守遮挡、有效范围与组件启用状态；骑乘退出标记优先显示，带弹弹射使用发射图示。所有按键提示读取当前设备及重映射。边缘箭头避让能力按钮，准星和倒计时使用暗底以适应亮背景。

潮水环读取真实进度；初始化未完成时隐藏零秒提示；终点淹没后显示宽限时间。减少动态模式保留静态符号。“辅助 > 详细文字提示”恢复完整说明；也可主动打开“操作与教学”查看目标、能力和当前按键。教学关闭时成功反馈仍保留，模态页面隐藏 HUD 并暂停图形提示计时。
