# Creat 泡泡沙盒

场景：Assets/GameMain/Scenes/Creat.unity（Unity 当前打开的 TapTapGJ21-clone 副本）。
主菜单左上角的「究极沙盒 · Creat」文字入口可进入（与右下角致谢入口同款样式），也可直接打开场景按 Play。

- 场地底面 96 × 48 米，限高 72 米；底面积为原来的 2 倍，高度为原来的 3 倍。
- 每格仍为 2 米，共 41472 格（原来的 6 倍）；地板、四周边界与天花板都有实体限制。
- 初始场地为空。所有玩家造物均由吹出的泡泡在落点完成；造物不会因普通泡泡寿命到期而消失。
- 使用独立沙盒发射器，不消耗泡泡值；普通关卡继续使用原有发射器与泡泡值规则。

| 操作 | 功能 |
| --- | --- |
| WASD / 空格 / Shift | 移动 / 跳跃 / 加速 |
| 鼠标 / 左键 | 观察 / 按住蓄力，松开吹出泡泡（跟随设置里的改键与点击蓄力选项） |
| 1 / 2 / 3，滚轮 | 浮空 / 建造 / 破坏 |
| 浮空 | 抬起六面相连的整件造物；蓄力决定上升 1～3 格；遇占位与天花板时整笔拒绝 |
| 建造 | 在落点的网格中生成可站立的圆泡或方泡；没有命中时可在视线前 12 米的空中开始造物 |
| 破坏 | 按笔刷范围局部拆除；场地与边框不受影响 |
| B / 教学与日志键 | 调色工具台（暂停游戏，选择颜色与笔刷） |
| C / V | 下一种 / 上一种预设色，共 40 色（原有 8 色、鲜艳色、深色、浅色、黑白灰与棕色） |
| X / G | 切换 1、3、5 格大小 / 圆泡、方泡形状 |
| P | 开关染色笔刷；建造能力改为给已有造物染色，不生成新格 |
| T | 开关连吹；长按发射键连续喷出泡泡 |
| Ctrl+Z / Ctrl+Y | 撤销 / 重做，最多保留 64 笔 |
| F5 / Home | 保存作品 / 返回入口 |
| Esc | 沙盒专用暂停菜单，提供存取、清空与返回主菜单 |

作品存储在 Application.persistentDataPath/Creat/sandbox.json，与旅程存档分开。
每 30 秒自动保存，保存并返回主菜单或退出时也保存；下次进入自动恢复。
读取会先校验完整文件，失败时保留当前作品。覆盖读取与清空场地都需在游戏内确认。
颜色与形状会随作品保存；撤销记录仅保存在本次游玩内。

按 B 打开调色工具台，点色块即可选择预设色；点击顶部「自由调色 / HEX」可调整 RGB 三通道（0～255），
或输入六位 HEX 色号（例如 #FF8800，支持粘贴与省略 #）。预览实时更新，点击「完成调色」继续使用所选颜色。
自定义颜色支持建造、染色、浮空、撤销与重做，并随作品存档保存；已经吹出的泡泡保留发射时的颜色。
新版存档使用版本 2，并兼容读取版本 1 的旧作品，原有 8 色索引保持不变。
扩建后也能读取原 48 × 48 米、限高 24 米场地的版本 1 / 2 存档；旧造物的实际位置、大小、形状和颜色保持一致。

编辑器菜单 PAO → Creat 提供打开与搭建入口。已有沙盒会被保留，搭建入口不会重置作品场景。
自动检查报告与预览图位于 output/CreatValidation；示例造物只在验证 Play 中生成，不写入正式场景或玩家存档。
