# Creat 泡泡沙盒

场景：Assets/GameMain/Scenes/Creat.unity（Unity 当前打开的 TapTapGJ21-clone 副本）。
主菜单左上角的「究极沙盒 · Creat」文字入口可进入（与右下角致谢入口同款样式），也可直接打开场景按 Play。

- 场地底面 96 × 48 米，限高 72 米；底面积为原来的 2 倍，高度为原来的 3 倍。
- 每格仍为 2 米，共 41472 格（原来的 6 倍）；地板、四周边界与天花板都有实体限制。
- 初始场地为空。所有玩家造物均由吹出的泡泡在落点完成；造物不会因普通泡泡寿命到期而消失。
- 使用独立沙盒发射器，不消耗泡泡值；普通关卡继续使用原有发射器与泡泡值规则。

| 操作 | 功能 |
| --- | --- |
| WASD / 空格 / Shift | 移动 / 跳跃 / 加速 |
| 鼠标 / 左键 | 观察 / 按住蓄力，松开吹出泡泡（跟随设置里的改键与点击蓄力选项） |
| 1 / 2 / 3，滚轮 | 建造 / 破坏 / 选中；选中模式点击添加红框，再次点击取消，R 清空选择 |
| Q / E（或 PageUp / PageDown） | 上浮 / 下浮 1 格；有选择时移动已选造物，无选择时移动准心对准的六面相连造物；操作按钮位于下方工具栏上方 |
| 泡泡合并 | 上下移动时与其他圆泡重叠会合并，保留移动泡泡的颜色与选择红框；方块、场地边界与角色仍会阻挡，整笔拒绝；Ctrl+Z / Y 可撤销 / 重做合并 |
| 建造 | 在落点的网格中生成可站立的圆泡或方泡；没有命中时可在视线前 12 米的空中开始造物 |
| 右键 | 建造模式下快速吹出一颗放置泡泡；左键蓄力方式也可使用 |
| 按住 Alt + 吹泡泡 | 建造模式下瞄准脚下支撑面的相邻格；像 MC 一样跳起再放置，落到新造物上继续搭高 |
| 破坏 | 有选择时整批拆除所有选中物件，无选择时拆除方框内全部造物（含角落）；场地与边框不受影响 |
| B / 教学与日志键 | 调色工具台（暂停游戏，选择颜色与笔刷） |
| C / V | 下一种 / 上一种预设色，共 40 色（原有 8 色、鲜艳色、深色、浅色、黑白灰与棕色） |
| X / G | 切换 1、3、5 格大小 / 圆泡、方泡形状 |
| P | 开关染色笔刷；建造能力改为给已有造物染色，不生成新格 |
| T | 开关连吹；长按发射键连续喷出泡泡 |
| Ctrl+Z / Ctrl+Y | 撤销 / 重做，最多保留 64 笔 |
| F5 / Home | 快速保存至自动存档 / 返回入口 |
| F6 / 作品预览 | 打开独立作品预览；暂停建造，只展示本次实际摆放的造物，按整体范围自动取景；Esc 返回建造 |
| Esc | 沙盒专用暂停菜单，提供存取、清空与返回主菜单 |

暂停菜单与作品预览都提供「保存作品」「作品存档」入口。命名后可保留多份独立作品，列表显示名称、造物数量与保存时间，支持读取、覆盖、改名和删除；读取、覆盖与删除前会确认。
命名作品保存在 Application.persistentDataPath/Creat/Works/，每份存档使用独立文件与原子写入校验。保存新作品不会覆盖其他作品，也不会被自动保存覆盖。
自动存档保存在 Application.persistentDataPath/Creat/sandbox.json，与旅程存档和命名作品分开；F5 快速保存更新此文件，作品存档页面也可读取旧的自动存档。
每 30 秒自动保存，保存并返回主菜单或退出时也保存；下次进入自动恢复。
读取会先校验完整文件，失败时保留当前作品。覆盖读取与清空场地都需在游戏内确认。
颜色与形状会随作品保存；撤销记录仅保存在本次游玩内。
放置参考 MC：瞄准造物的哪一面，就放到该面的相邻网格；已有造物不会被覆盖。
抬头时准心可穿过为镜头粒子化的遮挡物，选中可见的高处造物；瞄准距离覆盖整个扩建场地。普通实体仍遮挡准心，Alt 脚下放置仍检测实际支撑面。
玩家身体占用的位置不能放置，预览框与准心会变红。脚下放置需要先跳起让出位置，玩家位置由正常移动与碰撞决定。
大笔刷以脚下支撑面为底层；任一新格与玩家相交时整笔取消。泡泡发射后保留原定落点，到达时重新检查占位；重做也会检查玩家空间。
笔刷统一作用于预览方框内的全部格子：1 格为 1×1×1，3 格为 3×3×3，5 格为 5×5×5。建造填充框内空格，染色修改框内已有造物，区域破坏拆除框内全部造物；圆泡／方泡只决定造物外形，不缩小作用范围。

按 B 打开调色工具台，点色块即可选择预设色；点击顶部「自由调色 / HEX」可调整 RGB 三通道（0～255），
或输入六位 HEX 色号（例如 #FF8800，支持粘贴与省略 #）。预览实时更新，点击「完成调色」继续使用所选颜色。
自定义颜色支持建造、染色、浮空、撤销与重做，并随作品存档保存；已经吹出的泡泡保留发射时的颜色。
上浮／下浮操作不会切换当前建造、破坏或选中模式；移动通过发射泡泡在到达时生效，并保留发射时的选择。
批量破坏：按 3 多选物件，再按 2 吹出破坏泡泡；无需继续瞄准物件，泡泡到达时拆除发射时选中的所有物件。切换模式保留选择，Ctrl+Z / Y 可整批撤销 / 重做。
独立作品预览也可从暂停菜单进入。圆泡使用珠光材质，方块使用柔和陶瓷材质，保留原有颜色；仅作用于预览副本。
拖动旋转、滚轮缩放，中键或 Shift+拖动平移；F 重新取景，也可切换正面、侧面、顶视及开关网格地面。
预览相机没有墙体与场地边界限制，不带入玩家、红框或建造笔刷；退出后恢复原作品、选择与相机，存档不受影响。
新版存档使用版本 2，并兼容读取版本 1 的旧作品，原有 8 色索引保持不变。
扩建后也能读取原 48 × 48 米、限高 24 米场地的版本 1 / 2 存档；旧造物的实际位置、大小、形状和颜色保持一致。

编辑器菜单 PAO → Creat 提供打开与搭建入口。已有沙盒会被保留，搭建入口不会重置作品场景。
自动检查报告与预览图位于 output/CreatValidation；示例造物只在验证 Play 中生成，不写入正式场景或玩家存档。
