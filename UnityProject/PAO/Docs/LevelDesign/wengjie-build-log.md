## 三、每一段怎么玩

### 断柱廊（3 分钟）
1. 从西门进来，先看见一根已经歪 55° 的柱子（示范：这东西会倒）。
2. 走近，四根柱子脚下各有一颗**会发光的楔子**（`TerrainBubble`）。
3. 切弹力泡（2），把楔子填满（capacity 3 = 一颗满蓄力，或三颗点按）。
4. 楔子炸开 → 0.25 秒后柱子轰然倒下 → 倒向西岸，成了桥。
5. 不想花 12 值也行：等渡台。但柱子倒下来会砸在渡台轨道上 —— **自己毁掉备用路线**。

### 峡谷（1.5 分钟）
1. 踏进谷口触发 `B_TideGate`，1.2 秒后潮水从谷底开始涨。
2. 5 级台阶每级 3 米高 —— 跳是跳不上去的（跳 1.2 米），必须用滞留提拉（按住左键，10 米）或骑泡。
3. 被水追上是**不会死**的：水会以 3.5 m/s 把你顶起来。所以失败不是重开，是损失时间。
4. 93.6 秒内踩上祭坛就通关。
