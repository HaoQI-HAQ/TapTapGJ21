# wengjie · 15 分钟体验流程（美术落地版）

> 场景：`Assets/GameMain/Scenes/wengjie.unity`
> 主题：**涌现** ｜ 时长：**15:00** ｜ 约束：不改共享脚本、不动其他场景
> 前一版《倒柱桥》成为本文的 **第 3 段**，细节见 `wengjie-emergent-level.md`

## 0. 结构：一口井，三条路

```
                        ◉ 祭坛（井顶）
                          │
        ┌─────────────────┼─────────────────┐
        │              深渊井               │
        │        （终局 3:00，全系统）       │
        └───┬─────────────┼─────────────┬───┘
            │             │             │
   ┌────────▼───┐  ┌──────▼──────┐  ┌───▼────────┐
   │ 断柱廊 3:00 │  │ 沉没广场 1:30│  │ 峡谷裂口2:30│
   │  倒柱 / 物理 │  │  枢纽 / 呼吸 │  │ 潮水 / 逃跑 │
   └────────┬───┘  └──────▲──────┘  └───┬────────┘
            │             │             │
            └─────────────┴─────────────┘
                          │
                 ┌────────▼────────┐
                 │  珊瑚庭院 2:00   │   ← 开场 + 教学
                 └─────────────────┘
            迷宫废墟 2:30（挂在广场另一侧）
```

**为什么是「井 + 三条路」而不是一条长走廊：**

1. **井是可见的时钟** —— 水位就是进度条，不需要 UI。玩家每次回广场都能看见水又高了一截。
2. **枢纽给呼吸** —— 15 分钟里必须有 4 次「什么都不用做」的空档，否则全程高压会累。
3. **三条路各教一个系统**，终局全用一遍 —— 这是任天堂最稳的节奏公式。

## 2. 六个区域，一眼可辨

**每个区域 = 一个主色 + 一个主构件 + 一个主音效。** 玩家闭着眼睛也能听出自己在哪。

| # | 区域 | 主色 | 主构件 | 主音效 | 玩法 | 时长 |
|---|---|---|---|---|---|---|
| 1 | 珊瑚庭院 | **青绿** | `Green Sea Grass` + `Sunshafts` + 浅水后期 | Map4_Reef | 教学（吹/粘/骑） | 2:00 |
| 2 | 沉没广场 | **石灰白** | `TFD_Gate_01A` + `Pavement_01A` + `Railing` | Map4_Base | 枢纽 / 呼吸 | 1:30 |
| 3 | 断柱廊 | **暖褐（无雾）** | `TFD_Column_01A_Module_07/28` + `Beam_12A` | Map4_Pulse | 倒柱 / 物理 | 3:00 |
| 4 | 峡谷裂口 | **深蓝** | `Canyon_Cliff_01A` + `Rock_Large_08A` + 深水雾 | Map4_Trench | 潮水追 / 逃跑 | 2:30 |
| 5 | 迷宫废墟 | **暗紫** | `SM_L5_mi_gong` + `SM_L4_yi_ji` + `Ambient Particles` | Map4_Vent | 遥控炸弹 / 解谜 | 2:30 |
| 6 | 深渊井 | **黑 + 一束光** | `TFD_Column_01A_Module_28` 竖排 + `Sunshafts (Area)` | Map4_Tension + TideRising | 全系统 / 终局 | 3:30 |
| | **合计** | | | | | **15:00** |

**色彩脚本**：绿 → 白 → 褐 → 蓝 → 紫 → 黑，最后只剩一束光。这是整段体验的暗线，玩家不会说出来，但会觉得「一直在往里走」。

## 3. 节奏曲线

```
张力
 5 ┤                                  ██          █████
 4 ┤              ███                 ██          █████
 3 ┤          █   ███          ██     ██     ██   █████
 2 ┤      █   █   ███     █    ██     ██     ██   █████
 1 ┤  █   █   █   ███     █    ██     ██     ██   █████
 0 ┼──┴───┴───┴───┴───────┴────┴───┬──┴──────┴───┴───┴──→
   0  0:40 2:00 2:40    5:40  6:10 8:40  9:10 11:40 15:00
      ↑开场 ↑教学 ↑呼吸  ↑高潮A  ↑呼吸 ↑高潮B  ↑呼吸  ↑终局
```

**节奏规则（写进每个区域的设计里）：**

1. **每 90 秒必须变一次**：新颜色 / 新声音 / 新空间 / 新机制，四选一。
2. **每 3 分钟必须给一次 30 秒的「什么都不用做」**：回广场、走一段没有敌人的路、看一次井。
3. **两次高潮之间必须有一次「回看」**：让玩家从高处看见自己刚走过的路。
4. **难度只升不降，但压力可以降**：终局机制最难，但「掉下去不会死」（`FallRespawn` 回上一层），所以是「紧张的从容」。

## 4. 逐段节拍表

### ① 珊瑚庭院 · 0:00–2:00 ｜ 青绿 · 教学
| 时间 | 玩家在做什么 | 看到什么 | 在教什么 |
|---|---|---|---|
| 0:00–0:25 | **不能操作**，镜头从水下往上浮 | 海草摆动、三束 `Sunshafts`、远处的井口有一道光 | 建立「要去那道光」 |
| 0:25–0:50 | 能走了 | `Green Sea Grass` 之间的小路，浅水没过脚踝 | 移动、镜头 |
| 0:50–1:20 | 吹第一颗泡 —— 打一颗挂在石台上的 `TerrainBubble` | 泡打进目标 → 炸开 → 平台落下来 | **吹泡 + 填充** |
| 1:20–1:50 | 吹一颗大泡贴到 `StickySurface` 石壁 → 骑着它上升 | 泡贴住墙变成台阶/挂点 | **粘泡 + 骑泡** |
| 1:50–2:00 | 走到广场入口 `TFD_Gate_01A_Module_02` | 门后突然开阔 | 过渡 |

> 这一段**没有任何失败可能**（掉水里有 `FallRespawn`，而且水浅）。目的是让玩家在 2 分钟里把三个动词都摸过一遍。

### ② 沉没广场 · 2:00–3:30 ｜ 石灰白 · 枢纽
| 时间 | 玩家在做什么 | 看到什么 | 在教什么 |
|---|---|---|---|
| 2:00–2:40 | 走进广场，环顾 | 一圈 `TFD_Column_02A` 柱廊 + `Railing`；**中央是一口深不见底的井**，井壁竖排 `Column_28`，井口一束顶光 | 目标：井顶的祭坛 |
| 2:40–3:10 | 走近井沿往下看 | **井底有水，正在慢慢涨**；水面反光在柱子上晃 | 时钟：水位 = 进度 |
| 3:10–3:30 | 三扇门：左（断柱廊）、右（峡谷）、后（迷宫） | 三扇门的门楣上各有一个标记 | 三条路，随便选 |

> **这一段的唯一任务是「让他抬头看见祭坛，低头看见水」。** 只要这两眼看懂，后面 12 分钟玩家自己会紧张。

### ③ 断柱廊 · 3:30–6:30 ｜ 暖褐 · 第一个高潮
完整设计见 `wengjie-emergent-level.md`（倒柱桥）。这里只给美术落地：

- **柱廊** = 8 根 `TFD_Column_01A_Module_07`（柱身）+ `_28`（柱头）+ `Rock_Slab_02A`（柱础）拼成。
- **要倒的 4 根**：外观用 3 个模块拼成一个空物体，**碰撞体只用一个 `BoxCollider` 近似**（别用 MeshCollider，8 米高的网格碰撞会卡）。
- **横梁** = `TFD_Beam_12A`，倒下来的柱子正好卡在两根梁之间 —— 这一下会让玩家觉得「这地方是为我准备的」。
- **没有雾、没有水、没有后期**。和前后两段形成最大反差：这里是**干的、暖的、安静的**。

| 时间 | 玩家在做什么 | 在教什么 |
|---|---|---|
| 3:30–4:10 | 走进柱廊，摸到第一根柱子 —— **它会晃** | 「这些是活的」 |
| 4:10–5:00 | 填掉第一颗楔子 → 柱子倒 → 桥 | 核心机制 |
| 5:00–6:10 | 沟里涨水 + 渡台经过 + 柱子堵住渡台 | 自己毁掉备选路线 |
| 6:10–6:30 | 从倒下的柱子上走过去 | 成就感 → 回广场 |

### ④ 峡谷裂口 · 6:30–9:00 ｜ 深蓝 · 第一次被追
| 时间 | 玩家在做什么 | 在教什么 |
|---|---|---|
| 6:30–7:10 | 走进峡谷，**身后开始涨水**（`TideRising` 音效起） | 潮水会追 |
| 7:10–8:20 | 在 `Canyon_Cliff` 之间的窄道上跑，水在脚下涨 | 跑位、跳、用泡垫脚 |
| 8:20–8:50 | 被水顶起来（3.5 m/s）→ 发现水也能当电梯 | 危险 = 工具 |
| 8:50–9:00 | 冲到出口 | 逃脱 |

> 这一段的作用是**换气口反过来**：前面太安静，这里必须让玩家手心出汗。做法是水一直比玩家慢半步 —— 看到它、但永远追不上。

### ⑤ 迷宫废墟 · 9:00–11:30 ｜ 暗紫 · 放慢
| 时间 | 玩家在做什么 | 在教什么 |
|---|---|---|
| 9:00–9:40 | 进迷宫（`SM_L5_mi_gong` 模块拼 3×3），**很暗**，只有泡的光 | 幽闭感 |
| 9:40–10:30 | 发现一堵墙后面有东西，但过不去 | 制造问题 |
| 10:30–11:00 | 吹泡 → 把炸弹塞进泡里（`AbsorbBomb`）→ **按 E 遥控它飞过去** → 引爆 | 跨系统组合 |
| 11:00–11:30 | 墙塌了，拿到东西（一颗**大 `TerrainBubble`**，是终局要用的） | 奖励 |

> 这一段是**节奏的刹车**：不跑、不躲，只有「想」。放在两个高潮之间，玩家才会觉得终局有力气。

### ⑥ 深渊井 · 11:30–15:00 ｜ 黑 + 一束光 · 终局
| 时间 | 玩家在做什么 | 在教什么 |
|---|---|---|
| 11:30–12:00 | 回广场 —— **水已经涨到第二层了** | 「你花了 12 分钟」 |
| 12:00–12:40 | 下到井底（或从井壁的破口进） | 空间反转：往上 |
| 12:40–14:00 | 用倒柱 / 骑泡 / 提拉 / 被水顶 一层层往上 | 全系统复习 |
| 14:00–14:40 | 水追到脚边，最后 6 米 | 最高张力 |
| 14:40–15:00 | 踩上祭坛，水停在下面 | 收束 |

## 5. 三根「串场线」—— 让 15 分钟不散

1. **水位 = 全局时钟。** 井里的水从第 1 分钟就在涨，每次回广场都高一点。不写一个字，玩家自己会算。
2. **每条支路开一条回程捷径。** 断柱廊尽头有 `TFD_Stairs_01A` 直接回广场二层；峡谷出口是一条滑道；迷宫塌墙后有一条直通井壁的洞。**走回头路是 15 分钟体验最大的敌人**，所以每条路都必须「去 3 分钟，回 20 秒」。
3. **三个支路各给一件「只有终局用得上」的东西**：倒柱给的是一根**已经在沟上的柱**（终局可以当梯）、峡谷给的是**水位信息**（玩家知道该多快）、迷宫给的是**大 `TerrainBubble`**（终局填满它，井壁裂开一条路）。

## 6. 建造顺序（4 个半天）

| 半天 | 做什么 | 验收 |
|---|---|---|
| 1 | 广场 + 井（只做体块 + 水位） | 站在广场能一眼看见祭坛和水 |
| 2 | 珊瑚庭院（教学）+ 广场三扇门 | 3 个动词都能用，走完 2 分钟不卡 |
| 3 | 断柱廊（第 3 段完整） | 能倒柱过沟，柱子不抖 |
| 4 | 峡谷 + 迷宫 + 终局 | 15 分钟能一口气跑完 |

**如果时间不够，按这个顺序砍：** 迷宫 → 峡谷 → 终局简化成「爬到顶」。**绝不能砍**：珊瑚庭院（教学）、广场（时钟）、断柱廊（核心）。

## 7. 15 分钟怎么验收

1. **带一个人完整玩一遍，不说话，掐表。** 记录三个数：到达广场的时间、第一次倒柱的时间、通关时间。
2. **判断标准**：
   - 广场 ≤ 3:30（超过说明教学太长）
   - 第一次倒柱 ≤ 6:30（超过说明广场到柱廊的路太长）
   - 总时长 13:00–17:00（低于 13 太短，高于 17 说明有地方卡住了）
3. **问一句话**：「刚才你在哪一段最放松？」如果他说不出广场，说明呼吸点没做出来。

## 8. 一句话

> 15 分钟不是「六个关卡」，是**一条从绿到黑的路**。
> 玩家记得的不是哪一关好玩，是「水一直在我后面涨，而我一直在往里走」。
