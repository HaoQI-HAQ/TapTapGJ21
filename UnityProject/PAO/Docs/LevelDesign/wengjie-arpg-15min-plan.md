# wengjie · 15 分钟关卡规划（线性主干 + 三个箱庭）

> 参考：[《仁王3》二俣城——线性与箱庭融合的ARPG关卡设计拆解](https://www.gcores.com/articles/220542)

## 一、从参考里拿到的四条

1. **线性主干不可跳过** —— 主线承载目标与大节点，玩家永远知道「往哪走」。
2. **局部箱庭依附主线** —— 每个箱庭是半封闭空间：主线穿过它，支线从它分出，捷径把它缝回去。
3. **高低差是箱庭的骨架** —— 村子在高处、外围在低处；峡谷在低处、庭院在高处。玩家在垂直方向上「穿行」。
4. **捷径降低挫败** —— 单向门/梯子把「打过的路」折叠成 10 秒，放在战斗节点之间。

**它回答的三个问题**：为什么不会迷路（主干唯一）、为什么愿意探索（支线有明确奖励）、为什么不单调（每个箱庭的高低差+环绕都不同）。

## 二、整体：一条上山主线 + 三个箱庭

```
        ◉ 塔顶祭坛  y=+72
        ║
   ┌────╨────┐
   │ 箱庭三   │  峡谷井：螺旋井壁，潮水追
   │ y=40→70 │  环绕：井内绕 540°
   └────╥────┘
        ║
   ┌────╨────┐
   │ 箱庭二   │  断柱街市：环街 270°
   │ y=12→40 │  高低差：屋顶 ↔ 地面 ↔ 下水道
   └────╥────┘
        ║
   ┌────╨────┐
   │ 箱庭一   │  浅滩村口：绕村的弧形坡
   │ y=0→12  │  高低差：河岸 ↔ 村台
   └────╥────┘
        ║
      出生点
```

**主干长度**：约 620 m；**含支线与环绕**：约 900 m；**目标时长 15–17 分钟**。

## 三、箱庭一 · 浅滩村口（0:00–4:30）

### 空间
- 90 × 70 m，y = 0 → +12，天花板 24 m。
- **一条弧形坡道**从河岸绕到村台，贴着村子外缘转 **200°**，不是直线。

### 动线
| 类型 | 内容 | 位置 |
|---|---|---|
| 主线 | 河岸 → 弧形坡 → 村口石阶 → 村台 | 贯穿 |
| 支线 A | 河对岸的浅滩洞穴，尽头一颗**泡泡泉** | 入口在出生点右侧 20 m |
| 支线 B | 村台下方的一条小巷，尽头是**单向门**（从内侧打开，回程用） | 村台西侧 |
| 捷径 | 单向门开后，从村台直接跳回河岸，省 90 秒 | 战斗节点之后 |

### 弯曲与环绕
- 弧形坡用 **12 段折线**近似圆弧，半径 45 m，转角 16°，走起来是「绕着村子转」而不是「走直道」。
- 村台是一个 **环形平台**（外径 55、内径 25），中央是空的（下面就是箱庭二的屋顶）。

### 编排
- 入口 30 秒无威胁（看塔）。
- 坡道中段 1 个 `BubblePopObstacle` 尖刺，教「泡泡会被打破」。
- 村台 2 处塌陷板，逼玩家在环形平台上跑动。

## 四、箱庭二 · 断柱街市（4:30–9:30）

### 空间
- 110 × 90 m，y = +12 → +40（**三层**：地面街市 y=12 / 屋顶 y=26 / 下水道 y=6）。
- 主线在**三个高度之间穿行**：地面 → 屋顶 → 地面 → 下水道 → 地面。

### 动线
| 类型 | 内容 | 高度 |
|---|---|---|
| 主线 | 街市 → 爬梯上屋顶 → 屋顶跑到断柱处 → 跳下 → 下水道 → 爬出到井口 | 12→26→12→6→40 |
| 支线 A | 屋顶的隐藏阁楼（需要拆柱），奖励 2 颗泡泡泉 | 26 |
| 支线 B | 下水道的死路，尽头是一扇**单向门**直通箱庭三底部 | 6 |
| 捷径 | 断柱倒下后搭成的桥，把「绕街市」折叠成「直接过沟」 | 12 |

### 弯曲与环绕
- 主街是 **270° 的环形街**，绕着一个塌陷的钟楼转，走到底会发现自己回到了钟楼的另一侧。
- 屋顶路线是**相反方向**的 270°，所以玩家在同一个空间里走了两遍，但看到的是不同的面（一次仰视、一次俯视）。
- 断柱处有 4 根柱，倒下的方向决定桥的形状 —— **环绕的终点由玩家自己决定**。

### 编排
- 街市段：3 组巡逻刺墙，节奏是「走 20 米 → 躲一次」。
- 屋顶段：2 根扫杆 + 1 处塌陷，压力最高的一段（约 90 秒）。
- 下水道段：**没有机关**，只有黑暗和回声 —— 这是一次强制呼吸，为箱庭三攒钱。

## 五、箱庭三 · 峡谷井（9:30–14:00）

### 空间
- 80 × 80 m 竖井，y = +40 → +70，井壁 **6 层错落岩台**。
- 潮水从井底涨，玩家必须**一边绕井一边上升**。

### 动线
| 类型 | 内容 |
|---|---|
| 主线 | 井底进入 → 绕井 540° → 六层岩台 → 井口 |
| 支线 | 井壁中段一个凹洞，里面是最后一颗泡泡泉（决定你能否活着上去） |
| 捷径 | 无 —— **这一段故意不给捷径**，是全关唯一「必须一次做完」的段落 |

### 弯曲与环绕
- 六层岩台每层转 90°，整体是 **540° 的螺旋**，从井口往下看能看到自己刚才走过的六层。
- 潮水追上来的速度和玩家的上升速度**接近**（3.5 m/s vs 提拉 2 m/s + 跳跃），所以必须用「先跑、再爬、再跑」的节奏。

### 编排
- 第 1–2 层：教学（水在下面，很慢）
- 第 3–4 层：加速（水追上来，第一次被顶）
- 第 5–6 层：极限（没有落脚点，全靠泡泡）

## 六、终局 · 塔顶（14:00–15:30）

- 60 × 60 平台，y=+72，祭坛在中央。
- **从井口爬出来的那一刻，整个 A→D 在脚下** —— 这是 15 分钟唯一的俯瞰镜头。
- 没有战斗，没有机关。**只给 30 秒走路的时间。**

## 八、建造分期

| 期 | 内容 | 验收 |
|---|---|---|
| **P1** | 三个箱庭的**外壳**（弧形坡、环形村台、270° 街、540° 井） | 走完主干 **8–10 分钟**，不迷路 |
| **P2** | 支线 A/B + 单向门 + 捷径 | 每箱庭支线 ≤ 90 秒，捷径省 ≥ 60 秒 |
| **P3** | 机关 / 陷阱 / 潮水 | 三个战斗节点各死一次 |
| **P4** | 美术换装 + 光 | 站在出生点能看见塔顶 |

**P1 只做外壳**，而且必须**先做弧形和环形**（不是方块），这是这一版和之前最大的区别。
