# 泡涌 UI V2 接入说明

> 当前黑白线框界面、两级主菜单、横向章节图册与存档关系见 [界面与章节规划](../../../../../Docs/UI-V2/monochrome-route-atlas.md)。下文的彩色视觉与旧菜单记录保留为历史迭代说明。

本轮实现规划中各模块的可运行基础版本。Unity 2022.3 的 uGUI、现有中文字体、图标和 DOTween 直接复用。正式叙事、结局、配方及关卡终点由关卡内容配置驱动。

## 启动与预览

直接运行 `Assets/GameMain/UI/Menu.unity`。`Resources/PAOUIConfig.asset` 启用后，运行时自动创建统一 UI；进入配置中的玩法场景时创建 HUD。原有场景 UI 仅在运行时隐藏，关卡文件无需重建。配置中的 `enabledInBuild` 可以切换这套 UI。

通过 Unity 菜单 `PAO > UI > V2 > 打开 UI 预览场景` 打开独立预览。运行后按 F2 查看全部模块入口；预览中的对话与浮台明确标为示例，便于验证交互。

### 黑底加载与泡泡过场

Menu 场景保留原有 Canvas 和控件。`Black Loading Backdrop` 是置顶的纯黑底图，相机也使用纯黑清屏；编辑态和运行时初始化前不会露出旧菜单或天空盒。V2 初始化后仍会隐藏旧 Canvas，并创建当前主菜单。

`UIBubbleTransition` 使用独立的全屏画布承接启动和 `UIRuntime.LoadScene` 的场景切换，不受页面栈清理或安全区裁切影响。旧画面先淡入黑底，再异步加载；新场景的 Start、存档位置恢复和 HUD 完成后才揭开画面。加载期间屏蔽菜单导航和玩法输入，失败时回到重试确认。

`UILoadingBubbleField` 绘制 24 个黑白泡膜，采用大小相关的上浮速度、水流阻尼、柔性接触、弹簧回弹及面积保持形变。动画使用非缩放时间，减少动态效果时保持静止。正常过场最短停留 0.65 秒、淡出 0.4 秒；减少动态效果时取消最短停留并缩短淡出。

实际 Unity 截图、4 秒运动预览和验证记录见 `Docs/UI-V2/loading-transition-2026-10-17/`。可在独立验证工程运行 `LoadingTransitionReview.RunCLI` 重现。

## 关卡内容配置

`PAOUIConfig` 配置主题、字体、章节场景、章节文字和结局。现有 Map 标题是可替换的“水域 01 至 06”；默认未编写正式结局，不在游戏中虚构剧情分支。

- **章节入口**：配置 `defaultPlayer` 和每章的 `spawnAnchor`。缺少玩家时，在同名场景物体的世界上表面生成默认玩家，按实际碰撞体高度调整；已有玩家继续复用。入口朝向默认面向终点。生成玩家时停用白盒相机及其监听器。
- **章节终点**：`goalAnchor` 指定白盒中现有地标；缺少终点时在地标上创建可见灯柱及互动触发器。靠近后按当前设备的交互绑定，再确认完成；取消继续探索。已有 `tiaozhuan`、`ChapterGoalTrigger` 和 `BubbleTideDirector.Won/Lost` 继续复用。也可用 `PAO > UI > V2 > 创建章节终点触发器` 手动配置位置和 `nextScene`。
- **意识碎片**：创建 `MemoryTrigger`，设置稳定且唯一的 `memory.id`、标题与正文。可指定 `DialogueAsset` 播放对话及后续分支。
- **叙事资产**：`Create > PAO > UI > Dialogue`。每段对话提供稳定 `id`、说话者、文本、选项及后续资产。重要对话期间玩法暂停，已读内容进入日志。
- **建构点**：创建 `BuildSite`，设置唯一 `id`、落点 `placement`、合法性和不可用说明。`Create > PAO > UI > Build Recipe` 配置唯一配方 `id`、实际预制体、成本和说明。只有确认后创建预制体并扣除资源；拆除后返还。配方不承诺尚未实现的物理行为。
- **音频**：`UIAudioChannel` 将 AudioSource 接入音乐或音效音量；声音文字提示可填写在同一组件。未标记的循环 2D 音源推断为音乐，其他音源按音效接入；正式内容可显式设置 `music`。
- **目标更新**：调用 `UIRuntime.Instance.SetObjective(text)`；非模态情境提示使用 `Toast(text)`；其他模块通过 `CollectMemory`、`ShowDialogue`、`ShowConstruction`、`CompleteChapter` 接入。

## 页面生命周期

`UIPage` 提供 Show、Hide、Refresh、SetInteractable、RestoreFocus。顶层页面独占输入；关闭时回到原发起控件。确认弹窗默认聚焦取消。透明度动效使用非缩放时间，并在禁用或销毁时终止。

设置为事务式编辑：打开时保存快照，控件变化仅预览，应用统一持久化，返回恢复快照。UISettings 管理全局设置，UIRunState 管理当前旅程；界面不以零散 PlayerPrefs 作为业务状态来源。

关闭最后一个页面的当帧继续屏蔽玩法输入，避免返回键同时触发交互或发射。暂停时引爆、吸收炸弹的引爆、潮水确认与调试输入也被屏蔽。

## 设置与改键

进入设置的「键鼠」或「手柄」页，默认显示操作绑定；「输入参数」提供各自的灵敏度、视角反转和单击蓄力选项，手柄另有移动/视角死区、扳机阈值和摇杆交换。「按键示意」显示对应设备布局。

点击绑定，先松开当前输入，再按新按键；键鼠页接受键盘与鼠标按钮，手柄页接受按钮、十字键和扳机。Esc 或 Menu 取消，12 秒没有输入自动取消；捕获期间屏蔽菜单导航，避免按钮同时提交界面。冲突先确认再交换，不会让跳跃、蓄力等必需操作失去绑定。每行可恢复单项默认，可选的手柄直接选择/日志/帮助绑定可以清除。

「重置键鼠绑定」/「重置手柄绑定」恢复本设备的绑定及输入参数，「恢复全部默认」恢复所有设置；两者均需确认，并在应用后保存。返回会撤销未应用预览。改键后的 HUD、帮助、骑乘、碎片、建构点和章节终点提示读取共享映射。

声音页提供总音量、音乐、音效、后台静音和试听；画面页提供显示模式、分辨率、画质、垂直同步和帧率限制。显示模式与分辨率应用后须确认，15 秒无输入或选择还原会恢复实际原显示状态。辅助页提供字幕预览、透明度、色觉辅助、文字/UI 缩放和减少动态；语言页支持中文、英文和伪本地化预览。

设备热切换保留当前焦点。正在使用的手柄断开时取消改键并保持暂停，可重新连接或使用键鼠恢复，绑定保留。

## 探索中的画面引导

默认使用图像提示：目标在视野内显示小型目的地符号，视野外显示安全区内的方向箭头；蓄力与待发射状态显示准星环；首次操作显示短暂的动作图示和当前按键，不再自动弹出大段教学文字。右上日志与暂停使用图标和小型快捷键。

靠近意识碎片、建构点、章节终点或可乘坐泡泡时，图标和当前绑定跟随对象显示；固体遮挡物会隐藏互动标记，离开范围或对象失效时移除。乘坐/操控泡泡期间保留退出符号，暂停时所有引导随 HUD 隐藏。泡泡潮仍保留必要倒计时。

完整目标和能力说明可主动在「操作与教学」中查看。「辅助 > 详细文字提示」可恢复目标说明、蓄力文字和完整首次教学；声音字幕、剧情字幕和错误/危险确认继续提供文字。减少动态模式保留静态形状与按键信息。

## 存档边界

保存位置为 `Application.persistentDataPath/PAO_Saves`。每次覆盖先写临时文件并刷盘，再替换原文件，上一份保留为 `.bak`。损坏恢复保留 `.damaged`；损坏或未知版本不会被当作有效记录。旧版纯 JSON 可以读取。

本轮存档恢复玩家位置、旅程状态及已配置建构点。读取会重载场景，因此临时生成的泡泡、潮水计时、其他地形修改和运行中的物理状态会重置。保存界面已说明场景将重建；完整世界快照、云端冲突和版本迁移表需要在玩法层建立相应数据接口。

旅程恢复使用深拷贝，避免当前玩法修改已读记录；恢复时清理空条目、重复 ID、非法建构成本及无效计时。已收集碎片不会重复拾取；已归档但尚未提交选择的对话仍可重新打开。

## 主菜单与视觉细化

运行实际 `Assets/GameMain/UI/Menu.unity` 时，V2 自动隐藏旧菜单并确保事件系统可用。主菜单使用暖白水母背景与单列入口，宽屏左侧菜单、右侧插画，窄屏居中列；首屏仅保留标题、副标题、主要操作及次级入口。进度、碎片、时间、记录详情在对应页面查看；主菜单仅在无有效记录时提供简短的异常提示。`UIMenuPresentation.cs` 控制列宽、标题适配、按钮换行高度和低频背景呼吸。

菜单只显示可读取且可进入的继续记录；损坏记录可进入记录页面恢复备份。恢复或删除后返回菜单会同步更新状态并保留焦点。开始新旅程前检查第一章是否可进入，防止先清理进度后加载失败；没有有效记录时清理旧会话的章节解锁和意识碎片。

`UIButtonFeedback` 为共用按钮提供不受暂停影响的悬停、焦点及按下反馈；减少动态时关闭缩放。退出、删除和覆盖确认使用警示色，取消仍为默认焦点。章节、存档与制作人员面板使用同一套卡片样式。

`UIMenuVerification.RunCLI` 在独立工程中验证实际菜单、继续进入实际 Map0、备份恢复、异常记录、焦点导航和五种窗口比例；`UIV2Verification.RunAllCLI` 继续覆盖完整 UI 回归。`Tools/UIV2/collect_menu_results.py` 收集两组结果至 `Docs/UI-V2/menu-design/`，详细说明见该目录的 `verification.md`。

本轮主菜单精简与布局验证保存在 `Docs/UI-V2/menu-layout/`，使用 `Tools/UIV2/collect_menu_layout_results.py` 收集。专项覆盖用户截图的 934×534 小窗口、各窗口比例和大字号/界面缩放/伪本地化组合，逐次聚焦入口，检查可读性及标题、菜单、提示与底部帮助之间无可见重叠。滚动内容使用独立裁切区域；固定标题与底部操作保持分离。

补充优化使用较大的主入口、轻量底部操作与自动换行布局。`UIMenuEntryMotion` 在图标预留范围内提供 140 ms DOTween 反馈，减少动态时立即复位；共用滚动条在内容溢出时出现，并跳过默认焦点和方向导航。报告与截图另存 `Docs/UI-V2/menu-polish/`，收集命令为 `python Tools/UIV2/collect_menu_layout_results.py <隔离工程路径> polish`。

## 海洋珠光视觉与动效

最新角色与视觉参考使用深海蓝、青蓝、淡紫与粉色泡膜。菜单角色图片从现有 takoyaki 视觉网格烘焙；`UIOceanStyle` 用 uGUI 顶点色制作渐变、珠光膜、柔光与水流，装饰不接收点击。按钮悬停变紫、按压与涟漪由 `UIButtonFeedback` 控制，菜单焦点同时触发角色姿态与说明卡响应。

右下角 `UIAbilityMotion` 统一控制三节点选中边界、旋转光弧、切换涟漪、光珠移动与真实蓄力进度；能力卡与蓄力条联动对应能力色。图标保留独立形状。`UIConfig.motion` 中可调节响应、260 ms 切换、页面淡入、涟漪和旋转周期。动画使用独立时间，替换、隐藏与销毁时结束 Tween；减少动态会即时关闭漂移、旋转和缩放。

`UIVerificationRunner.Motion.cs` 检查快速切换终态、暂停时间、悬停色变、蓄力同步、减少动态和反复开关后的 Tween 数量，并捕获 60 帧真实运行动画。用 `Tools/UIV2/collect_motion_results.py` 收集至 `Docs/UI-V2/motion-design/`，包含动画预览、截图、行为报告与被验证的源码快照。

## 手绘基础质感

`UIHandDrawn` 在页面、按钮、能力节点与选中环接入画纸素材，`UIOceanStyle` 与 `UIGuideGraphic` 提供哑光泡膜及轻微不规则笔画。纸纹不影响字体绘制，高对比模式隐藏装饰，减少动态继续保留静态符号。
