## 角色设定

| 项 | 内容 |
|----|------|
| 造型 | 蓝色水母——圆顶状头部、5 条圆润触手 |
| 配饰 | **可爱储泡泡液罐**（替代背包）——圆润糖果色罐身、爱心/星星贴纸、橙色布质绑带、螺旋软管连接头部 |
| 面部 | 大号黑眼睛（带高光）、粉色腮红 |
| 风格 | Splatoon 3 官方美术风格 |

## 美术规范

### 风格要素

| 项 | 要求 |
|----|------|
| 线条 | 极粗、可变宽度的黑描边 |
| 色彩 | 霓虹撞色——青 / 品红 / 荧光黄绿 / 紫 |
| 质感 | 喷漆飞溅、流挂、半调网点 |
| 上色 | 硬边赛璐璐，不用柔和渐变 |
| 涂鸦 | 贴纸、星星、箭头、手写涂鸦、滴落 |
| 氛围 | 街头涂鸦、贴纸拼贴、活泼 |
| 剪影 | 敦实、圆润可爱 |

### ⚠️ 表情红线：搞笑但不丑化

| ✅ 可以 | ❌ 不可以 |
|--------|----------|
| 鼓腮、脸红 | 爆青筋 |
| 眼睛挤成 `><` | 眼球凸出 |
| 小汗珠 | 脸色发紫发黑 |
| 用力的小火花 | 五官扭曲变形 |

> **搞笑来自"可爱的努力"，不是来自"丑"。**

### ⚠️ 储罐设计约束

**要可爱，不要工业风。**

| ✅ 要 | ❌ 不要 |
|------|--------|
| 圆润糖果色罐身 | 拉丝金属质感 |
| 爱心 / 星星贴纸 | 警示条纹 |
| 橙色布质绑带 | 金属扣具 |
| 螺旋吸管状软管 | 工业气管 |
